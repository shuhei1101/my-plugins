# ui-kit 設計方針

## 対象スコープ

開発支援画面(管理パネル・内部ツール・デバッグページ)向けの UI コンポーネントと規約。

---

## PC 専用方針(PR53 で確定)

**ui-kit は PC 版のみをターゲットとする。**

- モバイル・タブレット向けのレスポンシブ対応は行わない
- スマホからアクセスする場合も PC 表示のまま使う
- ブレイクポイント・メディアクエリは生成しない

### 背景

- モバイル画面対応はバグが多く、見通しが悪い
- 操作性は PC 画面の方が優れている
- 開発支援ツールはデスクトップ環境での利用が前提

---

## 削除済みの概念(PR53)

| 概念 | 削除内容 |
|---|---|
| Responsive セクション | ブレイクポイント定義(< 640px / 640–1024px / ≥ 1024px)を削除 |
| Drawer (Mobile) | モバイル用ハンバーガーメニュー・スライドドロワーを削除 |
| モバイル分岐 | ヘッダー高さ・トースト位置・一覧+詳細の mobile フォールバックを削除 |
| @media クエリ | mock-skeleton.html の `@media (max-width: 640px)` ブロックを削除 |

---

## レイアウト原則

- サイドバーは常時表示(固定)
- 2ペイン(一覧+詳細)は PC の横並び表示のみ
- トースト通知は右下固定
- アクションボタン(一覧画面)はリスト上部右
