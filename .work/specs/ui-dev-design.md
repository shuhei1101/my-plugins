# ui-dev — 開発系画面デバッグ規約 設計仕様

## 概要

`dev-kit:ui-dev` は、開発系画面(管理画面・内部ツール・デバッグ画面など)を作成・編集する際に
必ず適用する UI 規約。中心機能は「フロートデバッグボタン」によるデバッグ動線提供。

エラー発生時や挙動確認時に、画面に関する情報(関連ファイルパス + 直近 JS ログ)を JSON で
クリップボードにコピーし、そのまま Claude Code に貼り付けてデバッグできることを目的とする。

## スキル位置づけ

- **プラグイン**: `dev-kit`
- **スキル名**: `dev-kit:ui-dev`
- **対象**: 開発系(本番ユーザーに見せない)画面の作成・編集
- **トリガー**: 開発用 UI を作る・改修する依頼が来たとき
- **関連リファレンス**: なし(将来 `references/frontend.md` に切り出す可能性あり)

## フロートデバッグボタン仕様

### 必須要件

- 開発系画面には**常に**フロートボタンを設置する(必須)
- 本番環境では表示しない(判定方法は QA-003 で確定)
- ボタンクリックでデバッグモーダルが開く

### デフォルト設定(暫定)

| 項目 | デフォルト |
|---|---|
| 位置 | 右下 (`position: fixed; bottom: 16px; right: 16px;`) |
| アイコン | 🐛 |
| サイズ | 48px 丸ボタン |
| z-index | 9999 |

位置は上下左右切替可、その他もオプションで上書き可能。

## デバッグモーダル

### 表示内容

クリックでフルスクリーンに近いモーダルが開き、以下を表示:

1. **画面識別子**(URL またはルート名)
2. **関連ファイル一覧**(HTML / CSS / JS / バックエンド)
3. **直近 N 行の JS ログ**(デフォルト 100 行)
4. **設定**: ログ取得行数の調整(localStorage に保存)
5. **コピーボタン**(一番上に大きく配置)

### コピーボタン押下時

クリップボードに以下のスキーマで JSON をコピー:

```json
{
  "page": "{画面の識別子}",
  "files": {
    "html":    ["..."],
    "css":     ["..."],
    "js":      ["..."],
    "backend": ["..."],
    "other":   ["..."]
  },
  "logs": {
    "limit":   100,
    "entries": [
      { "ts": "ISO8601", "level": "log|info|warn|error", "args": ["..."] }
    ]
  }
}
```

## JS ログ収集

`console.log / info / warn / error` をラップしてリングバッファに溜める(透過的に取得)。
`window.onerror` と `unhandledrejection` も自動で取り込み、未捕捉エラーを逃さない。

リングバッファのサイズはデフォルト 100 行(localStorage で上書き可能)。

## 関連ファイルの登録方法

各画面に「この画面が依存しているファイル」を明示登録する。
登録手段は実装スキル内で具体例を示す(`data-debug-files` 属性 / JS 設定オブジェクト / コメント規約 など)。

## 運用フロー

1. 開発者がエラーや挙動異常を確認
2. フロートボタンをクリック → モーダルが開く
3. コピーボタンを押す → JSON がクリップボードへ
4. Claude Code に貼り付けて「これでデバッグして」と依頼
5. Claude が関連ファイルとログから原因を特定
