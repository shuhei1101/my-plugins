# rules-organizer — .claude/rules/ フォルダ整理スキル

## 概要

`.claude/rules/` 配下がフラットに散らばっているルールファイルをコードベースに合わせてフォルダ単位で整理する。
どのプロジェクトにも適用できる汎用スキル。

## フォルダ設計方針

### 必須フォルダ

| フォルダ | 役割 |
|---|---|
| `core/` | プロジェクト全体にかかる規約・ワークフロー・環境設定。機能や開発フェーズに依存しない。 |
| `feature/` | 個別機能のドメイン知識・実装ルール。機能単位で 1 ファイル。 |

### 任意フォルダ（コードベース依存）

参考例として提示し、ユーザーが自由に追加・削除できる。

| フォルダ | 追加する目安 |
|---|---|
| `ui/` | フロントエンドがあるプロジェクト |
| `api/` | バックエンド API のルールが多いプロジェクト |
| `infra/` | インフラ・デプロイ系のルールが多いプロジェクト |

### 概要ファイル

- 各フォルダのルートに `_overview.md` を置く
- `_index.md` という名前は使わない（「ファイル一覧」と誤解されやすいため）

## スキルの動き（フロー）

1. **既存ルールを収集** — `.claude/rules/` 直下のフラットな `.md` を列挙
2. **コードベースをスキャン** — `package.json`・ディレクトリ構成などからプロジェクトの性質を把握
3. **フォルダ構成案を提示** — 移動計画を表形式で出す（移動元 → 移動先）
4. **ユーザー確認・修正** — フォルダ名や分類を対話的に調整
5. **実行** — ファイル移動 + `_overview.md` 生成
6. **既存フォルダがある場合** — 全体見直しモード（既存フォルダも再分類の対象）

## スキルの配置

- パス: `plugins/claude-kit/skills/rules-organizer/`
- コマンド名: `claude-kit:rules-organizer`
