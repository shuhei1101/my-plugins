# ベースブランチ設定の追加

> ブランチ: `feat/base-branch-config`

## 概要

`WORK_BASE_BRANCH` 環境変数を新設し、ワークツリー作成時にブランチを切り始めるベースブランチを指定できるようにする。
デフォルト（未設定）はこれまで通り `master`/`HEAD` から分岐する。
設定例: `nishikawa/master` のような個人作業用ベースブランチを指定すると、そのブランチを起点にワークツリーが作成される。
