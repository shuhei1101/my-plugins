# gh プラグインを追加

> ブランチ: `feat/new-gh-plugin`

## 概要

GitHub MCP 公式サーバーを同梱した新プラグイン `gh` を作成する。これまで work プラグインにあった「イシューを作って解決する」フローを GitHub Issues/PR に乗せ替え、マージは直列化された専用スキル/サブエージェント `auto-merge` が担当する。これにより複数 issue 並列実装時のマージ衝突問題を構造的に解決し、モバイル/ブラウザでのレビュー体験も向上させる。

work プラグインからは関連スキル/サブエージェントを移管せず、新プラグインとして 0 から組む（旧依存を持ち込まないため）。

### 実施条件

即時実施可
