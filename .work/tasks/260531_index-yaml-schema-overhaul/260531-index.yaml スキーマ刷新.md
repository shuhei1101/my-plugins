# index.yaml スキーマ刷新

> ブランチ: `refactor/index-yaml-schema-overhaul`

---

## 概要

ブランチインデックス `.work/tasks/index.yaml` のスキーマを刷新する。現状は2世代のスキーマが
混在し（旧36件は `branch` キー欠落、新2件のみ `branch` あり）、`id`/`last_id`/`tags` が実質
不要・未使用のまま残っている。さらに全38件が `completed: false` のまま溜まり、マージ済みでも
アーカイブされていない（merge スキルの set-completed/archive が取りこぼし）。

これを次の新スキーマへ統一する：

```yaml
branches:
  - branch: refactor/foo      # 識別キー
    title: 日本語タイトル
    type: refactor
    summary: 一行説明
    task: 260531_foo
    completed: false
```

- `id` / `last_id` を撤廃 → 識別は `branch`
- `tags` を撤廃（ブランチ index のみ。`.work/issues/` の issue 系 tags は対象外）
- 旧38件のマージ済みエントリを `index.archive.yaml` へ移行しバックログ解消

### 対象外

- `.work/issues/` の issue インデックス系（`issue-tool.py` / issue-save / issue-create / issue-scan）は
  独立系統のため触らない（id/tags はそちらでは有効）

### 実施条件

即時実施可。
