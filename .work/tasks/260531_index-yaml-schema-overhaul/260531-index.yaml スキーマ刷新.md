# index.yaml スキーマ刷新

> ブランチ: `refactor/index-yaml-schema-overhaul`

---

## 概要

ブランチインデックス `.work/tasks/index.yaml` のスキーマを刷新する。現状は2世代のスキーマが
混在し（旧36件は `branch` キー欠落、新2件のみ `branch` あり）、`id`/`last_id`/`tags` が実質
不要・未使用のまま残っていた。さらに全38件が `completed: false` のまま溜まり、マージ済みでも
アーカイブされていなかった。

新スキーマ（`branch` を識別キー、`created` をサロゲート、`id`/`last_id`/`tags` 撤廃）:

```yaml
branches:
  - branch: refactor/foo
    created: 2026-05-31
    title: 日本語タイトル
    type: refactor
    summary: 一行説明
    task: 260531_foo
    completed: false
```

### 対象外

- `.work/issues/` の issue インデックス系（`issue-tool.py` / issue-save / issue-create / issue-scan）は
  独立系統のため触らない。

### 実施条件

即時実施可。
