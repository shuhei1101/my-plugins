# 用語集・インシデントのコンテンツ選別復元

> ブランチ: `feat/glossary-incidents-content-restore`

## 概要

PR181（コミット `131daa72`）で、このリポジトリ自身の `.claude/rules/core/glossary.md`（75語）と
`incidents.md`（48件）＋詳細ファイル群が削除された。前ブランチ `feat/revive-conversation-to-claude`
（conversation-to-claude 復活）では「スキル等の仕組みのみ復活、プロジェクト固有コンテンツの復元は
しない」方針としたため、これらは未復元のまま。本ブランチでその**選別復元**を行う。

### 前ブランチからの引き継ぎ背景

- **全件復元はしない**。旧コンテンツには陳腐化した項目が多い（`workspace`→`work` 改名、
  provenance / mark-generated 廃止、py-kit 再編、削除済みスキルへの言及 等）。現在も有効なものだけを
  選別して復元する。
- 採用基準は前ブランチで新設した `plugins/work/references/conversation/用語集.md` /
  `インシデント.md` に従う:
  - glossary: プロジェクト固有・名前から非自明・繰り返す・CLAUDE.md/ルール/フォルダ構成に既出でない。
  - incidents: セッションの作業プロセスのミスのみ（コードのバグ修正は対象外）・一般化可能・既存ルール等で未強制。
- `.claude/references/incidents/` に**孤立した incident 詳細が8件**残っている（インデックス無し）。
  これらの扱い（現行基準で有効なものをインデックス化 / 無効なものを整理）も本ブランチで行う。
- 復元先フォーマット: glossary = `.claude/rules/glossary.md`、incidents = `.claude/rules/incidents.md`
  （インデックス・常時ロード）+ `.claude/references/incidents/{slug}.md`（詳細）。現状このリポジトリに
  `.claude/rules/` は存在しないため新規作成になる。
- 旧コンテンツは git 履歴から取得する: `git show 131daa72^:.claude/rules/core/glossary.md` /
  `git show 131daa72^:.claude/rules/core/incidents.md` および当時の `references/incidents/`。
