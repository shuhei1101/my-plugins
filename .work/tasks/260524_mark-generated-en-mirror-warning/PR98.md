# PR98 — JP ミラー警告コメントの遡及適用

## 概要

PR94 で `mark-generated` に JP ミラー警告コメント (`<!-- This file is a Japanese mirror. ... -->`) を導入したが、
当時の一括 backfill ではカバーされなかった／その後に追加された `.jp.md` ファイルが 25 件残っていた。
それらに「JP ミラー警告」と「Generated by スタンプ」（適用可能なファイル種別のみ）を遡及適用する。

### 方針

- ユーザー指示により EN 原本側には警告コメントを付けない
- `skill-jp-mirror-sync.md` ルールは残す（JP 警告コメントは JP を読んだときしかトリガーしないため、EN→JP 同期の規約はルールでしか担保できない）

### 経緯

- 元 TODO は「EN ミラー警告」の追加だったが、ユーザー判断により方針転換
- 真の問題は EN 警告の欠如ではなく、JP 警告自体が 25 個の JP ミラーに付いていなかったこと
- 初回調査では `head -5` で確認したため frontmatter 持ちファイルを誤検出していた（39 件と誤算）。フル grep で 25 件に確定
