## QA-001: Pythonファイルの「プロジェクト系」「スクリプト系」判定基準

**問い**: フックがPythonファイルを「プロジェクト系（py-project）」か「スタンドアロンスクリプト（py-script）」かをどう判断するか？

**選択肢**:
- A) `pyproject.toml` や `setup.py` が同ディレクトリ/祖先ディレクトリに存在するか
- B) ファイル名のパターン（例: `main.py`, `__init__.py` を含むパッケージ構造）
- C) ファイルパスに特定キーワードを含むか（例: `src/`, `tests/`）
- D) フックは判断せず、AIに両スキルの概要を提示して判断を委ねる

**決定**: D — フックは判断せず、py-project と py-script 両方の概要を1つのプロンプトに含め、AI が状況に応じて適切な方を参照するよう促す
