# work-startコミット順序修正

> ブランチ: `refactor/fix-work-start-commit-order`

## 概要

`work:start` スキルのコミット積み順を修正する。
現状のスキルでは Step 8（ノート作成）が実装前に行われ、Step 10 でブランチ文書とノートをまとめてコミットしてから実装を開始する構成だが、
コミット履歴に「実装→ブランチ文書→ノート更新」という順で積まれるケースがある。

正しいコミット積み順は下記の通り:
1. **最初**: ブランチ文書（実装計画）のみをコミット
2. **中間**: 実装コミット（複数可）
3. **最後**: ノート更新＋ブランチ文書の最終更新をコミット

これを実現するため、Step 8 (ノート) を最後のステップに移動し、Step 9 でブランチ文書のみをコミットしてから実装を開始する構成に変更する。
