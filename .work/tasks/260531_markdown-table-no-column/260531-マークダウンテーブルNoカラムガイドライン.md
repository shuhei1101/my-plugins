# マークダウンテーブルNoカラムガイドライン

> ブランチ: `docs/markdown-table-no-column`

## 概要

マークダウンテーブルリファレンス (`references/markdown/マークダウンテーブル.md`) の `#` カラム名を `No` に変更し、`No` カラムを省略できる条件のガイドラインを追加する。

`#` は英語圏では「number」を意味するが、日本人には直感的でないため `No` に統一する。また、左端カラムが会話中に自然に参照できる短い識別子（A/B/C 等の選択肢など）になっている場合は `No` カラムを省略してよい条件を明文化する。`No` カラムの目的は人間が指示を出しやすくすること（「3番のやつを修正して」）であるため、その目的が左端カラムで達成されている場合は不要。
