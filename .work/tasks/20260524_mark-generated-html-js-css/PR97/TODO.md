# PR97 — mark-generated HTML/JS/CSS 対応

## 概要

PR94 で `mark-generated` スキルが導入されたが、対応するファイル種別は `*.md` / `*.py` / `*.sh` / `*.yaml` のみ。
ui-kit のテンプレ群（`uidev.js` / `uidev.css` / `example.html` / `mock-skeleton.html`）は当時の対応外として遡及スタンプから除外されていた。

本 PR でこれらの記法を `mark-generated` に追加し、ui-kit のテンプレ全体を遡及スタンプ対象に含める。

### PR94 で決まった前提

- 出自メタデータコメントは YAML frontmatter の直後（frontmatter がない場合はファイル最上部）に挿入する
- `mark-generated/SKILL.md` の Step3 にファイル種別と記法のテーブルがある
- 遡及スクリプトの正規表現は「ドキュメント内のコードブロックの例示」を誤って削除するリスクがある（PR94 incidents 参照）

### 想定する記法

| 拡張子 | 記法 |
|---|---|
| `*.html` | `<!-- Generated by {plugin}/{skill} v{version} -->` |
| `*.js` | `// Generated by {plugin}/{skill} v{version}` |
| `*.css` | `/* Generated by {plugin}/{skill} v{version} */` |
