# スキル名プレフィックス統一

> ブランチ: `fix/skill-name-prefix-unification`

## 概要

`dev-kit`・`work`・`ref-inject` の各プラグインで `plugin-config` / `plugin-migrate` という裸のスキル名が使われており、同一環境にインストールされた場合に名前衝突が起きる。各スキルの `name` フィールドにプラグインプレフィックス（`{plugin}:`）を付与して命名規則を統一する。

ISSUE-032（dev-kit のみ）と ISSUE-033（複数プラグイン横断）をまとめて対応する。
