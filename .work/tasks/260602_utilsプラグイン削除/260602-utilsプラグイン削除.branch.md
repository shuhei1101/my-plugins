# utilsプラグイン削除

> ブランチ: `refactor/remove-utils-plugin`

## 概要

### 実施条件

即時実施可

### 背景・目的

`utils` プラグインは `jp-mirror-sync` スキル・`jp-mirror-translator` エージェント・`plugin-migrate` スキルを保持していたが、いずれも `claude-kit` に同等物が既に存在する（またはより適切な配置先）。プラグインを一本化してメンテナンスコストを下げる。

### 変更方針

- `utils/skills/jp-mirror-sync` を `claude-kit/skills/jp-mirror-sync` へ移動（サブエージェント参照を `utils:` → `claude-kit:` に書き換え）
- `utils` プラグイン全体を削除
- `marketplace.json` から `utils` エントリを削除
- `claude-kit` の `plugin.json` バージョンを bump
