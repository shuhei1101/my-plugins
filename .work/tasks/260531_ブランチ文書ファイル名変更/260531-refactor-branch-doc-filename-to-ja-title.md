# ブランチ文書ファイル名を日本語タイトル基準に変更

> 内部 ID: 244（index.yaml 採番用 — クロスリファレンス目的）

## 概要

ブランチ文書のファイル名を `{YYMMDD}-{branch-hyphenated}.md` から `{YYMMDD}-{日本語タイトル}.md` に変更する。
合わせて文書内にブランチ名行を追加し、`index.yaml` に `branch` フィールドを追加して PR 表記をブランチ表記に統一する。
