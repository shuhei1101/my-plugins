# work-kitスキル群ノートの現行化

> ブランチ: `docs/work-kit-skills-note-refresh`

## 概要

`.work/notes/スキル設計/work-kitスキル群.md` の冒頭「スキル一覧」表が陳腐化しているため現行化する。

### 背景（前ブランチからの引き継ぎ）

- 前ブランチ `refactor/branch-doc-ext-to-task`（v2.69.0）で、タスクドキュメント拡張子の `.task.md`
  化・用語統一（ブランチドキュメント→タスクドキュメント）・`work:quick-task` 新設を実施した。
- その際、当該ノートには現行仕様セクション（拡張子/用語/quick-task）と変更履歴は追記したが、
  **冒頭の「スキル一覧」表は旧名・旧仕様のまま残した**（スコープ外として保留）。
- 現状の問題: スキル一覧表が `work-start` / `merge` / `update` / `work-add` など**旧名**で、
  `TODO.md` / `QA.md` 作成など**旧仕様**を記述。`work:quick-task` や issue-* 系・`impl-review` ・
  `conversation-to-claude` ・`plugin-config` ・`plugin-migrate` など**現行スキルが未掲載**。
- ノートは references のノート規約上「現在のスナップショット仕様」であるべきで、旧名表は誤誘導になる。

### あるべき姿

- スキル一覧表を現行 18 スキル（`CLAUDE.md` の Skills 表と一致）に更新する。
- 旧名・旧仕様（TODO.md/QA.md 等）の記述を削除し、現行の名前・目的に揃える。
- 変更履歴（## 変更履歴）に 1 行追記する。

### 実施条件

即時実施可
