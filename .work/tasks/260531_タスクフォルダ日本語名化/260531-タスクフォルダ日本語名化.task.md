# タスクフォルダ日本語名化

> ブランチ: `refactor/task-folder-ja-naming`

## 概要

`.work/tasks/` のタスクフォルダ名（現状 `{YYMMDD}_{english-kebab-title}`）を日本語名へ変更し、視認性を上げる。

### このブランチが必要な理由・前ブランチとの関係

- 前ブランチ `refactor/work-templates-to-ref-inject`（v2.55.0）で、ブランチ**ドキュメントのファイル名**は `{YYMMDD}-{H1日本語タイトル}.branch.md` 形式へ移行済み（236件）。一方、**タスクフォルダ名**は依然 `{YYMMDD}_{english-kebab}` のまま。本ブランチでフォルダ名を日本語化する。
- **重要（スコープ修正）**: 当初候補の概要は「`setup-task.py` の生成ロジックを修正」だったが、前ブランチで **`setup-task.py` は廃止済み**。フォルダ名は `work:start` SKILL Step 5 で Claude が決定する（スクリプトなし）。したがって本ブランチの対象は次の3点:
  1. 既存タスクフォルダのリネーム（英語kebab → 日本語）
  2. `work:start` SKILL.md/.jp.md Step 5 の「新規フォルダは `YYMMDD_title`（kebab）」という記述を日本語名方針へ更新
  3. `references/work-dir/ワークディレクトリ構成.md`(+jp) / `タスクドキュメント.md`(+jp) のフォルダ名記述を日本語名に追従
- index.yaml / index.archive.yaml の `task:` フィールド（フォルダ名参照）もリネームに追従が必要。

### 実施条件

即時実施可（前ブランチ `refactor/work-templates-to-ref-inject` はマージ済み）

## QA

### QA-001: 既存フォルダのリネーム範囲

**背景**: `.work/tasks/` には 200 超のタスクフォルダがある。全部を日本語名へリネームすると大量の git mv になる（前ブランチのドキュメント236件移行と同様の規模）。

| # | 案 | 内容 |
|---|---|---|
| 1 | A | 既存フォルダ全部を日本語名へリネーム（完全移行） |
| 2 | B | 今後作成分のみ日本語名（既存は据え置き） |
| 3 | C | 仕組み（work:start の Step 5 を日本語名方針に）だけ整え、既存リネームは plugin-migrate に委ねる |

**推奨方式**: 着手時にユーザーへ確認（前ブランチでは「完全移行（案C相当）」が選ばれた経緯あり）

**状態**: 解決済み

**決定**: **案A（既存フォルダ全件を日本語名へ完全移行）** ＋ **仕組み整備**を実施。既存ドキュメントの H1 は大半が英語（`PR196 — ...` 形式）だったため、スラッグから直接翻訳して新フォルダ名を決定した。固有名詞（プラグイン名・スキル名・技術用語）は英字温存、動詞・一般名詞を日本語化。仕組み（`work:start` Step 5）は前ブランチでほぼ導入済みで、残りのプレースホルダ表記統一のみ実施。

**補足**: ドキュメント本体の H1 や内部ブランチ文書ファイル名の英語→日本語化は本ブランチのスコープ外（作業内容はフォルダ名＋index 追従に限定）。archive の orphan 36件（実フォルダを持たない過去エントリ）は8桁→6桁正規化のみ実施。

**決定したら反映先**: ## 作業内容（項目2の範囲）
