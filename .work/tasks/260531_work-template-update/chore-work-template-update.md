# chore/work-template-update

> 内部 ID: 226（index.yaml 採番用 — クロスリファレンス目的）

## 概要

workプラグインのタスクテンプレートファイル（`plugins/work/templates/.work/tasks/yymmdd_xxx/type-title.md`）を修正する。

修正内容:
1. テンプレートファイル名を `type-title.md` → `yymmdd-branch-name.md` に改名（実際の命名規則を反映）
2. `## 作業内容` テーブルから `対象ファイル` カラムを削除（`## 変更内容` セクションで管理するため不要）
3. テンプレート内の全テーブルに `#` 番号カラムを最左列として追加
4. `setup-task.py` のテンプレートパスと生成ファイル名（日付プレフィックス付き）を更新

### 実施条件

即時実施可
