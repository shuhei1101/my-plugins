# 会話キャプチャスキル復活

> ブランチ: `feat/revive-conversation-to-claude`

## 概要

PR181（コミット `131daa72`, 5/30）で削除された `conversation-to-claude` スキルを復活させる。
セッションの会話履歴を解析し、適切なアーティファクト（skill / rule / hook / CLAUDE.md /
incidents / glossary）を確認なしで自動生成するスキル。「用語辞書 = glossary」「インシデント記録 =
incidents」がこのスキルの中核機能。

旧版は claude-kit に置かれていたが、今回は **work プラグイン**に配置する（merge スキルが work に
あり、旧 notes-to-claude も workspace=work にあったため自然な配置）。

復活と同時に、過去に問題だった **glossary / incidents の登録基準を見直す**。
旧版は「CLAUDE.md に既に書いてある」「フォルダ構成を見ればわかる」「既にルールに書いてある」
ような低価値の項目まで登録してしまっていた。これらを除外する明確な基準を盛り込む。

### QA-001: work → claude-kit のプラグイン間依存

**背景**: conversation-to-claude は Step3 で claude-kit の creator スキル（skill/rule/hook/claude-creator）に委譲する。
スキルを work に置くと「work → claude-kit」のプラグイン間依存が生じる。work v2.48.0 では、まさにこの
種の依存を理由に notes-to-claude を削除した経緯がある。

| # | 案 | 内容 |
|---|---|---|
| 1 | A | 依存を許容して work に置く（ユーザー指定どおり） |
| 2 | B | claude-kit に戻す |

**推奨方式**: A。ユーザーが work 配置を明示指定。claude-kit は同一マーケットプレイス内の前提プラグインであり、依存は実用上許容範囲。

**状態**: 解決（ユーザー指定により A）
