# イシュー形式刷新

> ブランチ: feat/issue-format-redesign

## 概要

イシューファイル（`.work/issues/ISSUE-{N}.md`）の形式を刷新する。フロントマターを廃止し、
上半分=AI記入欄・下半分=`# ユーザー回答欄`（`## 意思` / `## QA` / `## 自由記述`）の2分割に。
`## 修正案`→`## 対応案` に改名し、`問題点/詳細` セクションを廃止。`status` / `branches` を
`_index.yaml` へ移管。依存スキル・エージェント・索引・ドキュメントを全面追従させる。

### 実施条件

即時実施可
