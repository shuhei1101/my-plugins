# リファレンスファイルのフロントマター形式移行

## 目的

dev-kit のリファレンス自動注入を「中央マップ（`_injection_rules.yaml` / `_index.yaml`）方式」から
「各リファレンスファイルが自分のトリガーをフロントマターで宣言する方式」へ移行する。
あわせて構造を `hooks/ref-inject/` に集約し、フロントマター仕様を簡素化し、
`~/.claude/rules` のルールを取り込む。

## 確定仕様

- 構造: `hooks/ref-inject/`（`main.py` + `references/` + 実行時生成の `cache.yaml`）
- フロントマター:
  - `paths`: glob 配列。ダブルクォート省略可。インラインスカラー `paths: "**/foo"` も可
  - `required`: 単一の真偽値（既定 true）。false ならマッチしても注入しない（optional 廃止）
  - `tools`: 既定 `[Edit, Write]`。`e/w/r`・`edit/write/read`・大小文字を吸収
- 出力: `hookSpecificOutput` 形式（Edit/Write=deny、Read=allow+additionalContext）、exit 0
- 二重注入は TTL トークンで防止。`MultiEdit` 参照は全廃（存在しないツール）
