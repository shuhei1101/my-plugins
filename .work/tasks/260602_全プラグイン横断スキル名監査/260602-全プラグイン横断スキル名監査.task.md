# 全プラグイン横断スキル名監査

> ブランチ: `fix/all-plugins-skill-name-audit`

## 概要

`my-plugins` 全プラグインのスキル `name` フィールドを横断チェックし、`{plugin}:{skill}` 形式のプレフィックスが付いていない違反を洗い出して修正する。

**背景**:
- `fix/skill-name-prefix-unification`（ISSUE-032・033）で dev-kit・work・ref-inject のスキルを修正
- `fix/claude-kit-skill-name-prefix-audit` で claude-kit 全10スキル（+ plugin-config のリネーム統合）を修正
- 以上2ブランチ以外のプラグインについても同ポリシー準拠状況を確認し、未修正のものがあれば一括修正する

**ポリシー**: `SKILL.md` の `name` フィールドは `{plugin-name}:{skill-name}` 形式（例: `dev-kit:plugin-config`）。プレフィックスなしは禁止。

**前ブランチで修正済みのプラグイン**: `dev-kit`、`work`、`ref-inject`、`claude-kit`
