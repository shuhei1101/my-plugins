# issue-scan ワークツリー対応

> ブランチ: `fix/issue-scan-use-worktree`

## 概要

`issue-scan` スキルのステップ 0 では `git checkout -b` でメインリポに直接スキャンブランチを作成し、
メインリポの HEAD を切り替えていた。これにより作業中のメインリポが scan ブランチに移動し、
ワークツリーパターンと整合しない状態が発生していた。

スキャンブランチも `git worktree add` でワークツリーとして作成し、サブエージェントがワークツリー内の
`.work/issues/` に書き出す形に変更する。

### 実施条件

即時実施可
