# fix/merge-skill-commit-order

> 内部 ID: 238（index.yaml 採番用 — クロスリファレンス目的）

## 概要

`work:merge` の Step 10（完了報告）がターンを終了させるため、その後のストップフックが
`notify-aituber` を呼んで新ターンが開始され、Step 11（`branch-reserve` → `work:start`）の
ノートコミットが次のターンに分離している問題を修正する。

Step 11 を Step 10 より前に移動することで、全コミットがターン終了前に完了し、
ストップフック後のターンではコミットが発生しなくなる。
