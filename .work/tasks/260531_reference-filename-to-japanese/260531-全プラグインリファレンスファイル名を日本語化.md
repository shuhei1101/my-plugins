# 全プラグインリファレンスファイル名を日本語化

> ブランチ: `refactor/reference-filename-to-japanese`

## 概要

全プラグイン（claude-kit / dev-kit / ref-inject / work）の `references/` ディレクトリ配下にあるリファレンスファイルのファイル名を日本語に変更する。

- ファイル名を英語スラッグ → 日本語に変更（例: `notes-naming-rules.md` → `ノート命名規則.md`）
- `.md` / `.jp.md` 両方ともファイル名を日本語化する（中身は変えない）
- ファイル名を参照している箇所（`_index.md`・`.ref-injects/CLAUDE.md`・スキルファイル・フックプロンプト等）もあわせて更新する

### 実施条件
