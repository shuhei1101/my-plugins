# ブランチドキュメント拡張子をtaskへ変更

> ブランチ: `refactor/branch-doc-ext-to-task`

## 概要

ブランチドキュメントのファイル名拡張子を `.branch.md` から `.task.md` に変更する。
格納フォルダが `.work/tasks/` であり、リファレンス名も既に「タスクドキュメント」であるため、
`.task.md` の方が命名として整合する（現状は `tasks/` フォルダに `.branch.md` が並ぶ不整合）。

「ブランチドキュメント」という概念名（1 git ブランチ = 1 ドキュメント）はそのまま維持し、
ファイル拡張子のみを変更する。拡張子の意味を説明している文だけ表現を調整する。
