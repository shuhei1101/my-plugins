# PR170 — remove-version-sync

## 概要

PR165 で `mark-generated` スキルと全 `<!-- Generated by ... v... -->` プロバナンスマーカーを削除した。
`version-sync` スキルはこれらのマーカーを grep して古い生成物を検出する仕組みだったため、
マーカーが存在しない今は検出対象が0件になり実質的に無意味になった。このスキルを削除する。

**削除対象:**
- `plugins/claude-kit/skills/version-sync/SKILL.md` / `SKILL.jp.md`

**確認が必要:**
- 他スキルや CLAUDE.md から version-sync を参照している箇所がないか確認し、あれば除去する
- glossary に version-sync エントリがあれば「PR170 で廃止」に更新する
