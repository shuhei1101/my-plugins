# ローカルYAML開発リポジトリパターン追加

> ブランチ: `docs/local-yaml-repository-pattern`

## 概要

dev-kit の Next.js バックエンドリファレンスに、ローカル開発用 YAML リポジトリパターンを追加する。
TypeScript インターフェースでデータアクセス層を抽象化し、本番は Drizzle/Supabase、
ローカル開発時は YAML ファイルを使って同じスキーマで読み書きできる仕組みをリファレンスとして文書化する。
