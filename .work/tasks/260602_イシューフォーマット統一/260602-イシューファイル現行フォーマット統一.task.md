# イシューファイル現行フォーマット統一

> ブランチ: `chore/unify-issue-format`

## 概要

`.work/issues/` 配下の 19 件のアクティブイシュー（ISSUE-034 / 035 / 063 / 064 / 092〜097 / 122〜130）を、
`plugins/work/references/work-dir/イシュー.jp.md`（英語原文 `イシュー.md`）が定義する現行フォーマットに統一する。

旧フォーマット（v2.60.0 で導入された YAML フロントマター + `## 問題` / `## 修正案` / `## 水平展開`、
ユーザー回答欄なし）から、現行フォーマット（フロントマターなし、`## 概要` / `## 背景` / `## 現状` /
`## 期待される状態` / `## 対応案` / `## 横展開` / `## 関連ドキュメント` + 末尾の `# ユーザー回答欄`
［`## 意思` / `## QA`］）へ変換する。

全イシューは未レビュー（旧 `decision: pending`）のため、`## 意思` の `**回答**:` は全候補
（対応する / 対応しない）を残す。複数の対応案を持つイシューには `## QA` に `### QA-1` を立てて
どの案で進めるかを問う。

### 実施条件

即時実施可
