# PR36 — fix-upgrade-skip-removed-plugins

## 概要

`upgrade` コマンドで、マーケットプレイスから削除・リネームされたプラグインが
インストール済みの場合に "Plugin not found" エラーで停止する問題を修正する。

修正方針:
- マーケットプレイスキャッシュの利用可能プラグインと照合する
- 削除済み（利用可能リストにないもの）は `uninstall` する
- 存在するものだけ `update` する
- リネームされた新名称の自動インストールはしない（ユーザーが手動でインストールする）
