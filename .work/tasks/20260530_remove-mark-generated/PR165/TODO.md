# PR165 — remove-mark-generated

## 概要

mark-generated スキル（`plugins/claude-kit/skills/mark-generated/`）を削除し、それを呼び出している全 SKILL.md の「Required: Stamp」セクションも除去する。また、リポジトリ内の全ファイルから `<!-- Generated by ... v... -->` / `# Generated by ... v...` 形式のバージョンマーカーを削除する（JP ミラー警告コメントは保持）。

### 実施条件
