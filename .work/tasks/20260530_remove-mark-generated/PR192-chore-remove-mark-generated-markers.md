# PR192 — remove-mark-generated-markers

## 概要

`mark-generated` スキル本体は claude-kit v3.34.0（PR165）で削除済みだが、
生成済みテンプレート・スキル・リファレンスに `<!-- Generated by ... -->` 系の
出自スタンプ（マーカー）が残っており、新規ファイル生成時の手本として誤って踏襲される可能性がある。
本 PR でリポジトリ内に残るレガシーマーカーをすべて削除し、ルール文中の `/claude-kit:mark-generated`
への参照も除去する。

ref-inject の `Generated by ref-inject/apply` コメントは注入機構そのものの実装なので残置する。

### 実施条件

即時実施可
