# イシュースキャナーコンテンツ返却リファクタ

> ブランチ: `refactor/issue-scanner-return-content`

## 概要

`issue-scanner` サブエージェントが ISSUE ファイルをディスクに書くのではなく、イシュー内容（本文 Markdown）を JSON で返却し、メインエージェント（`issue-scan` スキル）がファイル書き込み・ID 連番付与・index 更新をすべて担う設計に変更する。

これにより、サブエージェントは「コードを調べてイシューを見つける」ことだけに専念できる。また SLOT ブロックによる ID ギャップがなくなり、ID が真の連番になる。

### 実施条件

即時実施可
