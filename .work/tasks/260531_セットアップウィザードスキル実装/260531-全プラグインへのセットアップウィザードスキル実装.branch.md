# 全プラグインへのセットアップウィザードスキル実装

> ブランチ: feat/setup-wizard-skill

## 概要

`plugins/claude-kit/references/plugin/セットアップウィザード.md`（旧 `setup-wizard.md`）で必須化された `setup-wizard` スキルを、既存4プラグイン（work / dev-kit / claude-kit / ref-inject）に追加する。

参照先リファレンスは `260530_add-setup-wizard-reference` ブランチで整備済み。本ブランチはその実装フェーズにあたる。

各プラグインで行う共通作業:
- `skills/setup-wizard/SKILL.md` + `SKILL.jp.md` を新規作成
- `hooks/hooks.json` に `SessionStart` エントリを追加
- `hooks/scripts/setup_check.py` を実装（`.claude/{plugin}.local.md` の `setup_done` フラグを読む）
- `plugin.json` のバージョンを MINOR バンプ（新スキル追加）
- `marketplace.json` の対応エントリを同期

追加で:
- `claude-kit:plugin-creator` スキルの手順書に「setup-wizard を生成する」ステップを追加
- `ref-inject:plugin-migrate` チェックリストに `setup-wizard` 実装確認を追加

### 実施条件

即時実施可
