# マージ Step 12 — 次 PR 一覧の出力フォーマット

## 概要

merge スキルの Step 12 で提示する「次に取り組めるPR」一覧の設計メモ。
PR99 でステータス分類（着手可能・進行中・条件あり）が追加され、PR107 で出力形式をテーブルに変更した。

## フォーマット仕様（PR107以降）

3列テーブル形式:

| 分類 | PR番号 | 概要 |
|---|---|---|
| 着手可能 | PR{N} | タイトル（ブランチ: {branch}） |
|  | PR{M} | タイトル（ブランチ: {branch}） |
| 他セッション進行中 | PR{N} | タイトル（{commit_count}コミット先行） |
| 条件あり | PR{N} | タイトル — 実施条件: 「{依存先}」完了後 |

- 同一分類の2行目以降は分類セルを空欄にする
- 該当が0件の分類はその行ごと省略する
- 3分類すべて0件なら「他に予約済みPRはありません」と1行表示する
