# 用語集・インシデント選別復元 — .claude/rules/ コンテンツの再構築

## 概要

PR181（コミット `131daa72`）で削除された、このリポジトリ自身の `.claude/rules/core/glossary.md`（75語）と
`incidents.md`（48件）＋詳細ファイル群を、現行基準で**選別して**復元した
（`feat/glossary-incidents-content-restore`）。全件復元はしていない。

> `.claude/rules/` の path-match ルール（link/context 型）は PR203 で各プラグインの `references/` へ
> 移行・削除済み（`ルール廃止とリファレンス移行.md` 参照）。一方、常時ロードの glossary / incidents は
> 現行設計でも `.claude/rules/` が正しい配置（conversation-to-claude スキルと
> `work/references/conversation/{グロッサリー,インシデント}.md` がこのパスを対象に注入する）。両者は別物で矛盾しない。

## 採用基準

前ブランチ `feat/revive-conversation-to-claude` で新設した
`plugins/work/references/conversation/グロッサリー.md` / `インシデント.md` に従う。

- **glossary**: プロジェクト固有 + 名前から非自明 + 反復 + CLAUDE.md / skill description / フォルダ構成に
  既出でない、の全条件（QA-002 = strict A「現在も使われている用語のみ・少数精鋭」）。
- **incidents**: 実際に起きた**作業プロセスのミス**（コードバグは対象外）+ 一般化可能 +
  既存ルール / CLAUDE.md / フック / 既存 incident で未強制、の全条件。
- 孤立 incident 8ファイル（4件）は QA-001 = strict A「有効分のみインデックス化・無効分は削除」。

## glossary 復元結果（75語 → 4語）

旧75語の大半が陳腐化（`workspace`→`work` / `WORK_KIT_*`・`WORKSPACE_*`→`WORK_*` / py・next・html-kit→dev-kit
統合 / provenance・mark-generated・version-sync・creator-dispatch・session-kit 廃止 / PR→branch 改名 等）
していたか、CLAUDE.md・skill description・references に既出だったため大幅に削減。

復元: `incidents` / `glossary` / `JP ミラー` / `ref-inject` の4語のみ。

## incidents 復元結果（48 + 孤立4 → 23件）

履歴48件から19件を復元、孤立4件のうち3件を継続、1件（`mark-generated-markers-not-swept-on-removal`、
provenance 廃止により陳腐化）を削除。計23件。

### 除外した主な分類

| # | 分類 | 例 |
|---|---|---|
| 1 | 現行ルール/フック/CLAUDE.md で強制済み | master 直編集→merge conflict、merge 自動実行、work-start スキップ |
| 2 | jp-mirror 系（jp-mirror-translator + CLAUDE.md 規約 + frontmatter reference で対応済み） | claude-md/hook-prompts/incidents-glossary jp-mirror missing、frontmatter 配置、core-rules 言語 |
| 3 | 陳腐化したツール | creator-dispatch 関連、session-kit、mark-generated、provenance |
| 4 | 単なるコードバグ（プロセスミスでない） | statusline quote nesting |

### 復元した23件の所在

- インデックス: `.claude/rules/incidents.md`（+ `.jp.md`）
- 詳細: `.claude/references/incidents/{slug}.md`（+ `.jp.md`）
