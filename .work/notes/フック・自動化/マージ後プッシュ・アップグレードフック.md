# マージ後プッシュ・アップグレードフック — masterマージ後の自動push+upgrade

## 概要

masterへのgit mergeが完了したタイミングで、自動的に `git push` と `python tools/marketplace.py upgrade` を実行するClaude Codeフック。

## 設定ファイル

| No | ファイル | 役割 |
|---|---|---|
| 1 | `.claude/settings.json` | `PostToolUse(Bash)` フックエントリ |
| 2 | `.claude/hooks/post-merge-push-upgrade.sh` | 実行スクリプト |

## 動作仕様

- **トリガー**: `PostToolUse(Bash)` — Bashツールでコマンドが実行された後
- **発火条件**:
  1. 実行されたコマンドに `git merge` が含まれる
  2. 現在のブランチが `master`
- **実行内容**: `git push && python tools/marketplace.py upgrade`

## スクリプト設計

stdinからPostToolUse JSONを受け取り、`tool_input.command` フィールドを参照して `git merge` パターンを検知する。masterブランチでのみ動作する。
