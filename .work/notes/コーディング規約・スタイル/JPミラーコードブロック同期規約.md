# JPミラーコードブロック同期規約 — コードブロック内容は英語ソースと完全一致を維持する

## 概要

`plugins/dev-kit/references/python/` 配下の `.jp.md` ファイルは英語ソースの日本語ミラー。
散文（説明文）は翻訳してよいが、**コードブロック内のコードは英語ソースと完全一致**を維持する必要がある。

## 同期ルール

### コードブロック（``` ``` ```）

- コード・設定値・シェルコマンドはそのまま保持（変更不可）
- ブロック内の空行は英語ソースと同じ数・位置に揃える
- `# ===...===` などのセクション区切りコメントの前には英語ソースと同じだけ空行を入れる

### ディレクトリツリーブロック（`\`\`\`` 言語指定なし）

- ツリー構造はそのまま保持
- インラインコメント（`# ...`）は日本語に翻訳してよい（翻訳済みの場合は翻訳を保持する）

### 散文セクション

- 自由に翻訳可。空行・見出し構造は英語ソースに揃えることが望ましいが、必須ではない

## 修正スクリプト

`fix_blank_lines_only.py` を使うことで、コードブロック内空行を安全に同期できる。

```
python fix_blank_lines_only.py <references/python のパス>
```

**動作**: 英語ソースとJPミラーのコードブロックを比較し、非空行が完全一致する場合のみ空行を同期する。非空行が異なる場合（翻訳済みコメントを含む）はスキップする。

## 対象ファイル

`plugins/dev-kit/references/python/**/*.jp.md`（全サブフォルダ）
