# マークダウンテーブル規約 — Noカラムと繰り返し値の記法

## 概要

dev-kit プラグインのマークダウンテーブルリファレンス (`references/markdown/マークダウンテーブル.md`) が定める表記規約のメモ。

## Noカラム

テーブルの最左カラムには `No` カラムを設けて連番を振る。目的は **会話中に行を口頭で参照しやすくすること**（「3番のやつを修正して」等）。

### カラム名

カラム名は `No`（`#` は英語圏的で日本人に直感的でない）。

### 省略条件

左端カラムがすでに**短くて口頭で言える主キー**になっている場合は省略可。

| 省略できる例 | 理由 |
|---|---|
| 選択肢 A / B / C のテーブル | `A` `B` `C` を直接口頭で言える |
| 単一文字の識別子列 | 識別子で十分参照できる |

| 省略すべきでない例 | 理由 |
|---|---|
| 左端がファイルパスのテーブル | パスを口頭で言いにくい |
| 左端が長い説明文のテーブル | 参照しにくい |

## 繰り返し値

連続する行で同じ値が続く場合、2行目以降は `〃`（ダイトーマーク）で省略する。`No` カラムは例外（常に通し番号）。
