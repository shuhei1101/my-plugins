# スキル名プレフィックスポリシー — SKILL.md の name フィールド命名規則

## 概要

各プラグインのスキルに付与する `name` フィールドは、`{plugin}:{skill}` 形式のプレフィックス付き識別子でなければならない。

## ルール

SKILL.md の frontmatter `name` フィールドは **必ずプラグインプレフィックスを付与**する。

```yaml
---
name: dev-kit:plugin-config   # ✅ 正しい
name: plugin-config            # ❌ 禁止 — 他プラグインと衝突する
---
```

### 形式

```
{plugin-name}:{skill-name}
```

- `plugin-name`: プラグインディレクトリ名（例: `dev-kit`, `work`, `ref-inject`, `claude-kit`）
- `skill-name`: スキルディレクトリ名（例: `plugin-config`, `plugin-migrate`）

## 背景

`plugin-config` / `plugin-migrate` というスキル名が複数プラグインで重複して使われており、
同一の Claude Code 環境にインストールされた場合に名前衝突が生じるリスクがあった
（ISSUE-032、ISSUE-033）。プレフィックス付与で解消した。

## 適用範囲

このルールは `my-plugins` リポジトリ内の全プラグインに適用する。
`claude-kit:config` のように既にプレフィックスが付いているスキルは対象外（変更不要）。
