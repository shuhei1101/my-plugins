# 会話キャプチャスキル — work:conversation-to-claude

## 概要

`work:conversation-to-claude` は、現在のセッションの会話履歴を解析し、永続化すべき知識・手順を
適切な Claude Code アーティファクト（skill / rule / hook / CLAUDE.md / incidents / glossary）
として確認なしで自動生成するスキル。

元は claude-kit プラグインにあったが PR181 で削除された。`feat/revive-conversation-to-claude` で
**work プラグインに復活**させた（merge スキルが work にあり、旧 notes-to-claude も workspace=work に
あったため自然な配置）。

## 配置

- スキル: `plugins/work/skills/conversation-to-claude/SKILL.md`（+ `.jp.md`）
- 起動: `/work:conversation-to-claude`、または「会話をキャプチャして」「今の作業を保存して」等

## ステップ構成

| # | ステップ | 内容 |
|---|---|---|
| 1 | 会話履歴を解析 | カテゴリ A〜F の候補を抽出。skill/rule/hook/CLAUDE.md は広めに、incidents/glossary は厳格基準 |
| 2 | 重複排除（真実の源チェック） | 既存 CLAUDE.md・ルール・既存エントリと照合し、重複・自明なものを破棄 |
| 3 | 実装 | incidents/glossary は直接処理。skill/rule/hook/CLAUDE.md は claude-kit creator スキルに委譲 |
| 4 | 検証 | 出力ファイルを確認、incidents/glossary を重複基準で再チェック |
| 5 | コミット・報告 | |

## glossary / incidents の登録基準（旧版からの改善点）

旧版は「CLAUDE.md に既出」「フォルダ構成を見れば自明」「既にルールにある」ような低価値エントリを
大量登録する問題があった。復活版では採用基準を厳格化:

- **glossary**: プロジェクト固有 + 意味が名前から非自明 + 繰り返し出る + CLAUDE.md / ルール /
  スキル description / フォルダ構成に既出でない、の全条件を満たす場合のみ登録。
- **incidents**: このセッションで実際にミスが起きた + 教訓が一般化できる + 既存のルール /
  CLAUDE.md / フック / 既存 incident で強制済みでない、の全条件を満たす場合のみ記録。
- どちらも迷ったら**破棄**。Step 2 で能動的に grep して重複チェックする。

この採用基準とファイル形式は work リファレンスにも切り出してある（SKILL.md 内の記述と二重持ちだが、
編集時の自動注入のため）。`references/conversation/グロッサリー.md` と
`references/conversation/インシデント.md` が、対象プロジェクトで `.claude/rules/glossary.md` /
`.claude/rules/incidents.md` / `.claude/references/incidents/**` を編集したときに ref-inject で注入される。

## creator スキルへの委譲

Step 3 で skill/rule/hook/CLAUDE.md はサブエージェント（`isolation: "worktree"` で並列）が
claude-kit の creator スキルに委譲する。委譲は**スラッシュコマンド形式**（`/claude-kit:skill-creator`
等）で行う。旧版はリポジトリ固有パス（`plugins/claude-kit/...`）を参照しており install 先で壊れたため。

> プラグイン間依存（work → claude-kit）について: プラグイン規約「Zero inter-plugin dependency
> principle」では禁止依存に当たる（work v2.48.0 で notes-to-claude を同理由で削除した経緯あり）。
> 今回はユーザーの明示指定により work 配置を採用。claude-kit 未インストール時はサブエージェントが
> アーティファクトを直接作成する（ref-inject フックが認可ガイドを自動注入）フォールバックを持つ。

## 自動実行の入口

スキルは2つの経路で自動起動される（手動 `/work:conversation-to-claude` も可）:

- **PreCompact フック** — `/compact` の直前に実行。詳細は `フック・自動化/PreCompactフック.md`。
  トグル `WORK_PRECOMPACT_CONV2CLAUDE`。
- **merge スキル Step 4** — `work:merge` がワークツリー内で実行し、生成物をブランチに含める。
  トグル `WORK_MERGE_CONV2CLAUDE`。
