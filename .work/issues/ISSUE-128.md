# ISSUE-128: プラグイン設定.md のセクションタイトルが本文の条件と矛盾している

**作成日**: 2026-05-31

## 概要

`references/plugin/プラグイン設定.md` のセクションタイトルが「すべてのプラグイン」に config スキルが必要と読めるが、本文は「env トグルを持つプラグインのみ」を対象としており、タイトルと本文が矛盾している。

## 背景

`references/plugin/プラグイン構造.md` の「Required skills」セクションも `plugin-config` を「mandatory for plugins with env vars」と明示しており、対象は env トグルを持つプラグインに限定される。

## 現状

`プラグイン設定.md` 行 12 のセクションタイトル:

```
## Why every plugin needs a config skill
```

しかし行 27 の本文:

```
Add a config skill when the plugin has one or more env toggles the user is expected to change.
```

とあり、「すべてのプラグイン」ではなく「env トグルを持つプラグインのみ」が対象である。また JP ミラー（`プラグイン設定.jp.md`）行 13 のタイトルも「なぜすべてのプラグインに config スキルが必要か」と誤訳された状態で記述されている。

## 期待される状態

セクションタイトルが本文の条件（env トグルを持つプラグインのみ）と一致し、JP ミラーのタイトルも合わせて修正されている。

## 対応案

セクションタイトルを条件を反映した内容に修正する。例：

```
## Why plugins with env toggles need a config skill
```

JP ミラーも合わせて修正：

```
## env トグルを持つプラグインに config スキルが必要な理由
```

## 横展開

セクションタイトルと本文の条件が乖離するパターン。他のリファレンスでもタイトルが本文より広い断定になっていないか確認すると良い。
