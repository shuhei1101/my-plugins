# ISSUE-162: issue-scanner.md の JSON body サンプルが旧フォーマット（ユーザー回答欄が先頭・様子見選択肢あり）

**作成日**: 2026-06-02

## 問題

`plugins/work/agents/issue-scanner.md` の Step 5「Return findings as JSON」セクションにある JSON サンプルの `body` 文字列が、v2.71.0 で変更された現行フォーマットと一致していない。

### 問題 1: 構造が旧順序

`body` 内の `# ユーザー回答欄` が先頭にあり、`## 概要` / `## 現状` / `## 対応案` がその後に続く旧順序になっている。現行（v2.71.0 以降）は AI 本文が先・`# ユーザー回答欄` が `---` の後の末尾。

### 問題 2: `様子見` 選択肢が存在

サンプルの `**回答**: 対応する / 対応しない / 様子見` に `様子見` が含まれているが、`イシュー.md` テンプレートの `## 意思` は `対応する / 対応しない` の 2 択のみ。

同 agent の Step 4 Markdown テンプレートは正しいフォーマットを示しているため、Step 4 テンプレートと Step 5 JSON サンプルが矛盾している状態。

## 対応方針

JSON サンプル（Step 5）の `body` を Step 4 テンプレートおよび `イシュー.md` の現行フォーマットに合わせて修正する：
- `**作成日**` → `## 概要` → ... → `---` → `# ユーザー回答欄` → `## 意思` → `**回答**: 対応する / 対応しない`（`様子見` を削除）

## 対象ファイル

- `plugins/work/agents/issue-scanner.md`: Step 5 の JSON body サンプルを現行フォーマットに修正

# ユーザー回答欄

## 意思

**回答**: <!-- 承認 / 却下 / 保留 -->
