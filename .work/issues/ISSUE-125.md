# ISSUE-125: _index.md の全リンクがサブディレクトリパスを省略していて無効

**作成日**: 2026-05-31

## 問題
`references/_index.md`（人間向けナビゲーション文書）内の全リンクがファイル名のみで記述されており、実際のサブディレクトリパスを含んでいない。例：

- `[共通ガイド.md](共通ガイド.md)` → 実際は `common/共通ガイド.md`
- `[CLAUDE-md記述ガイド.md](CLAUDE-md記述ガイド.md)` → 実際は `claude-md/CLAUDE-md記述ガイド.md`
- `[フック.md](フック.md)` → 実際は `hook/フック.md`

`references/` 直下にこれらのファイルは存在しないため、GitHub 等のリンクレンダラーで全リンクが 404 になる。また、一部の `jinja2/テンプレート注意点.md` のみは `jinja2/テンプレート注意点.md` と相対パスが記されているが、これも `hook/jinja2/テンプレート注意点.md` が正しい。

さらに `_index.md` は `_index.yaml`（注入システムに登録されたリファレンス一覧）と比較すると `hook/jinja2/執筆ガイド.md` と `plugin/バージョン同期.md` が掲載されておらず、インデックスが不完全でもある。

## 修正案

1. 全リンクを正確な相対パス（`common/共通ガイド.md`、`hook/フック.md` 等）に修正する。
2. `_index.yaml` に掲載されているが `_index.md` に未掲載の `hook/jinja2/執筆ガイド.md` と `plugin/バージョン同期.md` の行を追加する。
3. 存在しない `incidents.md` の行は削除（別イシュー参照）。

## 水平展開
`_index.md`（人間向け）と `_index.yaml`（システム向け）が手動で二重管理されていることが根本原因。将来的には `_index.yaml` から `_index.md` を自動生成する仕組みを検討することで乖離を防げる。
