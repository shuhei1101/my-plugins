# ISSUE-001: JP ミラーの TOML コードブロック内空行が英語ソースと不一致

**作成日**: 2026-05-31

## 問題

英語ソース (pyproject設定.md) の TOML コードブロックは各セクション区切り（# ================================================================）の前に2行の空行があるが、JP ミラーは1行のみ。コードブロックの内容が完全に同期されていない。

## 水平展開

同プラグイン内の他の JP ミラーファイルでも同様のコードブロック同期ずれが潜在している可能性がある。dev-kit/references/python/ 配下の `.jp.md` を横断チェック推奨。

## 修正案

pyproject設定.jp.md のコードブロック内、各セクション区切りの前の空行を2行に統一する。
