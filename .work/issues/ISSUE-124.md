# ISSUE-124: 環境変数.md が JP ミラーを宣言しているが 環境変数.jp.md が存在しない

**作成日**: 2026-05-31

## 概要

`references/common/環境変数.md` が JP ミラーの存在を宣言しているが、対応する `環境変数.jp.md` が存在しない。

## 背景

`リファレンス同期.md` と `共通ガイド.md` の JP/EN ミラールールによれば、すべてのリファレンスファイルには対応する JP ミラーが必要である。他の全リファレンスファイル（`共通ガイド.md`、`AskUserQuestion制約.md`、`サブエージェント.md` 等）には対応する `.jp.md` が存在する。

## 現状

`references/common/環境変数.md` の行 8 に以下の宣言がある。

```
Japanese mirror: `references/common/環境変数.jp.md`
```

しかし `references/common/環境変数.jp.md` は存在せず、`環境変数.md` だけが JP ミラーを欠いている。

## 期待される状態

`references/common/環境変数.jp.md` が作成され、`環境変数.md` と内容が一致した JP ミラーが揃っている。

## 対応案

`references/common/環境変数.jp.md` を作成する。先頭には所定の警告コメントを付け、内容は `環境変数.md` を日本語に翻訳したものとする。`jp-mirror-translator` エージェント（`subagent_type: "claude-kit:jp-mirror-translator"`）を使用して生成可能。

## 横展開

新規リファレンスファイルを追加した際の JP ミラー作成が漏れるパターン。他の新規追加ファイルでも同様の漏れが発生しやすいため、プラグイン更新時のチェックリストに「全 `.md` に対応する `.jp.md` が存在するか確認」を加えることを推奨する。
