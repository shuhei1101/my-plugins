# ISSUE-176: git-guard.py / master-commit-guard.py のトークン挙動コメントが実態と誤記

**作成日**: 2026-06-02

## 問題

`git-guard.py` のドキュメント（冒頭コメント）に「1 回ブロックしたら **2 回目以降は素通りさせる**」と書かれているが、実際のトークンロジックは「次の 1 回のみ通し、トークンを削除する」であり、その後に同じコマンドを再実行するとまた 1 回ブロックされる。コメントが実際の挙動を誤って説明している。

実際のトークンロジック：
1. コマンド検出 → トークン不在 → トークン作成 → ブロック
2. リトライ → トークン存在 → トークン削除 → 素通り
3. 次のコマンド → トークン不在（削除済み）→ 再びブロック

これは「次の 1 回のみ素通り」であり「2 回目以降は素通り」ではない。`master-commit-guard.py` にも同趣旨の誤記コメントがある。

## 対応方針

両ファイルのコメントを実際の挙動（「1 回ブロックした直後の次の 1 回のみ素通りし、その後はまたブロックする」）に修正する。

## 対象ファイル

- `plugins/work/hooks/scripts/git-guard.py`: 冒頭コメントを修正
- `plugins/work/hooks/scripts/master-commit-guard.py`: 同趣旨コメントを修正
