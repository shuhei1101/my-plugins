# Incident: mark-generated Markers Not Swept on Skill Removal

## Summary

When the `mark-generated` skill was deprecated and removed in claude-kit v3.34.0 (PR165),
the physical `<!-- Generated by ... -->` / `# Generated by ...` comment markers it had previously
stamped were not swept from the repository. They persisted for one or more sessions, causing
confusion when ref-inject's own injection comment was mistaken for a mark-generated artifact.
A follow-up PR (PR192) was required to remove all stale markers.

## What Happened

- **PR165** (claude-kit v3.34.0): deleted the `mark-generated` skill and `references/provenance.md`.
- The skill's _output_ (comment markers in template files, hook `.py` files, SKILL.md files,
  injection `.j2` templates) was not cleaned up at that time.
- In a later session, a ref-inject injection comment (`<!-- Generated by ref-inject/apply ... -->`)
  triggered confusion — the user initially thought the injection mechanism itself was the old marker
  system. Investigation revealed many files still had stale `Generated by` comments.
- **PR192** swept all remaining markers: `uidev.css`, `uidev.js`, `example.html`,
  `mock-skeleton.html`, `ts_check.py`, `workspace/config/SKILL.md+jp.md`, `naming.md+jp.md`,
  and all `inject_references.py` / `injection.*.j2` files for claude-kit, dev-kit, and ref-inject.

## Root Cause

The removal PR (PR165) focused on deleting the skill code and its references, but did not include a
grep sweep for all files that already had markers applied.

## Correct Approach

When removing a code-generation system (skill, hook, script, etc.) that stamps output files:

1. Search for all output artifacts it produced (grep for its stamp pattern).
2. Include the sweep **in the same PR** as the removal, or create an explicit follow-up task.
3. Confirm the sweep with `grep -r "Generated by <system>" --include="*.md" --include="*.py" ...`
   before closing the PR.

## Prevention

- When removing a tool that generates markers, always grep for the marker pattern first.
- Checklist item for removal PRs: "sweep and delete all outputs this tool produced."
