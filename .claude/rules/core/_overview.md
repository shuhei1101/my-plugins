# core — プロジェクト全体の基盤ルール

## About this folder

プロジェクト全体に適用される基盤的なルール群。特定の機能に依存せず、すべての作業に共通する規約・用語・ワークフロー・インシデント記録を管理する。

## File list

| File | Content |
|---|---|
| `glossary.md` | プロジェクト固有の用語定義 |
| `incidents.md` | 再発防止ログ（インデックス + references/ への詳細リンク） |
| `plugin-work.md` | plugins/** 配下の制作ルール（フック・ルール・スキル・CLAUDE.md の作成指針） |
