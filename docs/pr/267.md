# inject_rules: ルール本文の直接注入をMCPツール参照方式へ変更

## 概要

Claude Code で作業する開発者・エージェントが、編集対象にマッチしたルールを、本文の丸ごと注入ではなく MCP ツール経由の取得で読めるようになる。
フックが注入するのは読み込みの案内文言だけになり、案内の対象はまだ読んでいないルールに限られる。

## 背景

現行のルール注入は 1 回あたりの注入上限（10000 トークン）に収めるためルール本文を分割して注入しており、上限を超えるルールではツール呼び出しの差し戻しと再実行を繰り返して全量を流し込んでいる。
マッチするたびに本文の全量がコンテキストへ載るため、既に読んだルールでも同じ内容を繰り返し読み込むことになり効率が悪い（Issue #263）。

## 単一ユースケース

| 変更種別 | 単一ユースケース | 概要 | 対応 story | 補足 |
| --- | --- | --- | --- | --- |
| 変更 | [ルール注入](https://github.com/shuhei1101/my-plugins/blob/master/docs/wiki/設計図/シナリオ/単一ユースケース/ルール注入.md) | 編集対象にマッチしたルールの読み込み案内をコンテキストへ取り込む | 未作成 | 本文の直接注入と分割注入を廃止し、案内の対象を未読のルールに限る |
| 新規 | ルール本文の取得 | 案内されたルールの本文を MCP ツールで取得し、読了として記録する | 未作成 | 複数パスの同時指定・http / ローカル両対応・`!{環境変数}` の展開を含む |
