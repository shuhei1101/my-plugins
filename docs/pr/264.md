# Python 規約に条件付き必須フィールドの判別付き Union 指針を追加

## 概要

Python コードを書く開発者・エージェントが、ある項目の値によって他項目の必須・省略可が変わるデータ構造を、判別付き Union で表せるようになる。
`docs/rules/` 配下の Python 規約に、判別子を `Literal` で持つ型に分けて `Annotated[Union[...], Field(discriminator="{判別子}")]` で束ねる指針を追加する。

## 背景

ai-monitor の代理応答の設計で、回答の種類（`select` / `reconsider` / `escalate`）ごとに必須フィールドが変わる DTO を、全フィールドを省略可にしたうえで補足列に「`select` のとき必須」と書く形で設計した。
レビューで、Pydantic の判別付き Union（`Field(discriminator=...)`）で型を分けるべきと指摘を受けた。
種類ごとに型を分ければ、必須・省略可の組み合わせを人が読んで守る必要がなくなり、バリデーションが型で効く。
現在の Python 規約にこの指針が無いため、同じ設計を別プロジェクト・別セッションでも繰り返す（Issue #262）。
