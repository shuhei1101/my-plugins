# フロントエンド テスト戦略

2 層で持つ。React Testing Library・MSW・DB は使わない

| 層           | ツール          | 見るもの                             | 配置                                      |
| ------------ | --------------- | ------------------------------------ | ----------------------------------------- |
| ユニット相当 | vitest（jsdom） | 純関数・状態・派生計算・フォーマッタ | 対象ファイルと同じ階層に `{name}.test.ts` |
| E2E          | playwright      | 画面が組み上がるか・主要操作フロー   | `frontend/tests/e2e/{name}.spec.ts`       |

- ピラミッド構造: ユニットで網羅し、E2E は重要フローだけ。E2E でユニットレベルを検証しない。
