# ビルドレス原則（バンドルしない）

- バンドラを使わない。
  - webpack / vite / esbuild などでブラウザ用にバンドル・最適化しない。
  - ネイティブ ES Modules と素の CSS をそのまま配信する。起動を軽く保つのが目的。
  - ただし TypeScript の型システムを使うため、`tsc` による `.ts` → `.js` のトランスパイル 1 段だけは許可する。
  - 開発時のツールは使ってよい。
    - 変換 `tsc -p tsconfig.build.json --watch`（`.ts` → 同階層 `.js`）
    - 型検査 `tsc -p tsconfig.json --noEmit`
    - lint `eslint`（typescript-eslint）
    - テスト `vitest` / `playwright`
