# デザイントークン

- 全デザイン値は `:root` の Custom Properties に集約する。 
  - 16 進カラー・px 値・フォントスタックをハードコードせず `var(--token)` 経由で参照する。
- 3 ティアで持つ:
  - プリミティブ 生の値（`--blue-500: oklch(...)`）
  - セマンティック 用途（`--color-bg` `--color-text` `--color-primary` `--color-border`）
  - 派生 セマンティックから生成（hover / subtle / border など）
- 派生色は `color-mix(in oklab, ...)` か相対カラー（`oklch(from var(--x) ...)`）で作る。
  - Sass の lighten/darken/rgba は使わない。
- アニメーションさせる / 型を固めるトークンは `@property` で登録する（`syntax` と `inherits` は必須）。
- ライト固定。ダークモードは対応しない（`light-dark()`・dark 変数を入れない）。
- 既存 `frontend-next/app/globals.css` の oklch セマンティックトークンを流用元にする。
