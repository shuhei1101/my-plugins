# モック画面ルール
- モックはプロジェクトルート直下にフォルダを配置し、FastAPI×バニラhtmlで構成される
- {プロジェクト}/mocks/{画面名}/{モック案A,B...}
  - {プロジェクト}/mocks/index.html


- `./mocks`ディレクトリ配下にhtmlでモックを作成する
  - もし`./mocks`が存在しない場合、作成する
- ssh経由で見ることがあるため、FastAPIで軽量サーバをmocks配下に配置して起動すること
- ポートは空いてるポートで。ただし、xx00番はメインで使うから避ける。メインで使いそうなポートは避ける
- 必ず`index.html`を配置し、各モックページへのリンクを引く
- 各モックは疎結合にすること
- モックごとにhtmlをわけること
