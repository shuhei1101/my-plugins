# スタイル

## ツール構成

| ツール    | 役割                                                 |
| --------- | ---------------------------------------------------- |
| `ruff`    | フォーマッタ + リンタ（black + isort + flake8 相当） |
| `mypy`    | 型チェック（CI / 厳格）                              |
| `pyright` | エディタ統合の高速型チェック（任意）                 |
| `pytest`  | テストランナー                                       |

## ruff 設定

```toml
[tool.ruff]
line-length = 100
target-version = "py312"

[tool.ruff.lint]
select = ["E", "F", "I", "B", "UP", "SIM", "RUF"]
ignore = ["E501"]   # 行長は formatter に任せる

[tool.ruff.format]
quote-style = "double"
indent-style = "space"
```

## mypy 設定

```toml
[tool.mypy]
python_version = "3.12"
strict = true
warn_unused_ignores = true
warn_redundant_casts = true
show_error_codes = true
pretty = true
plugins = ["pydantic.mypy"]   # Pydantic 使用時
```

pyright を使う場合は `typeCheckingMode = "strict"`。

## 書き方

- 行長 100 文字（URL・長い文字列リテラルは例外）
- ダブルクォート標準、docstring は `"""..."""`
- 長いモジュールはセクションマーカー（`# === DTO ===` 等）で区切ってよいが、セクションが必要なほど長くなったらまずファイル分割（`types.py` / `service.py`）
