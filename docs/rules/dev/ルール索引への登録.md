# ルール索引への登録

`docs/` 配下のドキュメントを新規作成・移動・リネームしたときは、inject-rules の索引（`docs/rules.yaml`）に載せるかどうかを判断する。
索引に載せたドキュメントは、`paths` の glob に一致するファイルを扱うときに本文が自動で注入される。
既存ドキュメントを編集したときも、索引に載っているかと `paths` が今の内容と合っているかを確認する。

## 載せるかの判断

- 特定のファイル種別・ディレクトリを扱うときに毎回従ってほしい規約・書式 → 載せる
- 必要になったときに取りに行く参照資料（調査メモ・一覧・議事録）→ 載せない

## 載せるときの書き方

- 索引に `rule`（索引ファイルからの相対パス）と `paths` の 1 エントリを追加する
- `paths` には「そのドキュメントに従ってほしい対象ファイル」の glob を書く
  - 対象が実装言語なら拡張子で引く（例: `**/*.py*`）
  - 対象がドキュメント種別ならそのフォルダで引く（例: `**/docs/wiki/設計図/シナリオ/**`）
- 既存エントリの `paths` と対象が重なってよい（一致したルールはすべて注入される）
- 索引が複数ある場合は、そのドキュメントを置いたリポジトリの索引に載せる
