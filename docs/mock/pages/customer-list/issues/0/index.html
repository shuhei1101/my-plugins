Issue #0: 顧客一覧の初期実装

フィルター UI の方式を 2 案出して比較した。

案 A: 左サイドフィルター

左に固定のフィルターパネルを置く案。発見性が高く、頻繁な絞り込み操作に強い。

  • 良い点: 条件が常時可視 / 多条件の同時切替がしやすい
  • 懸念点: モバイルでドロワー化が必要 / メイン幅が狭くなる

案 A を開く

案 B: フィルターモーダル

フィルターはモーダルで開閉する案。メインの情報密度を最大化できる。

  • 良い点: 一覧のメイン幅をフルに使える / モバイル対応が楽
  • 懸念点: 絞り込み状態の発見性が低い / 試行錯誤に向かない

案 B を開く

採用理由

業務での絞り込み頻度が高く、発見性と連続切替を重視した結果、案 A（左サイドフィルター）を採用。モバイル対応のドロワー化コストは許容範囲。
