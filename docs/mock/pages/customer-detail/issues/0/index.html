Issue #0: 顧客詳細の初期実装

情報量が多いため、レイアウト 2 案を比較した。

案 A: タブ切り替え

基本情報 / 関連 / 履歴 をタブで切り替える案。

  • 良い点: セクション間の認知が明確 / スクロールしなくて済む
  • 懸念点: タブ跨ぎの比較ができない

案 A を開く

案 B: 縦積み（スクロール）

全セクションを縦に積む案。

  • 良い点: 上から順に読める / 全体俯瞰がしやすい
  • 懸念点: 情報量が増えるとスクロール量が増える

案 B を開く

採用理由

関連情報のセクション数が多く、スクロールでの全体把握が現実的でないため、案 A（タブ）を採用。
