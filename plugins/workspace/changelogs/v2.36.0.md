# workspace v2.36.0

## Added

- **`merge` skill auto-closes related issues**: A new step (Step 5) reads the `## 関連イシュー` table in `TODO.md` and closes each listed issue via `scripts/issue-tool.py close` before the index archive / merge steps. Closing moves `.work/issues/ISSUE-{N}.md` to `.work/issues/closed/`, removes the entry from the local `_index.yaml`, and appends a `closed_issues` entry (with `linked_pr`) to `_index.archive.yaml`. Silent skip when `.work/issues/` is not present.
- **`scripts/issue-tool.py`**: New helper script with a `close` subcommand used by the `merge` skill. Same single-file `argparse` pattern as `index-tool.py`.
- **`work-start` skill / TODO template**: TODO.md now includes a `## 関連イシュー` section (`| ID | 概要 | resolution |`). `work-start` Step 7 documents how to fill (or remove) the section.
