# workspace v2.41.0 — 2026-05-30

## 変更内容

- **env トグル `WORKSPACE_PROTECTED_BRANCHES` を追加**: `master-commit-guard` の保護対象ブランチをカンマ区切りで上書き可能にした。デフォルトは現状維持の `master,main,develop`（未設定時は完全な後方互換）。
  - 例: `WORKSPACE_PROTECTED_BRANCHES=master` で master のみ保護
  - 例: `WORKSPACE_PROTECTED_BRANCHES=master,main,release/prod` でリリースブランチも追加
  - 空文字（`WORKSPACE_PROTECTED_BRANCHES=`）にすると全ブランチ素通り（ただし `WORKSPACE_GUARD=false` の方が意図表明として明示的）
  - 前後 strip で `master, main, develop` のようなスペース許容
- `WORKSPACE_GUARD`（PR169）が push/merge ガードの on/off だったのに対し、本 env はコミット時保護対象ブランチを細かく指定する用途。

## 変更ファイル

- `hooks/scripts/master-commit-guard.py` — `PROTECTED_BRANCHES` を env から構築するように変更
- `.claude-plugin/plugin.json` — 2.40.0 → 2.41.0、description に `WORKSPACE_PROTECTED_BRANCHES` を追記
- リポジトリ側: `.claude-plugin/marketplace.json` の workspace エントリも同期
