# workspace v2.43.0

## feat: WORKSPACE_MERGE_PROPOSAL env toggle

Added `WORKSPACE_MERGE_PROPOSAL` environment variable to control whether the Stop hook suggests running `/workspace:merge`.

### Behavior

- **Default (unset or truthy)**: Stop hook shows the full reminder including the merge suggestion (existing behavior unchanged)
- **Disabled (`false`/`0`/`no`/`off`)**: Stop hook shows only TODO/QA/notes reminders — merge suggestion is omitted

### Implementation

- Added `hooks/prompts/stop-no-merge.md` — Stop hook prompt without the merge suggestion
- Modified `hooks/hooks.json` Stop inline Python to check `WORKSPACE_MERGE_PROPOSAL` and load `stop.md` or `stop-no-merge.md` accordingly
- Updated `skills/config/SKILL.md` to include `WORKSPACE_MERGE_PROPOSAL` in the Managed Toggles table

### Configure via /workspace:config

Select `WORKSPACE_MERGE_PROPOSAL` via the "その他" free-text input in Step 2.
