# workspace:notes-to-claude — ノートを恒久知識に昇格させる

`.work/notes/` に蓄積した一時的なメモを分析し、
ルール・CLAUDE.md・references などの恒久アーティファクトに自動変換する。

---

## 概要

`.work/notes/` は「書き捨て可能な議事録・検討メモ」置き場であり、Claude Code に自動読み込みされない。
作業が蓄積してきたタイミングでこのスキルを実行し、有用な知識を永続的なファイルへ昇格させる。
昇格後のメモは自動削除する。不要なメモ（廃棄）もその場で削除する。

確認フェーズなし。作業はブランチ上で行うため、コミット内容をレビューすれば変更を確認できる。

**前提条件**: `claude-kit` プラグインがインストール済みであること（ステップ3で creator スキルを使用する）。

**`claude-refactor` との使い分け**:
- `claude-refactor` は `.claude/` の中身を監査・整理する（肥大化検出・重複解消・タイプ移管）
- `notes-to-claude` は `.work/notes/` の知識を `.claude/` へ流し込む

2つは補完関係にある: まず `notes-to-claude` で `.claude/` を充実させ、その後 `claude-refactor` で整理する。

## 作業内容

### ステップ1: ノート一覧を取得する

#### 条件

- 常に最初に実行する

#### 処理内容

1. `.work/notes/` 配下のファイルを列挙する:
   ```bash
   ls .work/notes/
   ```
2. ファイルが存在しない場合は「昇格対象のノートがありません」と報告して終了する

→ ステップ2へ進む

#### 出力

- ノートファイルの一覧

---

### ステップ2: 各ノートを分析して昇格種別を分類する

#### 条件

- ステップ1完了

#### 処理内容

各ノートを読み、参考資料の判定基準表を使って昇格種別を決定する。

| 種別 | 昇格先 | 判定基準 |
|---|---|---|
| **A — ルール** | `.claude/rules/` | ファイル依存関係「X を編集したら Y も更新」、特定ファイルを開いたときだけ必要な知識 |
| **B — CLAUDE.md** | `CLAUDE.md` | 全セッション共通の規約・禁止事項・命名規則（どのファイルを開いていても必要なもの） |
| **C — references** | `.claude/references/` | 詳細な表・設計図・長い仕様（ルールや CLAUDE.md からリンクして必要なときだけ読む） |
| **D — 廃棄** | 削除 | 一時的な比較・ボツ案・調査メモ（昇格の必要なし） |

また、既存アーティファクトと照合して増殖を防ぐ（参考資料の判定基準表を参照）:
- 同じドメインをカバーする既存ファイルがあれば → 追記（新規ファイル作成不要）
- 対応する既存ファイルがなければ → 新規作成

→ ステップ3へ進む

#### 出力

- 各ノートの昇格種別（A/B/C/D）、昇格先パス、アクション（追記 or 新規作成）

---

### ステップ3: 昇格を実施する

#### 条件

- ステップ2完了

#### 処理内容

ステップ2で決定した計画を1件ずつ実施する。対象ファイルを直接編集せず、必ず対応するクリエータースキルを経由すること。

| 種別 | 使用するスキル | 補足 |
|---|---|---|
| **A — ルール** | `/claude-kit:rule-creator` | `paths:` フロントマター・フォルダ配置・JP ミラー・リンクルールを強制 |
| **B — CLAUDE.md** | `/claude-kit:claude-creator` | 薄化原則・JP ミラー・セクション構成を強制 |
| **C — references** | （直接作成） | スキル不要。`.claude/references/{slug}.md` を直接作成する |
| **D — 廃棄** | （直接削除） | `rm .work/notes/{file}` |

ルール（種別 A）の配置フォルダは、参考資料のフォルダ構成ガイドを参照して決定する。

→ ステップ4へ進む

#### 出力

- 昇格先ファイルが作成・更新済み

---

### ステップ4: 昇格済みノートを削除する

#### 条件

- ステップ3完了

#### 処理内容

1. 昇格（種別 A / B / C）が完了したノートファイルをすべて削除する:
   ```bash
   rm .work/notes/{file}
   ```
2. 廃棄（種別 D）はステップ3で削除済みのため重複操作は不要

→ 完了

#### 出力

- 昇格・廃棄ずみのノートが `.work/notes/` から削除済み

## 参考資料

### 昇格種別の判定基準表

`claude-kit` の references（common.md / rules.md / claude-md.md）から抜粋して内包。
実行時にクロスプラグイン参照が不要なよう、ここに埋め込んでいる。

| 内容の性質 | 昇格先 | 理由 |
|---|---|---|
| 「X を編集したら Y も更新」などのファイル依存 | ルール | `paths:` マッチで対象ファイルを開いたときだけ読み込まれる |
| 特定フォルダ・ファイル種別に閉じたドメイン規約 | ルール | `paths:` を狭めることでコンテキストコストを抑える |
| 全セッション共通の禁止事項・命名規則・オンボーディング情報 | CLAUDE.md | 毎セッション必ず読まれるので全体に適用できる内容のみ |
| ユーザーが明示的に呼び出すマルチステップ手順 | スキル（`.claude/skills/`） | オンデマンド。notes-to-claude の対象外 |
| 長い表・設計図・詳細仕様（必要なときだけ参照） | `.claude/references/` | CLAUDE.md を薄く保つために外出し |
| 一時的な比較・調査メモ・ボツ案・完了済みの検討 | 廃棄 | 永続化不要 |

### 増殖防止ガード（既存アーティファクト照合）

| 種別 | 確認対象 |
|---|---|
| A — ルール | `.claude/rules/` 配下（ファイル名と冒頭20行を確認） |
| B — CLAUDE.md | プロジェクトの `CLAUDE.md`（該当セクションの有無を確認） |
| C — references | `.claude/references/` 配下（ファイル名を確認） |

### ルールフォルダ配置ガイド

| フォルダ | 使う場面 |
|---|---|
| `core/` | プロジェクト全体の規約・ワークフロー・環境設定 |
| `feature/` | 機能・ドメイン固有のルール（1機能 = 1ファイル） |
| `ui/` | フロントエンドのコンポーネント・ページルール |
| `api/` | バックエンドのルーティング・ハンドラールール |

### クリエータースキル早見表

| スキル | 強制する内容 |
|---|---|
| `/claude-kit:rule-creator` | `paths:` フロントマター・フォルダ配置・JP ミラー（`.claude/rules-jp/`） |
| `/claude-kit:claude-creator` | CLAUDE.md 薄化原則・JP ミラー・セクション構成 |
| `/claude-kit:skill-creator` | ステップ構造・`description` フロントマター・JP ミラー |
| `/claude-kit:hook-creator` | フックイベント種別・settings.json への配線・ループ防止 |

### 関連スキルの使い分け

| スキル | 起点 | 目的 |
|---|---|---|
| `workspace:notes-to-claude`（本スキル） | `.work/notes/` の一時メモ | `.claude/` に新しい知識を流し込む |
| `claude-kit:claude-refactor` | 既存の `.claude/` の中身 | 肥大化・重複・タイプミスマッチを監査・整理する |
