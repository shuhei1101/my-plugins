# dev-kit v4.8.0 — 2026-05-31

## 変更内容

- **`dev-kit:yaml` スキルと付随ファイルを削除 (PR202)**:
  YAML ファイル管理の規約（`index.yaml` / `settings.yaml` / `settings.yaml.sample` の三層パターン等）は dev-kit のスコープ外として整理。
  - スキル本体: `plugins/dev-kit/skills/yaml/` (SKILL.md + .jp.md) を削除
  - 注入リファレンス: `plugins/dev-kit/references/yaml/` (yaml.md + .jp.md) を削除
  - dispatch フック: `plugins/dev-kit/hooks/scripts/yaml_skill_dispatch.py` を削除
  - フックプロンプト: `plugins/dev-kit/hooks/prompts/yaml-skill-dispatch.{md,jp.md}` を削除
- **`hooks/hooks.json` から `yaml_skill_dispatch.py` エントリ削除 (Edit / Write の両方)**
- **`_index.yaml` / `_index.jp.yaml` から `yaml/yaml.md` エントリ削除**
- **`_injection_rules.yaml` から `**/index.yaml` / `**/settings.yaml` / `**/settings.yaml.sample` の 3 パターン削除**（これらは `yaml/yaml.md` を required としていた）
- `plugins/dev-kit/.claude-plugin/plugin.json` と `.claude-plugin/marketplace.json` の description から「YAML」を削除
- `references/python/llm/prompts-authoring.{md,jp.md}` および `references/python/shared/secrets-and-env.{md,jp.md}` の関連項目から `dev-kit:yaml` 言及を削除
