# dev-kit v4.2.0

## New: Markdown frontmatter placement check

Added a hook that warns when content appears before the opening `---` of a YAML frontmatter block.

### What's new

- `references/markdown-editing.md` (+ `markdown-editing.jp.md`) — short reference explaining the rule
- `hooks/scripts/markdown_frontmatter_check.py` — PreToolUse advisory check for `*.md` writes
- `references/injection_rules.yaml` — new `**/*.md` rule with `lang: markdown` (opt-in via `DEV_KIT_MARKDOWN=true`)
- `references/inject_references.py` — added `lang: markdown` / `DEV_KIT_MARKDOWN` support
- `plugins/claude-kit/references/common.md` (+ jp) — updated JP mirror warning comment placement rule

### Background

Writing the JP mirror warning comment (`<!-- This file is a Japanese mirror. ... -->`) above the
opening `---` causes YAML frontmatter to be rendered as body text in GitHub and most Markdown previewers.
The hook detects this pattern and advises moving the comment to after the closing `---`.
