# dev-kit v4.7.0 — 2026-05-31

## New: Markdown frontmatter placement check

Added a hook and reference that warn when content appears before the opening `---` of a YAML frontmatter block.

### What's new

- `references/markdown/markdown-editing.md` (+ `markdown-editing.jp.md`) — short reference explaining the rule
- `hooks/scripts/markdown_frontmatter_check.py` — PreToolUse advisory check for `*.md` writes (opt-out via `DEV_KIT_MARKDOWN_CHECK=false`)
- `references/_injection_rules.yaml` — `**/*.md` rule updated to include `markdown/markdown-editing.md` alongside `markdown/markdown-table.md`
- `hooks/scripts/inject_references.py` — added `lang: markdown` / `DEV_KIT_MARKDOWN` support
- `plugins/claude-kit/references/common.md` (+ jp) — updated JP mirror warning comment placement rule

### Background

Writing the JP mirror warning comment (`<!-- This file is a Japanese mirror. ... -->`) above the
opening `---` causes YAML frontmatter to be rendered as body text in GitHub and most Markdown previewers.
The hook detects this pattern and advises moving the comment to after the closing `---`.
