# v4.0.0 — 2026-05-30

## 変更内容

- **py-kit / html-kit / next-kit を dev-kit に統合**（PR166 / [[merge-language-plugins-into-dev-kit]]）。
- 統合後のスキル一覧:
  - `dev-kit:py-script` / `dev-kit:py-project`（py-kit から移行）
  - `dev-kit:html-implement` / `dev-kit:html-logging` / `dev-kit:html-mock` / `dev-kit:html-debug-fab`（html-kit から移行・rename）
  - `dev-kit:next-implement` / `dev-kit:next-plan`（next-kit から移行・rename）
  - `dev-kit:yaml`（既存）
- フック統合:
  - `hooks/inject_references.py`: 全 lang 共通の reference 自動注入フック。各ルールに `lang: python|html|next` を持ち、`DEV_KIT_PYTHON` / `DEV_KIT_HTML` / `DEV_KIT_NEXT` が truthy (`true`/`1`/`yes`/`on`) のときのみ該当 lang のルールを有効化（デフォルト全 OFF — opt-in 方式）。
  - `hooks/ts_check.py`: PostToolUse(Edit/Write/MultiEdit) で `*.ts` / `*.tsx` を `tsc --noEmit --incremental` でチェック。`DEV_KIT_NEXT_TS_CHECK=false` で無効化（デフォルト有効）。
  - 既存の yaml-skill-dispatch（PreToolUse Edit/Write の `*.yaml` ディスパッチ）はそのまま維持。
  - html-kit の UserPromptSubmit キーワードマッチ方式は廃止し、PreToolUse ref-inject 方式に統一。
- リファレンス構造:
  - `references/python/`, `references/html/`, `references/next/` の lang サブフォルダに分割。
  - `references/index.yaml` / `index.jp.yaml` / `injection_rules.yaml` を統合（各エントリに `lang` フィールド付き）。
- 既存プラグイン削除:
  - `plugins/py-kit/`, `plugins/html-kit/`, `plugins/next-kit/` を完全削除。
  - `.claude-plugin/marketplace.json` から 3 エントリ削除。

## 構造の変更

- 旧パス → 新パス:
  - `py-kit/skills/py-script` → `dev-kit/skills/py-script`
  - `py-kit/skills/py-project` → `dev-kit/skills/py-project`
  - `html-kit/skills/implement` → `dev-kit/skills/html-implement`
  - `html-kit/skills/logging` → `dev-kit/skills/html-logging`
  - `html-kit/skills/mock` → `dev-kit/skills/html-mock`
  - `html-kit/skills/debug-fab` → `dev-kit/skills/html-debug-fab`
  - `next-kit/skills/implement` → `dev-kit/skills/next-implement`
  - `next-kit/skills/plan` → `dev-kit/skills/next-plan`
  - `py-kit/references/{path}` → `dev-kit/references/python/{path}`
  - `html-kit/references/{path}` → `dev-kit/references/html/{path}`
  - `next-kit/references/{path}` → `dev-kit/references/next/{path}`
  - `html-kit/templates/rules/*` → `dev-kit/templates/html/rules/*`
  - `next-kit/hooks/ts_check.py` → `dev-kit/hooks/ts_check.py`
- TTLトークン保存先: `~/.claude/tokens/py-kit/` および `~/.claude/tokens/next-kit/` から `~/.claude/tokens/dev-kit/` に統合。
- env 変数の変更:
  - `PY_KIT_INJECTION_TTL` → `DEV_KIT_INJECTION_TTL`
  - `PY_KIT_INJECTION_LANG` → `DEV_KIT_INJECTION_LANG`
  - `PY_KIT_INJECTION_DISABLE` → `DEV_KIT_INJECTION_DISABLE`
  - `NEXT_KIT_INJECTION_TTL` → `DEV_KIT_INJECTION_TTL`（共通）
  - `NEXT_KIT_INJECTION_LANG` → `DEV_KIT_INJECTION_LANG`（共通）
  - `NEXT_KIT_INJECTION_DISABLE` → `DEV_KIT_INJECTION_DISABLE`（共通）
  - `NEXT_KIT_TS_CHECK` → `DEV_KIT_NEXT_TS_CHECK`
  - **新規**: `DEV_KIT_PYTHON` / `DEV_KIT_HTML` / `DEV_KIT_NEXT`（言語ごとの opt-in トグル）
- プロジェクト側の `settings.json` を更新する必要がある:
  - 使用する言語を `DEV_KIT_PYTHON=true` 等で明示的に opt-in
  - 旧 `PY_KIT_*` / `NEXT_KIT_*` の env 設定は廃止
