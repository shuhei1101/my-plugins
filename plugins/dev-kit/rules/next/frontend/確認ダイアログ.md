# `useConfirmDialog()` — 確認ダイアログ

`window.confirm` の代替。`await confirm({ ... })` で `boolean` を返す。

- `app/layout.tsx` で `<ConfirmDialogProvider>` wrap が必要
- 削除は確認必須、登録・更新は不要
- 破壊的アクションは `variant: "destructive"`

## Options

`title`, `description?`, `confirmText?`, `cancelText?`, `variant?: "default" | "destructive"`
