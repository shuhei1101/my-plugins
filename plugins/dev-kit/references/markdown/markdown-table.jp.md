# Markdown テーブル規約

英語正本: `references/markdown/markdown-table.md`

## ナンバーカラム

テーブルを作成するときは、**最左カラムに必ず `#` カラム**を設ける。
`#` カラムは**常に入力必須** — すべての行に通し番号を書く。例外なし。

**例:**

| # | ファイル | 変更内容 |
|---|---|---|
| 1 | `foo.md` | セクション A を追加 |
| 2 | 〃 | セクション B の誤字を修正 |
| 3 | `bar.md` | 非推奨の注記を削除 |

**アンチパターン — ナンバーカラムを省略してはいけない:**

| ファイル | 変更内容 |
|---|---|
| `foo.md` | セクション A を追加 |
| `bar.md` | 非推奨の注記を削除 |

`#` カラムがあると、会話中に行を参照しやすくなり（「3行目」など）、長いテーブルでも見通しが良くなる。

## セルの繰り返し値

同じ列で連続した行が同じ値を持つ場合、値は**最初の行にのみ**書き、以降の行は `〃`（ダイトーマーク）を使う。

**例:**

| # | ファイル | 変更内容 |
|---|---|---|
| 1 | `foo.md` | セクション A を追加 |
| 2 | 〃 | セクション B の誤字を修正 |
| 3 | `bar.md` | 非推奨の注記を削除 |

**アンチパターン — 値を繰り返してはいけない:**

| # | ファイル | 変更内容 |
|---|---|---|
| 1 | `foo.md` | セクション A を追加 |
| 2 | `foo.md` | セクション B の誤字を修正 |
| 3 | `bar.md` | 非推奨の注記を削除 |

このルールは値が複数行にまたがる列全般に適用する: ファイル名、コンポーネント名、カテゴリ名など。
`#` カラムはこのルールの適用外 — 常に通し番号を書く。
