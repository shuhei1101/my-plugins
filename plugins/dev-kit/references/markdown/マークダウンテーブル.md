# Markdown テーブル規約

英語正本: `references/markdown/マークダウンテーブル.md`

## ナンバーカラム

会話中に行を参照したい（「3番のやつを修正して」）場合、テーブルの**最左カラムに `No` カラム**を設ける。

`No` カラムを設ける場合、**すべての行に通し番号を書く** — 空欄・省略行は不可。

**つける場合:**
- 最左カラムの値が長い・複雑（ファイルパス、URL、長い名前など）で、口頭で参照しにくい。
- 行を簡潔に指定できる識別子が他にない。

**省略できる場合:**
- 最左カラムがすでに自然な主キーとして機能しており、短く口頭で言える — 例えば選択肢ラベル（`A` / `B` / `C`）、単一文字、いずれかから選ぶ短い識別子など。

**例 — つける場合:**

| No | ファイル | 変更内容 |
|---|---|---|
| 1 | `foo.md` | セクション A を追加 |
| 2 | 〃 | セクション B の誤字を修正 |
| 3 | `bar.md` | 非推奨の注記を削除 |

**例 — 省略できる場合（選択肢が識別子として機能している）:**

| 選択肢 | 内容 |
|---|---|
| A | 既存のヘルパーを使う |
| B | 新しいヘルパーを追加する |
| C | ロジックをインライン化する |

**アンチパターン — 値が口頭で言いにくいのに `No` を省略してはいけない:**

| ファイル | 変更内容 |
|---|---|
| `foo.md` | セクション A を追加 |
| `bar.md` | 非推奨の注記を削除 |

## セルの繰り返し値

同じ列で連続した行が同じ値を持つ場合、値は**最初の行にのみ**書き、以降の行は `〃`（ダイトーマーク）を使う。

**例:**

| No | ファイル | 変更内容 |
|---|---|---|
| 1 | `foo.md` | セクション A を追加 |
| 2 | 〃 | セクション B の誤字を修正 |
| 3 | `bar.md` | 非推奨の注記を削除 |

**アンチパターン — 値を繰り返してはいけない:**

| No | ファイル | 変更内容 |
|---|---|---|
| 1 | `foo.md` | セクション A を追加 |
| 2 | `foo.md` | セクション B の誤字を修正 |
| 3 | `bar.md` | 非推奨の注記を削除 |

このルールは値が複数行にまたがる列全般に適用する: ファイル名、コンポーネント名、カテゴリ名など。
`No` カラムはこのルールの適用外 — 常に通し番号を書く。
