## tsconfig.json

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["dom", "dom.iterable", "esnext"],
    "allowJs": false,
    "skipLibCheck": true,
    "strict": true,
    "noImplicitAny": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true,
    "noImplicitOverride": true,
    "noUncheckedIndexedAccess": true,
    "forceConsistentCasingInFileNames": true,
    "noEmit": true,
    "esModuleInterop": true,
    "module": "esnext",
    "moduleResolution": "bundler",
    "resolveJsonModule": true,
    "isolatedModules": true,
    "jsx": "preserve",
    "incremental": true,
    "plugins": [{ "name": "next" }],
    "paths": {
      "@/*": ["./*"]
    }
  },
  "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx", ".next/types/**/*.ts"],
  "exclude": ["node_modules"]
}
```

ポイント:
- `strict: true` + `noImplicitAny` + `noUncheckedIndexedAccess` = 最大限の型安全
- `moduleResolution: "bundler"` で Next.js 16 推奨
- `paths` で `@/` エイリアス

## ESLint v9 Flat Config

`eslint.config.js`（Flat Config 形式、Next.js 16 で標準）:

```js
// eslint.config.js
import { FlatCompat } from "@eslint/eslintrc"
import path from "path"
import { fileURLToPath } from "url"

const __dirname = path.dirname(fileURLToPath(import.meta.url))
const compat = new FlatCompat({ baseDirectory: __dirname })

export default [
  // Next.js のルール（旧 extends を Flat に変換）
  ...compat.extends(
    "next/core-web-vitals",
    "next/typescript",
  ),
  {
    rules: {
      "@typescript-eslint/no-unused-vars": ["error", { argsIgnorePattern: "^_", varsIgnorePattern: "^_" }],
      "@typescript-eslint/consistent-type-imports": "error",
      "@typescript-eslint/no-explicit-any": "warn",
      "no-console": ["warn", { allow: ["warn", "error"] }],

      // React
      "react/jsx-no-leaked-render": "error",

      // import order
      "import/order": ["warn", {
        "groups": ["builtin", "external", "internal", "parent", "sibling", "index"],
        "newlines-between": "always",
        "alphabetize": { "order": "asc" },
      }],
    },
  },
  {
    files: ["**/*.test.{ts,tsx}", "tests/**/*.{ts,tsx}"],
    rules: {
      "@typescript-eslint/no-explicit-any": "off",
    },
  },
  {
    ignores: [".next/", "node_modules/", "drizzle/migrations/"],
  },
]
```

実行:

```bash
pnpm eslint .
pnpm eslint . --fix
```

`next lint` は **Next.js 16 で削除** されたため、ESLint CLI を直接呼ぶ。

### ESLint と Prettier の整合

```bash
pnpm add -D eslint-config-prettier
```

```js

import eslintConfigPrettier from "eslint-config-prettier"

export default [
  // ...
  eslintConfigPrettier,
```

`eslint-config-prettier` が Prettier と競合する ESLint ルールを無効化。

## tsc --noEmit による型チェック

CI / pre-commit で型崩れを検知:

```bash
pnpm tsc --noEmit
```

`Awaited<ReturnType<typeof ...>>` パターン（`型定義.md` 参照）で型を導出している場合、内部関数の変更で client.ts の型が壊れる。CI で必ず実行。

```json
// package.json
{
  "scripts": {
    "typecheck": "tsc --noEmit",
    "lint": "eslint .",
    "format": "prettier --write .",
    "check": "pnpm typecheck && pnpm lint && pnpm prettier --check ."
  }
}
```

## Constraints

- TypeScript の `strict` モード必須 + `noUncheckedIndexedAccess`
- ESLint v9 Flat Config（Next.js 16 標準）
- `next lint` は使わない（廃止）
- Prettier で format 統一
- `eslint-config-prettier` で競合解消
- `prettier-plugin-tailwindcss` で class ソート
- `tsc --noEmit` を CI で必ず実行
- `lint-staged` で commit 時の自動 lint / format
- VSCode は format on save + ESLint auto fix
- `@typescript-eslint/consistent-type-imports` で `import type` 強制
