# lib/auth.ts — Better Auth セットアップ

採用認証プロバイダ: **Better Auth**（DB 非依存・TypeScript ファースト）。

---

## インストール

```bash
pnpm add better-auth
```

---

## 必須テンプレ

```ts
// lib/auth.ts
import { betterAuth } from "better-auth"
import { drizzleAdapter } from "better-auth/adapters/drizzle"
import { db } from "@/drizzle/db"
import { users, sessions, accounts, verifications } from "@/drizzle/schema"

export const auth = betterAuth({
  database: drizzleAdapter(db, {
    provider: "pg",
    schema: { user: users, session: sessions, account: accounts, verification: verifications },
  }),
  emailAndPassword: {
    enabled: true,
    requireEmailVerification: false,
  },
  socialProviders: {
    google: {
      clientId: process.env.GOOGLE_CLIENT_ID!,
      clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
    },
  },
  session: {
    expiresIn: 60 * 60 * 24 * 30,    // 30 days
    updateAge: 60 * 60 * 24,          // 1 day（sliding renewal）
    cookieCache: { enabled: true, maxAge: 60 * 5 },
  },
})
```

## API ルート

```ts
// app/api/v1/auth/[...all]/route.ts
import { auth } from "@/lib/auth"

export const { GET, POST } = toNextJsHandler(auth.handler)
```

## クライアント

```ts
// app/(shared)/auth/client.ts
'use client'
import { createAuthClient } from "better-auth/react"

export const authClient = createAuthClient({
  baseURL: process.env.NEXT_PUBLIC_APP_URL,
})

// 使い方
await authClient.signIn.email({ email, password })
await authClient.signOut()
const { data: session } = authClient.useSession()
```

## サーバーからセッション取得

`app/(shared)/auth/provider.ts` で薄くラップする（`認証コンテキスト.md` 参照）:

```ts
// app/(shared)/auth/provider.ts
import { auth } from "@/lib/auth"
import { headers } from "next/headers"

export const getSession = async () => {
  return await auth.api.getSession({ headers: await headers() })
}
```

---

## ルール

- `lib/auth.ts` は 1 つだけ（複数 instance NG）
- セッション期限は **30 日 + sliding renewal**
- `cookieCache` を有効化（DB クエリ削減）
- 環境変数経由でシークレットを渡す（hard-code 禁止）
- OAuth プロバイダの secret は **`NEXT_PUBLIC_` 付けない**

## 禁止

- Auth.js / Supabase Auth / Lucia 等の他プロバイダを混在
- セッショントークンを localStorage に保存（httpOnly cookie のみ）
- DB スキーマを Better Auth 公式と互換にしない
