# app/(shared)/errors/handler/server.ts — withRouteErrorHandling

`route.ts` の HTTP ハンドラを wrap して、AppError 派生・Zod エラーを構造化 JSON に変換する。

---

## 実装

```ts
// app/(shared)/errors/handler/server.ts
import { NextResponse } from "next/server"
import { z } from "zod"
import { AppError, ClientValueError, ClientAuthError, VersionConflictError } from "../appError"
import { logger } from "@/app/(shared)/logger"

const log = logger.create("error:server")

export const withRouteErrorHandling = async <T>(
  handler: () => Promise<T>,
): Promise<T | NextResponse> => {
  try {
    return await handler()
  } catch (e) {
    // Zod バリデーションエラー
    if (e instanceof z.ZodError) {
      const first = e.issues[0]
      return NextResponse.json(
        { error: { code: "VALIDATION", message: first.message, field: first.path.join(".") } },
        { status: 400 },
      ) as any
    }
    if (e instanceof ClientAuthError) {
      return NextResponse.json({ error: { code: e.code, message: e.message } }, { status: e.statusCode }) as any
    }
    if (e instanceof ClientValueError) {
      return NextResponse.json(
        { error: { code: e.code, message: e.message, field: e.field } },
        { status: e.statusCode },
      ) as any
    }
    if (e instanceof VersionConflictError) {
      return NextResponse.json({ error: { code: e.code, message: e.message } }, { status: e.statusCode }) as any
    }
    if (e instanceof AppError) {
      return NextResponse.json({ error: { code: e.code, message: e.message } }, { status: e.statusCode }) as any
    }

    // 予期しないエラー
    log.error("unexpected error", {
      error: e instanceof Error ? e.message : String(e),
      stack: e instanceof Error ? e.stack : undefined,
    })
    return NextResponse.json(
      { error: { code: "INTERNAL", message: "予期せぬエラーが発生しました。" } },
      { status: 500 },
    ) as any
  }
}
```

---

## 使い方

```ts
// app/api/v1/resources/route.ts
export async function POST(request: NextRequest) {
  return withRouteErrorHandling(async () => {
    const { db, userId } = await getAuthContext()    // ClientAuthError 投げる可能性
    const body = await request.json()
    const data = PostResourceRequestSchema.parse(body)    // ZodError 投げる可能性
    const result = await registerResource({ db, userId, form: data.form })    // AppError 派生
    return NextResponse.json({ data: { id: result.id } }, { status: 201 })
  })
}
```

## レスポンス封筒

| Error | Status | Body |
|---|---|---|
| Zod (validation) | 400 | `{ error: { code: "VALIDATION", message, field } }` |
| ClientValueError | 400 | `{ error: { code: "VALUE", message, field? } }` |
| ClientAuthError | 401 / 403 | `{ error: { code: "AUTH", message } }` |
| VersionConflictError | 409 | `{ error: { code: "CONFLICT", message } }` |
| AppError (404 等) | e.statusCode | `{ error: { code: e.code, message } }` |
| 予期せぬエラー | 500 | `{ error: { code: "INTERNAL", message: "予期せぬエラー" } }` |

---

## ルール

- 全 `route.ts` handler を **`withRouteErrorHandling`** で wrap（try/catch を書かない）
- Zod / AppError 派生は自動でレスポンスに変換
- 予期しないエラーは **ログに stack を記録** して 500 で返す
- ユーザーに raw error.message / stack を出さない

## 禁止

- `try` / `catch` を直接書く（→ withRouteErrorHandling 内に書く）
- stack をクライアントレスポンスに含める
- generic Error をそのまま投げる（AppError 派生に変換）
