# `<EmptyState>` — 空状態の汎用 UI

データが 0 件のときに必ず描画する共通コンポーネント。

---

## 実装

```tsx
// app/(shared)/components/EmptyState.tsx

type Props = {
  message: string
  description?: string
  action?: React.ReactNode
}

export const EmptyState = ({ message, description, action }: Props) => (
  <div className="text-center py-12 space-y-3">
    <p className="text-muted-foreground">{message}</p>
    {description && <p className="text-sm text-muted-foreground/70">{description}</p>}
    {action}
  </div>
)
```

---

## 使い方

```tsx
{rows.length === 0 && !isFetching && (
  <EmptyState
    message="該当するリソースがありません"
    action={
      <Button variant="outline" onClick={() => setFilter({})}>
        フィルタをクリア
      </Button>
    }
  />
)}
```

```tsx
{!hasAnyData && (
  <EmptyState
    message="まだデータがありません"
    description="新規作成して始めましょう"
    action={<Button asChild><Link href={RESOURCE_URL.new}>新規作成</Link></Button>}
  />
)}
```

---

## ルール

- リスト系画面の `length === 0 && !isFetching` で **必ず描画**（白画面禁止）
- フィルタが効いていれば「フィルタをクリア」action
- フィルタなしの空なら「新規作成」action
- message は短く、description は補足

## 禁止

- 空状態を描画せずに白画面のまま
- message を冗長にする
- action なし（ユーザーが次の行動に困る）
