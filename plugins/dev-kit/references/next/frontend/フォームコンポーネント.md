# shadcn `<Form>` でフォームを書く

react-hook-form + Zod + shadcn/ui の標準パターン。`{Feature}EditScreen.tsx` 等の中で使う。

---

## 基本構造

```tsx
'use client'

import { useForm } from "react-hook-form"
import { zodResolver } from "@hookform/resolvers/zod"
import { Form, FormControl, FormField, FormItem, FormLabel, FormMessage, FormDescription } from "@/app/(shared)/components/ui/form"
import { Input } from "@/app/(shared)/components/ui/input"
import { Button } from "@/app/(shared)/components/ui/button"

import { ResourceFormSchema, defaultResourceForm, type ResourceFormType } from "../form"

const form = useForm<ResourceFormType>({
  resolver: zodResolver(ResourceFormSchema),
  defaultValues: defaultResourceForm,
})

<Form {...form}>
  <form onSubmit={form.handleSubmit(onSubmit)} className="space-y-4">
    <FormField
      control={form.control}
      name="name"
      render={({ field }) => (
        <FormItem>
          <FormLabel>リソース名</FormLabel>
          <FormControl>
            <Input {...field} />
          </FormControl>
          <FormDescription>1〜20 文字</FormDescription>
          <FormMessage />
        </FormItem>
      )}
    />
    <Button type="submit">保存</Button>
  </form>
</Form>
```

ポイント:
- `<Form {...form}>` で `FormProvider` を提供
- `<FormField name="..." render={({ field }) => ...}>` で react-hook-form と橋渡し
- `field` = `{ value, onChange, onBlur, name, ref }`
- `<FormMessage />` がエラーメッセージ自動描画

## 入力タイプ別

### Text / Textarea

```tsx
<FormField control={form.control} name="name" render={({ field }) => (
  <FormItem>
    <FormLabel>名前</FormLabel>
    <FormControl><Input {...field} /></FormControl>
    <FormMessage />
  </FormItem>
)} />

<FormField control={form.control} name="description" render={({ field }) => (
  <FormItem>
    <FormLabel>説明</FormLabel>
    <FormControl><Textarea rows={4} {...field} /></FormControl>
    <FormMessage />
  </FormItem>
)} />
```

### Number

```tsx
<FormField control={form.control} name="reward" render={({ field }) => (
  <FormItem>
    <FormLabel>報酬</FormLabel>
    <FormControl>
      <Input
        type="number"
        value={field.value ?? ""}
        onChange={(e) => field.onChange(e.currentTarget.value === "" ? null : Number(e.currentTarget.value))}
      />
    </FormControl>
    <FormMessage />
  </FormItem>
)} />
```

### Date

```tsx
import { Calendar } from "@/app/(shared)/components/ui/calendar"
import { Popover, PopoverContent, PopoverTrigger } from "@/app/(shared)/components/ui/popover"
import { Button } from "@/app/(shared)/components/ui/button"
import { CalendarIcon } from "lucide-react"
import { format } from "date-fns"
import { ja } from "date-fns/locale"

<FormField control={form.control} name="birthday" render={({ field }) => (
  <FormItem>
    <FormLabel>誕生日</FormLabel>
    <Popover>
      <PopoverTrigger asChild>
        <FormControl>
          <Button variant="outline" className="w-full justify-start">
            <CalendarIcon className="mr-2 h-4 w-4" />
            {field.value ? format(new Date(field.value), "yyyy年M月d日", { locale: ja }) : "選択..."}
          </Button>
        </FormControl>
      </PopoverTrigger>
      <PopoverContent className="w-auto p-0">
        <Calendar
          mode="single"
          selected={field.value ? new Date(field.value) : undefined}
          onSelect={(d) => field.onChange(d?.toISOString() ?? null)}
        />
      </PopoverContent>
    </Popover>
    <FormMessage />
  </FormItem>
)} />
```


## エラー表示

`<FormMessage />` が自動的に `errors[fieldName]?.message` を描画。Server Action の戻り値からフィールドエラーを設定:

```tsx
const result = await updateResourceAction(...)
if (!result.ok) {
  if (result.error.field) form.setError(result.error.field as any, { message: result.error.message })
  else toast.error(result.error.message)
}
```

## ルール

- shadcn `<Form>` プリミティブを使う（`<FormField>` `<FormItem>` `<FormControl>` `<FormLabel>` `<FormMessage>`）
- `register` 直接使用は禁止 (shadcn `<Form>` を経由)
- `setValue` + `watch` も避けて `<FormField>` パターン
- 必須マーカーは `<FormLabel>` 内に `<RequiredMark />`
- IME 入力（タグ等）は **`<TagInput>`** で共通化
- フィールドエラーは `<FormMessage />`、汎用エラーは toast

- IME 制御を画面ごとに手書き（`<TagInput>` を使う）
- エラーメッセージを `<FormMessage />` の外で描画
