# `<RequiredMark />` — 必須フィールド表示

`<FormLabel>` 内に挟む赤い `*`。

---

## 実装

```tsx
// app/(shared)/components/RequiredMark.tsx
export const RequiredMark = () => <span className="text-destructive ml-1">*</span>
```

---

## 使い方

```tsx
<FormField control={form.control} name="name" render={({ field }) => (
  <FormItem>
    <FormLabel>名前<RequiredMark /></FormLabel>
    <FormControl><Input {...field} /></FormControl>
    <FormMessage />
  </FormItem>
)} />
```

---

## ルール

- **Zod で必須** にしているフィールドには **必ず付ける**
- `<FormLabel>` の子要素として配置（ラベルの直後）
- カラーは `text-destructive`（テーマ色）

## 関連 references

- `frontend/フォームコンポーネント.md`

## 禁止

- 必須なのに `<RequiredMark />` なし
- 任意フィールドに付ける
