## 必須ルール

### UI 設計時は必ず `frontend-design` スキルを使う

フロントエンドの**あらゆる**ビジュアル/UX 作業 — コンポーネント・ページ・アプリ全体・レイアウト判断・
タイポグラフィ・配色・アニメーション — では **例外なく** `frontend-design` スキルを呼び出すこと。

このスキルが担保するもの:

- 明確なコンセプト/美的方向性(AI 汎用デフォルトに陥らない)
- 特徴あるタイポグラフィと配色の選択
- 意図のあるモーション・空間構成
- 美的ビジョンと釣り合った実装グレード

その場のセンスで UI コードを書かない。小さなコンポーネントでも UI 設計判断はすべて
このスキル経由で行い、出力に一貫性を持たせて「AI っぽいデザイン」を回避する。

スキル ID: `frontend-design:frontend-design`(公式 Claude プラグインマーケットプレイス提供)。
