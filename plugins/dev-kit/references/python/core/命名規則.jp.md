# 命名規約

## 基本ルール

| 対象 | 規則 | 例 |
|---|---|---|
| モジュール / ファイル | `snake_case` | `user_service.py`, `open_ai_client.py` |
| 関数（公開・内部問わず） | `snake_case` | `create_user`, `find_user_by_id` |
| 内部専用関数 / モジュール | 先頭 `_` | `_validate_input`, `_helpers.py` |
| 公開する識別子（`__init__.py` 経由） | 通常名 | `from .service import create_user` |
| 隠したい識別子 | `_` プレフィックス | `_internal_state` |
| 型エイリアス（`type X = ...`） | `UpperCamel` | `UserId`, `CreateUserInput`, `FindUser` |
| dataclass / Pydantic クラス | `UpperCamel` | `User`, `CreateUserInput` |
| Protocol | `UpperCamel`（prefix なし） | `UserFinder`, `AsyncChatFn`（動詞ベース可） |
| 定数 | `UPPER_SNAKE_CASE` | `MAX_RETRY_COUNT` |
| TypeVar / generic param | 1 文字大文字 or `UpperCamel + T` | `T`, `K`, `V`, `UserT` |

### 補足

- **Protocol 名に `I` プレフィックスは付けない**（Java 風の `IUserFinder` は使わない）
- **動詞ベースの型エイリアス名**は許容: `AsyncChatFn`, `SaveUser`, `FindUser`
  - 関数の型エイリアスとして使う場合、動詞名のほうが用途が明確になる
- 識別子型エイリアス（`UserId`, `OrderId` 等）は **名詞** で揃える

## feature フォルダ内の標準ファイル名

機能フォルダ `{pkg}/{feature}/` の中で以下の名前を **標準パターン** として推奨。
小さい feature なら `types.py` + `service.py` だけでも可。

| ファイル名 | 役割 |
|---|---|
| `__init__.py` | 公開シンボルの再エクスポート（`from .service import create_user` 等） |
| `types.py` | 型エイリアス + DTO + Protocol（feature 内の型定義の置き場） |
| `query.py` | 読み取り系関数（`find_*`、`list_*`、`get_*`） |
| `service.py` | ビジネスロジック関数（`create_*`、`update_*`、`delete_*`、複合操作） |
| `route.py` | HTTP ハンドラ（FastAPI ルーター。server / feature が Web に公開される場合のみ） |
| `client.py` | 外部 API 呼び出し関数（`integrations/` 配下で主に使う） |
| `db.py` | 永続化操作（DB を使う場合のみ。新方針では基本不要） |
| `prompts/` | プロンプトファイル（LLM feature の場合のみ、サブフォルダ） |
| `_helpers.py` | feature 内部のみで使うヘルパー |

「全部置く」ではなく「**この名前を使うときはこの役割**」という標準。

### 関数名の動詞接頭辞

| プレフィックス | 用途 | 戻り値 |
|---|---|---|
| `create_*` | 新規作成 | 作ったエンティティ |
| `update_*` | 更新 | 更新後のエンティティ または `None` |
| `delete_*` | 削除 | `None` |
| `find_*` | 1 件検索 | `Entity \| None` |
| `get_*` | 1 件取得（必ず存在する想定） | `Entity`（無ければ raise） |
| `list_*` | 複数取得 | `list[Entity]` |
| `search_*` | 条件検索（複数） | `list[Entity]` |

## モジュールパスと「公開 API」

- 各 feature は `__init__.py` で公開シンボルを明示的にエクスポートする
- 外部から `from {pkg}.features.chat.service import _internal_helper` のように内部を直接掴ませない
- 公開したくない関数 / 変数は名前を `_` で始める

```python
# {pkg}/features/chat/__init__.py
from .service import generate_response
from .types import ChatRequest, ChatResponse

__all__ = ["generate_response", "ChatRequest", "ChatResponse"]
```
