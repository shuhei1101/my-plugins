# logger — Structured logging in JSON Lines format

Use `logger` instead of `print`. The output format is **JSON Lines** (one JSON per line).
This is designed with aggregation, grep, and dashboard integration in mind.

---

## Standard implementation

```python
# src/{pkg}/shared/logger.py
from __future__ import annotations
import json
import logging
import sys
from datetime import datetime, timezone


class JsonLinesFormatter(logging.Formatter):
    """構造化ログ（1 行 1 JSON）。"""

    def format(self, record: logging.LogRecord) -> str:
        payload: dict[str, object] = {
            "ts": datetime.now(timezone.utc).isoformat(timespec="milliseconds"),
            "level": record.levelname,
            "name": record.name,
            "msg": record.getMessage(),
        }
        # extra=... で渡されたフィールドを取り込む
        for key, value in record.__dict__.items():
            if key in _LOGRECORD_RESERVED:
                continue
            payload[key] = value
        # 例外情報
        if record.exc_info:
            payload["exc"] = self.formatException(record.exc_info)
        return json.dumps(payload, ensure_ascii=False, default=str)


_LOGRECORD_RESERVED = frozenset({
    "name", "msg", "args", "levelname", "levelno", "pathname", "filename",
    "module", "exc_info", "exc_text", "stack_info", "lineno", "funcName",
    "created", "msecs", "relativeCreated", "thread", "threadName",
    "processName", "process", "message",
})


def _ensure_root_configured() -> None:
    """プロセスで一度だけ実行する root logger 設定。"""
    root = logging.getLogger()
    if getattr(root, "_jsonl_configured", False):
        return
    handler = logging.StreamHandler(sys.stdout)
    handler.setFormatter(JsonLinesFormatter())
    root.addHandler(handler)
    root.setLevel(logging.INFO)
    root._jsonl_configured = True   # type: ignore[attr-defined]


def get_logger(name: str) -> logging.Logger:
    """モジュール名で logger を取得する。`get_logger(__name__)` で使う。"""
    _ensure_root_configured()
    return logging.getLogger(name)
```

## Usage

```python
# 任意のモジュールで
from {pkg}.shared.logger import get_logger

logger = get_logger(__name__)

def create_user(input: CreateUserInput) -> User:
    logger.info("creating user", extra={"name": input.name})
    user = User(...)
    logger.info("user created", extra={"user_id": user.id})
    return user
```

Sample output (JSON Lines, formatted here for one-line display):

```json
{"ts":"2026-05-27T10:00:00.123+00:00","level":"INFO","name":"mypkg.users.service","msg":"creating user","name_extra":"alice"}
{"ts":"2026-05-27T10:00:00.234+00:00","level":"INFO","name":"mypkg.users.service","msg":"user created","user_id":"u-123"}
```

## Log level guidelines

| Level | Purpose |
|---|---|
| `debug` | Development only. Trace info, argument dumps |
| `info` | Business events. Request received, use case start/finish |
| `warning` | Expected errors (recoverable via retry, invalid input, etc.) |
| `error` | Unexpected errors. Humans should monitor and respond |
| `critical` | Process cannot continue |

The standard is to emit `WARNING` or higher in production and `DEBUG` and above in development.

---

## Structured arguments vs f-strings

| Use case | Recommended |
|---|---|
| Used in dashboards / aggregation | **Structured arguments** (`extra={...}`) |
| Temporary debug output during development | f-string |
| Error logs (where details are needed for reproducibility) | Structured arguments |

```python
# ✅ 構造化（集計・grep しやすい）
logger.info("llm_call", extra={"provider": "openai", "tokens": 1234, "elapsed_ms": 567})

# ✅ f-string（人間が読むデバッグログ）
logger.debug(f"trying provider {provider_name}, attempt {attempt}/{max}")
```

## Exception logging

Using `logger.exception(...)` automatically attaches the traceback to the `exc` field:

```python
try:
    result = await chat(messages)
except LlmError:
    logger.exception("chat failed", extra={"messages_len": len(messages)})
    raise
```

## Level configuration (via environment variables)

Read from `shared/settings.py` and apply:

```python
# src/{pkg}/main.py
import logging
from {pkg}.shared.settings import Settings
from {pkg}.shared.logger import get_logger

def main() -> None:
    settings = Settings()
    logging.getLogger().setLevel(settings.log_level.upper())  # e.g. "DEBUG"
    ...
```

```python
# src/{pkg}/shared/settings.py
class Settings(BaseSettings):
    log_level: str = "INFO"
```

## Output destinations

- Development: emit to stdout (the standard implementation above does this)
- Docker / k8s: stdout as-is (container logs)
- Lambda / Cloud Functions: stdout as-is (picked up by CloudWatch / Stackdriver)
- One-shot scripts that need file output: tee to `log/{script_name}-{YYYYMMDD-HHMMSS}.log` (on the bat/sh side)

See `scripts/launchers-windows.md` / `scripts/ランチャー-Unix.md` for details.

## What not to do

```python
# ❌ print デバッグ
print(f"user {user.id} created")   # ロガー使う

# ❌ 機密情報をログに出す
logger.info(f"login", extra={"password": password})   # NG

# ❌ ループ内で大量に DEBUG
for item in huge_list:
    logger.debug(f"processing {item}")   # 必要なら DEBUG レベルで運用するが、本番では INFO 以上
```
