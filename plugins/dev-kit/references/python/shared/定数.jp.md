# shared/constants.py — 計算済み定数

> このファイルは `定数.md` の日本語ミラーです。

`constants.py` には **計算済みの不変値** だけを置く。実行時可変な値（env で切り替える等）は `settings.py` 側へ。

---

## 役割境界

| 配置先 | 内容 |
|---|---|
| `constants.py` | プロジェクト構造から計算される定数（PROJECT_ROOT、LOG_DIR）、業務的に固定の定数（MAX_TAGS、DEFAULT_TIMEOUT_SEC 等） |
| `settings.py` | env / .env で切り替えたい値（API キー、モデル名、log_level） |
| 各 feature の `types.py` | feature 専用の定数（業務 Enum 等） |

---

## サンプル

```python
# src/{pkg}/shared/constants.py
from __future__ import annotations
from pathlib import Path

# ----- パス -----
PROJECT_ROOT: Path = Path(__file__).resolve().parents[2]
"""プロジェクトのルートディレクトリ（src/ の 1 つ上）。"""

LOG_DIR: Path = PROJECT_ROOT / "log"
"""ログ出力ディレクトリ。"""

CONFIG_DIR: Path = PROJECT_ROOT / "config"
"""設定ファイル置き場。"""

DATA_DIR: Path = PROJECT_ROOT / "data"
"""データファイル置き場（メディア / 永続化等）。"""

# ----- 業務的な固定値 -----
MAX_TAGS_PER_POST: int = 10
"""1 投稿あたりのタグ最大数。"""

DEFAULT_PAGE_SIZE: int = 20
"""ページネーションの既定件数。"""

DEFAULT_TIMEOUT_SEC: float = 30.0
"""外部 API 呼び出しの既定タイムアウト（秒）。"""
```

## 命名

- `UPPER_SNAKE_CASE` で統一
- 型注釈を必ず付ける（型推論に頼らない）
- 説明が要るものは docstring または `# ` コメント

---

## やってはいけないこと

```python
# ❌ 実行時に変わる値を constants に入れる
LOG_LEVEL = "INFO"   # → settings.py に入れる（env で切り替えるため）
OPENAI_MODEL = "gpt-4o"   # → settings.py（モデル切替したい）

# ❌ 計算結果を都度書く（同じパスを 5 箇所で計算するなら共通定数に）
log_path = Path(__file__).resolve().parents[2] / "log" / "..."   # 散在する

# ❌ 巨大な dict を constants に置く
PROMPTS = {
    "greet": "...",   # 大きければプロンプトファイルや config に
    "farewell": "...",
}
```

## 計算済み Path のメリット

```python
from {pkg}.shared.constants import LOG_DIR

log_file = LOG_DIR / "app.log"
log_file.write_text("...", encoding="utf-8")
```

- 起動時に 1 度だけ計算され、以降は参照だけ
- どこから呼んでも同じ値（カレントディレクトリ依存にならない）
- IDE で「定義へ移動」が効く

## Enum との関係

業務的に取りうる値が固定の場合は **`Enum` か `Literal`** を使う:

```python
# Literal の場合（軽量）
type Status = Literal["draft", "published", "archived"]

# Enum の場合（ライブラリ要求等）
from enum import StrEnum

class Status(StrEnum):
    DRAFT = "draft"
    PUBLISHED = "published"
    ARCHIVED = "archived"
```

`Literal` を基本にする。`StrEnum` はライブラリが要求するときだけ。
