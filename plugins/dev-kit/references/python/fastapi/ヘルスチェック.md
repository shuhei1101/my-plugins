# fastapi/health — Health Check

Simple is best. Just return 200 from `/healthz`.

---

## Minimal implementation

```python
# src/{pkg}/server/routes/health.py
from __future__ import annotations
from fastapi import APIRouter

router = APIRouter(tags=["health"])


@router.get("/healthz")
async def healthz() -> dict[str, str]:
    """プロセスが生きていることだけを確認する。"""
    return {"status": "ok"}
```

---

## Why keep it simple

Health checks are used by **k8s / load balancers to determine process liveness**.
Making it complex causes the following issues:

- Failures of external DBs / Redis / upstream LLMs cause the health check to fail → the process is killed and the situation worsens
- The health check itself becomes heavy, putting pressure on traffic
- False positives / false negatives increase

---

## When you want to separate liveness and readiness

In k8s, you can use different endpoints for `livenessProbe` and `readinessProbe`:

| Purpose | Endpoint | Content |
|---|---|---|
| liveness (process alive) | `/healthz` | Just return 200 |
| readiness (can accept requests) | `/readyz` | Check startup-complete flag |

```python
@router.get("/healthz")
async def healthz() -> dict[str, str]:
    return {"status": "ok"}


@router.get("/readyz")
async def readyz(request: Request) -> dict[str, str]:
    """起動が完了してリクエストを受け取れる状態か。"""
    if not getattr(request.app.state, "ready", False):
        # 起動中
        from fastapi import HTTPException
        raise HTTPException(503, "not ready")
    return {"status": "ready"}
```

Set `app.state.ready = True` when the lifespan startup completes.

## When you want to expose dependency status

Create a separate diagnostic endpoint such as **`/healthz/deep`** for the monitoring dashboard.
**Do not touch the load balancer**:

```python
@router.get("/healthz/deep", tags=["health"])
async def healthz_deep(request: Request) -> dict[str, object]:
    """依存先の疎通も含む詳細ヘルスチェック。監視用。"""
    settings = request.app.state.settings

    return {
        "status": "ok",
        "checks": {
            "openai": await _check_openai(settings),
            "anthropic": await _check_anthropic(settings),
        },
    }


async def _check_openai(settings: Settings) -> dict[str, object]:
    try:
        # ping 的な短いリクエスト
        ...
        return {"ok": True}
    except Exception as e:
        return {"ok": False, "error": str(e)}
```

This endpoint should:
- Require authentication (publishing it risks secret leakage)
- Be excluded from the load balancer's probe configuration
- Be aimed at monitoring / operations engineers

## Do not

```python
# ❌ DB 接続を毎回確認
@router.get("/healthz")
async def healthz(db: DbDep):
    await db.execute("SELECT 1")   # DB 落ちたら ALB が prove 失敗、Pod kill 連鎖
    return {"ok": True}

# ❌ ヘルスチェックで外部 API を叩く
@router.get("/healthz")
async def healthz():
    await openai_client.chat(...)   # 課金もコスト効率も悪い

# ❌ status だけでなく余計な情報を返す
@router.get("/healthz")
async def healthz():
    return {
        "version": ...,
        "uptime": ...,
        "db_status": ...,
        "queue_depth": ...,
    }
    # ↑ /readyz や別エンドポイントへ
```
