# fastapi/health — ヘルスチェック

シンプルが正義。`/healthz` で 200 を返すだけ。

---

## 最小実装

```python
# src/{pkg}/server/routes/health.py
from __future__ import annotations
from fastapi import APIRouter

router = APIRouter(tags=["health"])

@router.get("/healthz")
async def healthz() -> dict[str, str]:
    """プロセスが生きていることだけを確認する。"""
    return {"status": "ok"}
```

---

## なぜシンプルにするか

ヘルスチェックは **k8s / load balancer がプロセスの生存判定** に使う。
複雑にすると以下の問題が起きる:

- 外部 DB / Redis / 上流 LLM の障害でヘルスチェックが落ちる → プロセスが kill されて余計に状況が悪化
- ヘルスチェック自体が重くなり、トラフィックを圧迫
- 偽陽性 / 偽陰性が増える

---

## liveness と readiness を分けたい場合

k8s では `livenessProbe` と `readinessProbe` を別エンドポイントにできる:

| 用途 | エンドポイント | 中身 |
|---|---|---|
| liveness（プロセス生存） | `/healthz` | 200 を返すだけ |
| readiness（リクエスト受付可） | `/readyz` | 起動完了フラグを確認 |

```python
@router.get("/healthz")
async def healthz() -> dict[str, str]:
    return {"status": "ok"}

@router.get("/readyz")
async def readyz(request: Request) -> dict[str, str]:
    """起動が完了してリクエストを受け取れる状態か。"""
    if not getattr(request.app.state, "ready", False):
        # 起動中
        from fastapi import HTTPException
        raise HTTPException(503, "not ready")
    return {"status": "ready"}
```

lifespan の startup 完了時に `app.state.ready = True` をセットする。

## 依存先の状態を見せたい場合

監視ダッシュボード用に **`/healthz/deep`** のような診断用エンドポイントを別に作る。
**load balancer は触らない**:

```python
@router.get("/healthz/deep", tags=["health"])
async def healthz_deep(request: Request) -> dict[str, object]:
    """依存先の疎通も含む詳細ヘルスチェック。監視用。"""
    settings = request.app.state.settings

    return {
        "status": "ok",
        "checks": {
            "openai": await _check_openai(settings),
            "anthropic": await _check_anthropic(settings),
        },
    }

async def _check_openai(settings: Settings) -> dict[str, object]:
    try:
        # ping 的な短いリクエスト
        ...
        return {"ok": True}
    except Exception as e:
        return {"ok": False, "error": str(e)}
```

このエンドポイントは:
- 認証必須にする（公開すると秘密漏洩のリスク）
- load balancer の prove 設定からは外す
- 監視 / 運用エンジニア向け

## やってはいけないこと

```python
# ❌ DB 接続を毎回確認
@router.get("/healthz")
async def healthz(db: DbDep):
    await db.execute("SELECT 1")   # DB 落ちたら ALB が prove 失敗、Pod kill 連鎖
    return {"ok": True}

# ❌ ヘルスチェックで外部 API を叩く
@router.get("/healthz")
async def healthz():
    await openai_client.chat(...)   # 課金もコスト効率も悪い

# ❌ status だけでなく余計な情報を返す
@router.get("/healthz")
async def healthz():
    return {
        "version": ...,
        "uptime": ...,
        "db_status": ...,
        "queue_depth": ...,
    }
    # ↑ /readyz や別エンドポイントへ
```
