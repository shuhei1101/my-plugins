# Markdown 編集規約

## フロントマターの配置

> ファイルに YAML フロントマター（`---` ブロック）がない場合は、このリファレンスを無視してください。

YAML フロントマターを持つ Markdown ファイルでは、**開き `---` より前に何も置いてはならない** —
HTML コメントも、空行も、何も。多くのレンダラーは `---` がファイルの先頭行にある場合のみ
YAML ブロックとして認識し、それ以外はフロントマターを本文として描画してしまう。

## `---`について
マークダウン内で指定がない場合、`---`による区切り線は使わないこと。

## `**`について
マークダウンで指定がない場合、`**`による太字や`*`による斜め文字は使わないこと（見づらいし、編集しづらいから）
`>`これもあんまり使わないでください。

## 一行の長さについて
- 一行は長くなりすぎないようにする
  - 長くなる場合は箇条書きにするか、改行する
