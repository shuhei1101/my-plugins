## 概要

## 旧称ナンバリング禁止 (LLM タスク識別子)

`T1`/`T2`/`T3`/`TC` 等の LLM タスク旧称ナンバリング識別子はコード全領域（コード・コメント・ログ・YAML・identifier）で禁止。
物理 ID (`progression_management` / `response_generation` / `media_selection` / `comment_classification`) を使う。

### 検証 grep

```bash
grep -rn -iE '\b(t[1-8]|tc|t[1-9]_[a-z]+):\s' src/ frontend/ prompts/ config/ tools/ .claude/rules/
```

- `-i` フラグで大文字小文字両方を検出する（`t2:` / `T2:` いずれも引っかかる）
- 0 件を維持すること
