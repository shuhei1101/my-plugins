## 概要

タイムスタンプ表示は **JST (Asia/Tokyo) 統一**。UTC のまま画面・ログに出すと
「昨日のデータに見える」誤認を確実に起こす

## ルール

| 場所                                                                  | 規約                                                                        |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| **ストレージ** (`*.jsonl` / `*.yaml` / DB)                            | UTC タイムゾーン付き ISO8601 (`2026-05-24T05:18:02+00:00`) — 標準慣行を維持 |
| **UI 表示** (HTML / dev 画面)                                         | **JST に変換** (`05/24 14:18:02 JST` 形式)                                  |
| **CLI / バッチログ** (ユーザーが目で見るログ)                         | JST タイムゾーン付き or UTC でも `+00:00` 明示                              |
| **コミット message / PR タイトル / コメント / `.work/notes/` の日付** | **JST 日付** で表現 (例: 「2026-05-24 に発生した障害」)                     |

## 編集時の注意

### Python (ストレージ → 表示変換)

```python
from datetime import datetime
from zoneinfo import ZoneInfo

dt_utc = datetime.fromisoformat("2026-05-23T20:18:02+00:00")
dt_jst = dt_utc.astimezone(ZoneInfo("Asia/Tokyo"))
print(dt_jst.strftime("%Y/%m/%d %H:%M:%S JST"))   # 2026/05/24 05:18:02 JST
```

- `datetime.now()` 禁止 → `datetime.now(timezone.utc)` を使う (timezone-naive は予測不能)
- 比較や差分計算は UTC で。表示直前のみ JST に変換

### JavaScript / TypeScript (UI 表示)

```js
const fmt = new Intl.DateTimeFormat("ja-JP", {
  timeZone: "Asia/Tokyo",
  month: "2-digit", day: "2-digit",
  hour: "2-digit", minute: "2-digit", second: "2-digit",
  hour12: false,
});
fmt.format(new Date("2026-05-23T20:18:02+00:00"));   // "05/24 05:18:02"
```

- `toString()` / `toLocaleString()` (引数なし) はブラウザ実行環境の TZ に依存して不安定 → 上記 `Intl.DateTimeFormat` パターンで明示

### YAML / JSONL / 設定ファイル

- 保存値は UTC ISO8601 のまま。表示する時に変換。
- ファイル名にタイムスタンプを入れる時は **JST 日付** (`20260524_xxx.yaml`) を使う

## 検証

```bash
# UTC タイムゾーンを生で表示している箇所を grep (新規違反検出)
grep -rn -E '\+00:00|T[0-9]{2}:[0-9]{2}:[0-9]{2}Z' frontend/dev/ frontend/js/page/ \
  | grep -v 'localizeSource\|toJstLabel\|Asia/Tokyo'
```

UTC 文字列が画面に直接出ているコードがあれば疑う。`Intl.DateTimeFormat` か
`localizeSource()` 系ヘルパーを経由するべき。
