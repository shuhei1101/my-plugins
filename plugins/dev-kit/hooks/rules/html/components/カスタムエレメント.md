# カスタムエレメント

共通 UI は Light DOM の autonomous custom element で作る。Shadow DOM は使わない（既存のグローバル CSS とデザイントークンをそのまま効かせるため）。

- セットアップは `connectedCallback` で（constructor ではなく）。
- 中身は `innerHTML` か `<template>` のクローンで組む。
- 属性で見た目・状態を切り替え、`attributeChangedCallback` で反映（`observedAttributes` に列挙）。
- `is` 属性は使わない（naming/カスタムエレメント）。

共通化の置き場所は使う範囲がいちばん狭い階層に置く（全体 = `shared/js/components/`、ドメイン内 = `pages/{domain}/_shared/`、画面内 = `pages/{screen}/_shared/`）。範囲が広がったら上の階層へ昇格する。
