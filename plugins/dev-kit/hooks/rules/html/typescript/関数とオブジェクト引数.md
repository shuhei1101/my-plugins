# 関数とオブジェクト引数（汎用 TypeScript）

依存は引数で注入する。差し替えたいものは関数型エイリアス（`型システム.md`）で契約を定義し、引数で渡す。

## オブジェクト引数

引数が 2 つ以上、または真偽値・ID が並ぶときはオブジェクトで受ける。位置引数の順序依存をなくし、呼び出し側が読みやすくなる。

```ts
// ✅ オブジェクト引数
const fetchComments = ({ resourceId, page }: { resourceId: string; page: number }) => { /* ... */ }

// ❌ 位置引数が並ぶ
const fetchComments = (resourceId: string, page: number, includeHidden: boolean) => { /* ... */ }
```

## 関数型での依存注入

関数型エイリアスで契約を定義し、引数で渡す。実体もモックも同じ型で渡せる（テストが楽）。

```ts
type Fetcher = (id: string) => Promise<Detail>

const makeLoader = (fetch: Fetcher) => ({
  load: (id: string) => fetch(id),
})

const loader = makeLoader(realFetcher)
const testLoader = makeLoader(async () => mockDetail)
```

クラスベースの DI（interface 実装 + コンストラクタ注入）より軽い。型で契約を縛りつつ関数で渡す。
