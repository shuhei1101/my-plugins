# CSS コメント

全ての CSS セレクタ（クラス・要素・擬似クラス等）にコメントを書く。コメントはセレクタの直上に置く。

## 書くべき内容

- そのクラスが何に使われるか（用途・役割）
- デザイン上の意図や挙動（なぜこの値か）
- 修飾クラス（`--primary` 等）はベースクラスとの違いだけ書く

## 書き方

```css
/* ボタン共通: 横並び・中央揃え・ホバー時のトランジション */
.button {
  display: inline-flex;
  ...
}

/* primary: 塗りつぶし青ボタン（主要アクション） */
.button--primary {
  background: var(--color-primary);
  ...
}

/* 無効状態: 半透明 + ポインター無効 */
.button:disabled {
  opacity: 0.5;
  ...
}
```

## 注意

- `:hover` / `:focus` 等の状態セレクタはベースクラスの「続き」なので、用途が自明なら省略可。
- `/* ... */` 形式のみ使用（`//` は CSS の正規コメントではない）。
