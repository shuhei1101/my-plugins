# エラーは握りつぶさない

例外は基本キャッチしない。伝播させる。エラーで画面が落ちてよい。落ちた方が開発者がすぐ気づけ、放置を防げる。

禁止:
- `catch` して握りつぶす（何もしない / 続行する）
- ログだけ出して続行する（握りつぶしの言い訳にログを使わない）
- フォールバックで隠す（隠れると気づけないまま実装が放置される）

`catch` してよいのは、その例外をプログラム的に処理する明確な理由がある時だけ。リトライ・代替処理など、処理した上で正しく次に進む場合に限る。「念のため」の catch は書かない。
