# ユニットテスト（vitest）

vitest + jsdom で素の ES modules を直接テストする。React プラグインは使わない。

- 対象ファイルと同じ階層に `{name}.test.ts` で置く（`shared/lib/fmt.test.ts` 等）。
- `.ts` で著作する（`// @ts-check` は不要）。`import { describe, it, expect } from "vitest"`。
- テスト対象は純関数・派生計算・状態ロジック（DOM や通信に依存しない部分）。`state.ts` や `shared/lib` が主対象。描画の細部は E2E に任せる。
- import 別名 `shared/` は `vitest.config.js` の alias で解決される（相対パスに直さない）。
- `location` 等のブラウザ API を使う関数は jsdom 環境で動く。時刻系は固定日時を渡して JST 変換を検証する（`dev/タイムスタンプ規約`）。
- mock は最小限。本物の関数の振る舞いを検証する。
