# `<LoadingButton>` — 非同期処理向けボタン

クリックで非同期処理を起こすボタン。`loading` 中は disable + spinner 表示。

---

## 実装

```tsx
'use client'

import { Loader2 } from "lucide-react"
import { Button, type ButtonProps } from "./ui/button"

type Props = ButtonProps & {
  /** ロード中（disable + spinner 表示） */
  isLoading?: boolean
}

export const LoadingButton = ({ isLoading, disabled, children, ...rest }: Props) => (
  <Button disabled={isLoading || disabled} {...rest}>
    {isLoading && <Loader2 className="mr-2 h-4 w-4 animate-spin" />}
    {children}
  </Button>
)
```

---

## 使い方

```tsx
const [isPending, startTransition] = useTransition()

<LoadingButton
  isLoading={isPending}
  onClick={() => startTransition(async () => { await someAction() })}
>
  実行
</LoadingButton>
```

`<form>` 内では shadcn の `useFormStatus` も使える:

```tsx
import { useFormStatus } from "react-dom"

const SubmitButton = () => {
  const { pending } = useFormStatus()
  return <LoadingButton isLoading={pending} type="submit">送信</LoadingButton>
}
```

---

## ルール

- mutation を伴うボタンには **必ず使う**（非同期 onClick で `<Button>` を直接使わない）
- `isPending` (useTransition) や mutation の loading フラグを渡す
- spinner は `lucide-react` の `Loader2`
- loading 中は disable して重複クリックを物理的にブロック（disable せず spinner だけ出さない）
