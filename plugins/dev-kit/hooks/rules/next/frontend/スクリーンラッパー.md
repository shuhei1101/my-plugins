# `<ScreenWrapper>` — Screen の必須外殻

全 Screen（List / View / Edit / New）の最外殻。`relative max-w-screen-xl mx-auto p-4 md:p-6`。

- `isLoading` 時に半透明オーバーレイ（mutation 中のみ。他のロードは `<Skeleton>` / `loading.tsx`）
- `className` で個別 padding 等を上書き可能
- 多重 wrap しない
