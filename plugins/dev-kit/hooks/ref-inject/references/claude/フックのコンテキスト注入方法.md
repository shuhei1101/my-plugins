# フックのコンテキスト注入方法

```json
// ============================================================
// PreToolUse
// ============================================================
{
  "hookSpecificOutput": {
    "hookEventName": "PreToolUse",        // 必須：イベント名
    "permissionDecision": "allow",        // "allow" / "deny" / "ask" / "defer"
    "permissionDecisionReason": "理由",   // allow/ask → ユーザーに表示、deny → Claudeに表示
    "updatedInput": {                     // ツールの入力を書き換える（オブジェクト全体置換）
      "file_path": "/new/path.ts",
      "content": "書き換えた内容"
    },
    "additionalContext": "Claudeへ注入するテキスト"  // コンテキスト注入
  }
}

// ============================================================
// PostToolUse（制御はトップレベル、注入はhookSpecificOutput）
// ============================================================
{
  "decision": "block",    // "block" のみ。省略すれば続行
  "reason": "理由",       // Claudeに表示
  "hookSpecificOutput": {
    "hookEventName": "PostToolUse",
    "additionalContext": "Claudeへ注入するテキスト"
  }
}

// ============================================================
// SessionStart
// ============================================================
{
  "hookSpecificOutput": {
    "hookEventName": "SessionStart",
    "additionalContext": "セッション開始時にClaudeへ注入するテキスト",
    "initialUserMessage": "最初のユーザーメッセージとして挿入（-pモード用）",
    "sessionTitle": "セッションタイトル",
    "watchPaths": ["/path/to/watch"],   // FileChangedで監視するパス
    "reloadSkills": true                // SessionStart後にスキルを再スキャン
  }
}

// ============================================================
// Stop / SubagentStop（制御はトップレベル、注入はhookSpecificOutput）
// ============================================================
{
  "decision": "block",    // "block" で停止を阻止して会話継続
  "reason": "理由",
  "hookSpecificOutput": {
    "hookEventName": "Stop",
    "additionalContext": "ターン終了時にClaudeへ注入するテキスト"
  }
}

// ============================================================
// PermissionRequest
// ============================================================
{
  "hookSpecificOutput": {
    "hookEventName": "PermissionRequest",
    "decision": {
      "behavior": "allow",              // "allow" / "deny"
      "updatedInput": {                 // allowのみ：ツール入力を書き換え
        "command": "npm run lint"
      },
      "updatedPermissions": [],         // allowのみ：パーミッションルールを追加
      "message": "拒否理由",            // denyのみ：Claudeへ
      "interrupt": true                 // denyのみ：trueでClaudeを停止
    }
  }
}

// ============================================================
// PermissionDenied
// ============================================================
{
  "hookSpecificOutput": {
    "hookEventName": "PermissionDenied",
    "retry": true   // trueでモデルに再試行を許可
  }
}

// ============================================================
// MessageDisplay
// ============================================================
{
  "hookSpecificOutput": {
    "hookEventName": "MessageDisplay",
    "displayContent": "画面表示を置換するテキスト（トランスクリプトは変わらない）"
  }
}

// ============================================================
// Elicitation / ElicitationResult
// ============================================================
{
  "hookSpecificOutput": {
    "hookEventName": "Elicitation",
    "action": "accept",           // "accept" / "decline" / "cancel"
    "content": {                  // acceptのときフォームフィールドの値
      "field_name": "value"
    }
  }
}

// ============================================================
// 全イベント共通（トップレベル）
// ============================================================
{
  "continue": false,              // falseでClaudeを完全停止
  "stopReason": "停止理由",       // continue:false のときユーザーに表示
  "suppressOutput": true,         // trueでstdoutをトランスクリプトに出さない
  "systemMessage": "警告メッセージ",  // ユーザーへの警告
  "terminalSequence": "\033]9;..."    // ターミナル通知用エスケープシーケンス
}
```

# hookSpecificOutput の全フィールド

## 共通必須フィールド
| フィールド      | 説明                                                       |
| --------------- | ---------------------------------------------------------- |
| `hookEventName` | どのイベントの出力かを示す文字列。必須。例: `"PreToolUse"` |

---

## イベント別フィールド

### PreToolUse
| フィールド                 | 説明                                                                 |
| -------------------------- | -------------------------------------------------------------------- |
| `permissionDecision`       | `"allow"` / `"deny"` / `"ask"` / `"defer"`                           |
| `permissionDecisionReason` | allow/askはユーザーに表示、denyはClaudeに表示                        |
| `updatedInput`             | ツールの入力パラメータを実行前に書き換える（オブジェクト全体を置換） |
| `additionalContext`        | Claudeのコンテキストに文字列を追加注入                               |

### PostToolUse
| フィールド          | 説明                                         |
| ------------------- | -------------------------------------------- |
| `additionalContext` | Claudeのコンテキストにツール結果と並べて追加 |
※ ブロックは `decision: "block"` / `reason` をトップレベルに置く（hookSpecificOutput不要）

### SessionStart / Setup / SubagentStart
| フィールド          | 説明                                         |
| ------------------- | -------------------------------------------- |
| `additionalContext` | セッション開始時にClaudeのコンテキストに追加 |

SessionStart固有:
| フィールド           | 説明                                                             |
| -------------------- | ---------------------------------------------------------------- |
| `initialUserMessage` | 最初のユーザーメッセージとして挿入（非インタラクティブモード用） |
| `sessionTitle`       | セッションタイトルを設定                                         |
| `watchPaths`         | FileChangedイベントで監視するパスの配列                          |
| `reloadSkills`       | `true`にするとSessionStart後にスキルを再スキャン                 |

### Stop / SubagentStop
| フィールド          | 説明                                                         |
| ------------------- | ------------------------------------------------------------ |
| `additionalContext` | ターン終了時にClaudeに追加フィードバック（会話が継続される） |
※ ブロックは `decision: "block"` / `reason` をトップレベルに置く

### PermissionRequest
| フィールド                    | 説明                                |
| ----------------------------- | ----------------------------------- |
| `decision.behavior`           | `"allow"` / `"deny"`                |
| `decision.updatedInput`       | allow時：ツール入力を書き換え       |
| `decision.updatedPermissions` | allow時：パーミッションルールを追加 |
| `decision.message`            | deny時：Claudeに理由を伝える        |
| `decision.interrupt`          | deny時：`true`でClaudeを停止        |

### PermissionDenied
| フィールド | 説明                         |
| ---------- | ---------------------------- |
| `retry`    | `true`でモデルに再試行を許可 |

### MessageDisplay
| フィールド       | 説明                                                   |
| ---------------- | ------------------------------------------------------ |
| `displayContent` | 画面表示テキストを置換（トランスクリプトは変わらない） |

### WorktreeCreate
| フィールド     | 説明                                       |
| -------------- | ------------------------------------------ |
| `worktreePath` | worktree作成先のパスを返す（HTTPフック用） |

### Elicitation
| フィールド | 説明                                  |
| ---------- | ------------------------------------- |
| `action`   | `"accept"` / `"decline"` / `"cancel"` |
| `content`  | acceptの場合、フォームフィールドの値  |

### ElicitationResult
| フィールド | 説明                                           |
| ---------- | ---------------------------------------------- |
| `action`   | `"accept"` / `"decline"` / `"cancel"`          |
| `content`  | acceptの場合、フォームフィールドの値（上書き） |

---

## hookSpecificOutput を使わないイベント（トップレベルで完結）
| イベント            | 使うフィールド                                                     |
| ------------------- | ------------------------------------------------------------------ |
| UserPromptSubmit    | `decision: "block"`, `reason`, `additionalContext`, `sessionTitle` |
| UserPromptExpansion | `decision: "block"`, `reason`, `additionalContext`                 |
| PostToolBatch       | `decision: "block"`, `reason`                                      |
| ConfigChange        | `decision: "block"`, `reason`                                      |
| PreCompact          | `decision: "block"`, `reason`                                      |

---

## 全イベント共通（hookSpecificOutput の外、トップレベル）
| フィールド         | 説明                                                            |
| ------------------ | --------------------------------------------------------------- |
| `continue`         | `false`でClaudeを完全停止                                       |
| `stopReason`       | `continue: false`のときユーザーに表示                           |
| `suppressOutput`   | `true`でhookのstdoutをトランスクリプトに出さない                |
| `systemMessage`    | ユーザーへの警告メッセージ                                      |
| `terminalSequence` | ターミナル通知用エスケープシーケンス（OSC 0/1/2/9/99/777, BEL） |
