# app/(shared)/providers/QueryProvider.tsx — TanStack Query 設定

QueryClient のグローバル設定。`app/layout.tsx` から wrap する。

---

## 必須テンプレ

```tsx
// app/(shared)/providers/QueryProvider.tsx
'use client'

import { QueryClient, QueryClientProvider } from "@tanstack/react-query"
import { useState } from "react"

export const QueryProvider = ({ children }: { children: React.ReactNode }) => {
  const [client] = useState(() => new QueryClient({
    defaultOptions: {
      queries: {
        staleTime: 0,                       // 常にサーバーを真実扱い（PR135、QA-051）
        gcTime: 5 * 60 * 1000,              // メモリキャッシュ 5 分保持
        refetchOnWindowFocus: false,
        refetchOnReconnect: true,
        retry: false,
      },
      mutations: {
        retry: false,
      },
    },
  }))
  return <QueryClientProvider client={client}>{children}</QueryClientProvider>
}
```

## ルート layout で wrap

```tsx
// app/layout.tsx
import { QueryProvider } from "@/app/(shared)/providers/QueryProvider"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ja">
      <body>
        <QueryProvider>
          {/* 他の Provider も入れ子に */}
          {children}
        </QueryProvider>
      </body>
    </html>
  )
}
```

---

## defaultOptions の解説

| Option | 値 | 理由 |
|---|---|---|
| `staleTime` | `0` | 常にサーバーを真実扱い。古いデータを見せる事故を防ぐ（PR135） |
| `gcTime` | `5 * 60 * 1000` | メモリキャッシュは 5 分（再ナビゲーションで即表示） |
| `refetchOnWindowFocus` | `false` | ウィンドウフォーカスで毎回フェッチしない |
| `refetchOnReconnect` | `true` | ネットワーク復帰時はフェッチ |
| `retry` | `false` | 失敗を即エラー表示（個別 hook で override 可能） |

特定 hook で staleTime を伸ばす:

```ts
useQuery({
  queryKey: ["categories"],
  queryFn: getCategories,
  staleTime: 60 * 60 * 1000,    // マスターは 1 時間 fresh
})
```

## SSR との連携

Server Component で初期データを取得して `initialData` で hydrate する戦略（`useQueryパターン.md` 参照）。
複雑な hydrate（`dehydrate` / `HydrationBoundary`）が必要なら別途検討。

## ルール

- QueryClient は **`useState(() => new QueryClient(...))`** で初期化（SSR で複数 instance 防止）
- グローバル `staleTime: 0`（PR135、QA-051）。個別 hook で override 可能
