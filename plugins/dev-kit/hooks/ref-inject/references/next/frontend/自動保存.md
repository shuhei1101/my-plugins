# Next.js App Router — Autosave Pattern

> **対象**: 編集中のフォームを自動保存したい画面（長文編集、設定画面、ノート編集など）。
> **Stack**: react-hook-form + Server Action + debounce + 楽観 UI。

---

## 設計方針

| 観点 | 方針 |
|---|---|
| 保存トリガ | 値の変更後 500ms-2s debounce（ユーザーが入力を止めたら） |
| 保存先 | Server Action（または PATCH route） |
| 楽観 UI | 「保存中…」→「保存しました」→（無操作時）非表示 |
| 失敗時 | toast.error + retry ボタン |
| 離脱検知 | dirty 状態で離脱しようとしたら beforeunload 警告 |
| ネットワーク復帰 | online イベントで自動 retry |
| draft 保存 | localStorage に最後の draft を退避（オプション） |

---

## 全体構造

```
useAutosave({ values, save, debounceMs }) → {
  status: "idle" | "saving" | "saved" | "error",
  retry: () => void,
  lastSavedAt: Date | null,
}
```

`status` を画面に表示し、ユーザーに状態を可視化する。

## useAutosave hook

```ts
// app/(shared)/hooks/useAutosave.ts
'use client'

import { useEffect, useRef, useState } from "react"

type Status = "idle" | "saving" | "saved" | "error"

type Args<T> = {
  values: T
  save: (v: T) => Promise<void>
  /** 何 ms 後に保存するか */
  debounceMs?: number
  /** 値が比較で同じなら保存しない */
  isEqual?: (a: T, b: T) => boolean
  /** dirty チェック関数（保存対象として有効か） */
  isValid?: (v: T) => boolean
}

const defaultEqual = <T,>(a: T, b: T) => JSON.stringify(a) === JSON.stringify(b)

export const useAutosave = <T>({ values, save, debounceMs = 1000, isEqual = defaultEqual, isValid }: Args<T>) => {
  const [status, setStatus] = useState<Status>("idle")
  const [lastSavedAt, setLastSavedAt] = useState<Date | null>(null)
  const lastSavedRef = useRef<T>(values)
  const timerRef = useRef<ReturnType<typeof setTimeout> | null>(null)
  const inflightRef = useRef<Promise<void> | null>(null)

  // online イベントで retry
  useEffect(() => {
    const onOnline = () => { if (status === "error") triggerSave() }
    window.addEventListener("online", onOnline)
    return () => window.removeEventListener("online", onOnline)
  }, [status])

  const triggerSave = () => {
    if (isValid && !isValid(values)) return
    if (isEqual(values, lastSavedRef.current)) return

    setStatus("saving")
    const promise = save(values)
    inflightRef.current = promise

    promise
      .then(() => {
        if (inflightRef.current !== promise) return     // 古いリクエストの結果は捨てる
        lastSavedRef.current = values
        setStatus("saved")
        setLastSavedAt(new Date())
        // 数秒後に "idle" に戻す
        setTimeout(() => setStatus((s) => (s === "saved" ? "idle" : s)), 2000)
      })
      .catch(() => {
        if (inflightRef.current !== promise) return
        setStatus("error")
      })
  }

  useEffect(() => {
    if (timerRef.current) clearTimeout(timerRef.current)
    timerRef.current = setTimeout(triggerSave, debounceMs)
    return () => { if (timerRef.current) clearTimeout(timerRef.current) }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [values])

  return { status, lastSavedAt, retry: triggerSave }
}
```

## 使用例（Notes 編集画面）

```tsx
'use client'

import { useForm } from "react-hook-form"
import { zodResolver } from "@hookform/resolvers/zod"
import { Form, FormField, FormItem, FormControl } from "@/app/(shared)/components/ui/form"
import { Textarea } from "@/app/(shared)/components/ui/textarea"
import { useAutosave } from "@/app/(shared)/hooks/useAutosave"
import { AutosaveIndicator } from "@/app/(shared)/components/AutosaveIndicator"
import { updateNoteAction } from "../actions"

export const NoteEditScreen = ({ note }: Props) => {
  const form = useForm<NoteFormType>({
    resolver: zodResolver(NoteFormSchema),
    defaultValues: { title: note.title, body: note.body },
    mode: "onChange",
  })

  const values = form.watch()
  const { status, lastSavedAt, retry } = useAutosave({
    values,
    save: async (v) => {
      const result = await updateNoteAction(note.id, v)
      if (!result.ok) throw new Error(result.error.message)
    },
    debounceMs: 1000,
    isValid: () => form.formState.isValid,
  })

  return (
    <Form {...form}>
      <div className="flex items-center justify-between">
        <h2 className="text-xl font-semibold">ノート編集</h2>
        <AutosaveIndicator status={status} lastSavedAt={lastSavedAt} onRetry={retry} />
      </div>

      <FormField name="title" control={form.control} render={({ field }) => (
        <FormItem><FormControl><input className="text-2xl font-bold w-full" {...field} /></FormControl></FormItem>
      )} />

      <FormField name="body" control={form.control} render={({ field }) => (
        <FormItem><FormControl><Textarea rows={20} {...field} /></FormControl></FormItem>
      )} />
    </Form>
  )
}
```

## AutosaveIndicator コンポーネント

```tsx
// app/(shared)/components/AutosaveIndicator.tsx
'use client'

import { Check, Loader2, AlertCircle } from "lucide-react"
import { Button } from "./ui/button"
import { formatDistanceToNow } from "date-fns"
import { ja } from "date-fns/locale"

type Props = {
  status: "idle" | "saving" | "saved" | "error"
  lastSavedAt: Date | null
  onRetry: () => void
}

export const AutosaveIndicator = ({ status, lastSavedAt, onRetry }: Props) => {
  if (status === "saving") return (
    <span className="flex items-center text-sm text-muted-foreground gap-1">
      <Loader2 className="h-4 w-4 animate-spin" /> 保存中...
    </span>
  )

  if (status === "saved") return (
    <span className="flex items-center text-sm text-green-600 gap-1">
      <Check className="h-4 w-4" /> 保存しました
    </span>
  )

  if (status === "error") return (
    <span className="flex items-center text-sm text-destructive gap-1">
      <AlertCircle className="h-4 w-4" />
      保存失敗
      <Button variant="link" size="sm" onClick={onRetry}>再試行</Button>
    </span>
  )

  // idle: 最終保存時刻を表示
  if (lastSavedAt) return (
    <span className="text-sm text-muted-foreground">
      {formatDistanceToNow(lastSavedAt, { locale: ja, addSuffix: true })}に保存
    </span>
  )

  return null
}
```

## 離脱検知（beforeunload）

dirty 状態で離脱しようとしたら警告を出す:

```ts
// app/(shared)/hooks/useBeforeUnload.ts
'use client'

import { useEffect } from "react"

export const useBeforeUnload = (enabled: boolean, message?: string) => {
  useEffect(() => {
    if (!enabled) return
    const handler = (e: BeforeUnloadEvent) => {
      e.preventDefault()
      e.returnValue = message ?? ""
    }
    window.addEventListener("beforeunload", handler)
    return () => window.removeEventListener("beforeunload", handler)
  }, [enabled, message])
}
```

使用:

```tsx
const { status } = useAutosave({ ... })
useBeforeUnload(status === "saving" || status === "error", "保存中の変更があります。ページを離れますか？")
```

ただしほとんどの場合、autosave がきちんと動いていれば dirty な状態は短時間。離脱検知は **error 状態** の時のみ使うのが推奨。

## Draft の localStorage 退避（オプション）

ネットワークがダウンした場合のフォールバック:

```ts
const [draft, setDraft] = useLocalStorage(`note:${id}:draft`, null)

useEffect(() => {
  if (status === "error" || status === "saving") {
    setDraft(values)            // 保存失敗中は draft も localStorage に
  } else if (status === "saved") {
    setDraft(null)              // 保存成功で draft をクリア
  }
}, [status, values])

// 起動時に draft があれば form に流す
useEffect(() => {
  if (draft) form.reset(draft)
}, [])
```

## Server Action の高速化（cacheLife）

Autosave はリクエストが多くなりがちなので、Server Action 内のキャッシュ制御を最適化:

```ts
'use server'

import { revalidateTag } from "next/cache"

export async function updateNoteAction(id: string, input: NoteFormType) {
  const { db, userId } = await getAuthContext()
  await updateNote({ db, userId, id, data: input })
  revalidateTag(`note:${id}`, "max")    // 自分のキャッシュだけ invalidate
  // refresh() は呼ばない（client router の不必要な再フェッチ防止）
  return { ok: true }
}
```

## Constraints

上記の設計方針表・本文の補足:
- 古いリクエストの結果は無視（inflight ref で判定）
- 離脱検知は **error 状態** のみ（成功する保存に対して beforeunload は出さない）
- Server Action の `refresh()` は呼ばない（client router の再フェッチが autosave のたびに走るのを避ける）
- `cacheLife` プロファイルで stale-while-revalidate 戦略を採用
