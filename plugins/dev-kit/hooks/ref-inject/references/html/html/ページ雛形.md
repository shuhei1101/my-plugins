# ページ雛形

各画面の `index.html` は共通レイアウト（Jinja2 `_layout.html`）を継承し、中身ブロックだけ書く。head・importmap・`<app-shell>`（ヘッダ/サイド/デバッグ FAB）は `_layout` 側に集約する（重複させない）。

- importmap は 1 ドキュメント 1 つ、`<head>` 先頭（最初の `type="module"` より前）。共通 partial から差し込む。
- `<link rel="modulepreload">` はその画面のエントリ + 重要依存のみ。全列挙しない。
- 起動スクリプトは「エントリモジュールを読むだけ」の小さなものに留める。
- インライン `<script>` ブロックや `onclick=` は使わない。外部スクリプト（`screen.ts` から生成した `.js`）+ `addEventListener`。
