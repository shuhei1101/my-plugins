# ビルドレス原則（バンドルしない）

バンドラを使わない。webpack / vite / esbuild などでブラウザ用にバンドル・最適化しない。ネイティブ ES Modules と素の CSS をそのまま配信する。起動を軽く保つのが目的。

ただし TypeScript の型システムを使うため、`tsc` による `.ts` → `.js` のトランスパイル 1 段だけは許可する。これはバンドルではない（1 ファイル 1 出力・依存解決もしない）。生成 `.js` を FastAPI が配信する。詳細は `html/tooling/tsc運用.md`。

開発時のツールは使ってよい。
- 変換 `tsc -p tsconfig.build.json --watch`（`.ts` → 同階層 `.js`）
- 型検査 `tsc -p tsconfig.json --noEmit`
- lint `eslint`（typescript-eslint）
- テスト `vitest` / `playwright`

モジュール解決は import maps、依存の固定は vendoring で行う（バンドルの代わり）。詳細は `html/js/モジュール解決.md`。
