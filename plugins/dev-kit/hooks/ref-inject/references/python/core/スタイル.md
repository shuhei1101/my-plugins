# スタイル

整形・静的解析の設定方針。`pyproject.toml` への記述例は `packaging/pyproject設定.md` 参照。

---

## ツール構成

| ツール | 役割 |
|---|---|
| `ruff` | フォーマッタ + リンタ（black + isort + flake8 相当） |
| `mypy` | 型チェック（CI / 厳格） |
| `pyright` | エディタ統合の高速型チェック（任意） |
| `pytest` | テストランナー |

---

## ruff 推奨設定

`pyproject.toml`:

```toml
[tool.ruff]
line-length = 100
target-version = "py312"

[tool.ruff.lint]
select = [
  "E",    # pycodestyle errors
  "F",    # pyflakes
  "I",    # isort
  "B",    # bugbear（バグになりやすいパターン）
  "UP",   # pyupgrade（古い書き方の自動修正）
  "SIM",  # simplify（簡潔な書き方の提案）
  "RUF",  # ruff 独自
]
ignore = [
  "E501",  # 行長は formatter に任せる
]

[tool.ruff.format]
quote-style = "double"
indent-style = "space"
```

## mypy 推奨設定

```toml
[tool.mypy]
python_version = "3.12"
strict = true
warn_unused_ignores = true
warn_redundant_casts = true
show_error_codes = true
pretty = true

# Pydantic と組み合わせる場合
plugins = ["pydantic.mypy"]
```

`strict = true` に含まれる主な検査:
- `--check-untyped-defs`
- `--disallow-any-generics`
- `--disallow-untyped-defs`
- `--no-implicit-optional`
- `--warn-return-any`

---

## pyright 推奨設定（任意）

`pyproject.toml`:

```toml
[tool.pyright]
pythonVersion = "3.12"
typeCheckingMode = "strict"
reportMissingImports = "error"
reportMissingTypeStubs = "warning"
```

エディタ（VS Code / Cursor）の Pylance と組み合わせて開発時の即時検知に使う。

## 行長

- **100 文字** を標準（black の 88 より少し緩く、可読性重視）
- 例外: URL、長い文字列リテラル、Markdown 内の表

```python
# OK（100 文字以内）
def create_user(input: CreateUserInput, *, save: SaveUser, generate_id: GenerateUserId) -> User:
    ...
```

---

## クォート / 文字列

- ダブルクォート（`"..."`）標準（black / ruff format に合わせる）
- f-string は `f"..."`
- docstring は `"""..."""`
- 文字列内に `"` を含むときはシングルに切り替えても可（`'I said "hi"'`）

## セクションマーカー

長いモジュールでは、ロジックの大きな区切りをセクションマーカーで示してよい。

```python
# ================================================================
# DTO
# ================================================================

@dataclass(frozen=True, slots=True, kw_only=True)
class User: ...


# ================================================================
# Service
# ================================================================

def create_user(input: CreateUserInput, *, save: SaveUser) -> User: ...
```

ただし、**セクションが必要なほど長くなったら、まずファイルを分割**する
（`types.py` / `service.py` に分ける）。セクションマーカーは「分けるほどでもないが見出しが欲しい」ときの最後の手段。
