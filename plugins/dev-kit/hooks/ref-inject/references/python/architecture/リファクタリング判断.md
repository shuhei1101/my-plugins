# リファクタ判断基準

「いつ DRY 化するか」「いつ抽象化するか」「いつ設定外出しするか」の判断基準。

---

## DRY 化判断 — 何回書いたら共通化するか

| トリガー | アクション |
|---|---|
| 1 回目 | そのまま書く |
| **2 回目（コピペが発生）** | **共通化を検討開始**（小さければその場で関数 / 定数化） |
| 3 回目 | **必ず共通化**。`_helpers.py` / `shared/utils.py` / 関数の型エイリアスへ |
| 4 回目以降に発見 | 共通化漏れ。最優先で潰す |

判断補助:
- 「コピペでもう 1 つ書こうとした」瞬間が共通化のサイン
- ロジック行数 ≥ 3 行で再利用候補なら関数化
- 1〜2 行の同じ式は **インライン重複でも OK**（共通化のコストが上回るケース）

---

## 抽象化判断 — いつ Protocol / 型エイリアスを切るか

| 状況 | アクション |
|---|---|
| 実装が 1 個しかない | **抽象化しない**（YAGNI） |
| 実装が **2 個目** が見えた / テスト用 Mock が要る | 関数の型エイリアス（`Callable`）を導入 |
| 実装が **3 個以上** ある or 振る舞いが複雑 | `Protocol` を導入 |
| 拡張ポイントが明確（新 provider 追加が予定済み） | 最初から型エイリアスで抽象化 |

抽象化を増やすコストは「読む人が辿る型ジャンプの増加」。本当に必要かを毎回問う。

詳細パターンは `architecture/TypeScriptスタイル適用.md` の「インターフェース抽象化の 3 段階」。

---

## 設定外出し判断 — いつコードから出すか

| 種別 | 配置先 | 例 |
|---|---|---|
| **環境ごとに変えたい値** | `.env` / `settings.py` | API キー、モデル名、ホスト名 |
| **複数ファイルで参照する固定値** | `shared/constants.py` | `PROJECT_ROOT`、`MAX_RETRY_COUNT` |
| **業務的に固定の選択肢** | `Literal[...]` または `StrEnum` | ステータス、カテゴリ |
| **長文 / 段組み / 多言語** | `prompts/*.md` などファイル | LLM プロンプト、テンプレート |
| **配信者 / 非エンジニアが触る値** | YAML / `settings.yaml` | 表示ラベル、画面パラメータ |

`shared/シークレットと環境変数.md` も参照。

判断補助:
- 「コード変更なしで値を変えたい」 → 設定へ
- 「複数ファイルで同じ値を参照する」 → 定数へ
- 「数値 / 文字列リテラルが意味を持つ」 → 名前を付ける（マジックナンバー禁止）

## ファイル分割判断 — いつファイルを分けるか

| 状況 | アクション |
|---|---|
| 1 ファイル ~200 行 | OK |
| 1 ファイル 200〜400 行 | 内容で分割を検討（types / service / query / route 等の役割別） |
| 1 ファイル 400 行以上 | **分割推奨**。役割か feature で分ける |
| セクションマーカー（`# ===`）が 5 個以上 | 分割サイン |

reference の場合（`*.md`）:
- フック注入単位として「無駄な情報を入れたくない」観点で細かく分ける
- 1 reference 1 トピック原則。複数トピックがあれば分割

## やってはいけないこと

```python
# ❌ 1 回目で抽象化（過剰設計）
class AbstractUserService(Protocol):
    def find(self, id: str) -> User | None: ...

class UserServiceImpl:   # ← 実装が 1 個しかないのに Protocol を切らない
    ...

# ❌ 3 回コピペしたまま放置
def parse_a(raw): return int(raw.strip().replace(",", ""))
def parse_b(raw): return int(raw.strip().replace(",", ""))
def parse_c(raw): return int(raw.strip().replace(",", ""))   # → 共通化必須

# ❌ マジックナンバー
if user.age > 18:   # 18 とは何か？ MIN_ADULT_AGE = 18 へ
    ...

# ❌ 設定値をコードに直書き
OPENAI_MODEL = "gpt-4o-mini"   # → settings.py で env 切替可能に
```
