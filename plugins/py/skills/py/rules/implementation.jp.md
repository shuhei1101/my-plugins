# 実装作業ルール

> **このファイルは日本語ミラーです。Claude には読み込まれません。本体は `implementation.md`。**

## コードを書く前に

1. `wiki/` に仕様書が存在することを確認する。関連する wiki ドキュメントがない、またはリクエストと矛盾している場合は、作業を止めてユーザーに確認する。
2. `wiki/Issues.md` に未解決の Issue が存在する場合は、着手前にユーザーへ通知する。
3. Python コードを書く前に `/py:py` スキルを読む。

## コミット前チェックリスト

- [ ] コード / 設定ファイルを変更した
- [ ] `docs/PR/PR{N}.md` を作成または更新した
- [ ] 実装が文書化済みの動作を変更する場合、wiki ドキュメントを更新した
- [ ] 新しいファイル種別やディレクトリを追加した場合、`.gitignore` を更新した
- [ ] 新しい設計判断を `wiki/Issues.md` または関連フィーチャードキュメントに記録した
