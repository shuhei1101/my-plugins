# claude-kit v3.41.0

## feat: add setup-wizard reference and mandate setup-wizard/plugin-config in every plugin

新規プラグイン作成時の必須スキル規約を拡張し、`setup-wizard` を `plugin-update` と並ぶ必須スキルとして追加した。

### Changes

- 新規: `references/setup-wizard.md` (+ `.jp.md`) — setup-wizard スキルの執筆ガイド。SessionStart フック + `.claude/{plugin}.local.md` の `setup_done` フラグ、AskUserQuestion の options 上限（2〜4 個）、`plugin-config` への委譲、SKILL.md skeleton を含む
- 編集: `references/plugin-structure.md` (+ `.jp.md`) — Required skills セクションに `setup-wizard` と `plugin-config` を追加（`plugin-update` と並べる）
- 編集: `references/index.yaml` (+ `.jp.yaml`) — `setup-wizard.md` のエントリ追加
- 編集: `references/injection_rules.yaml` — `plugin.json` / `marketplace.json` 編集時に `setup-wizard.md` を required 注入

### Behavior

claude-kit のフック自体の挙動は v3.40.0 と同一。プラグイン作成時に注入される執筆ガイドの内容が拡張される。

### Why

各プラグインの env トグル・ユースケースは CLAUDE.md に分散しており、ユーザーが能動的に読まないと初期セットアップに辿りつけなかった。`plugin-update`（バージョン追従）と対になる「初期セットアップ」の規約を `setup-wizard` として明文化することで、新規プラグインが必ず初回オンボーディング体験を提供するようになる。

### Migration

既存プラグインへの `setup-wizard` 追加は別 PR（rollout-setup-wizard-to-existing-plugins）で扱う。
