# v3.19.0 — 2026-05-24

## 変更内容

- **`mark-generated` スキルに HTML / JavaScript / CSS の記法を追加**: Step 3 のファイル種別テーブルに `*.html` / `*.js` / `*.css` を追加。HTML は Markdown と同じ `<!-- ... -->`、JavaScript は `// Generated by ...`、CSS は `/* Generated by ... */`。
- **既存メタデータ検出ロジックを拡張**: 「既にメタデータが存在する場合は置き換える」検出条件を 4 種類のリード文字列（HTML 開きコメント / `#` / `//` / CSS 開きコメント）に対応。
- **ドキュメント例示の正規表現衝突対策**: 検出条件を散文表現に変更（PR94 incidents: `backfill-regex-destroyed-doc-examples` の教訓を反映）。

## 構造の変更

- なし（既存スキル `mark-generated` の Step 3 テーブル拡張のみ）
