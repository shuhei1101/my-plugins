# claude-kit v3.36.0

## refactor: move hook scripts under hooks/scripts/

Aligned with the `hooks/scripts/` layout adopted across all plugins in PR180.

### Changes

- Moved `hooks/inject_references.py` → `hooks/scripts/inject_references.py`
- Added `hooks/scripts/_common.py` — shared helpers (`read_hook_input`, `env_truthy`, `exit_if_stop_loop`, `already_dispatched_this_session`, `emit_block_reason`)
- Added `hooks/scripts/pre_compact.py` — replaces the PreCompact inline python in `hooks.json`; preserves the alternating once-per-cycle token semantics
- `hooks/hooks.json`: all entries now point to `hooks/scripts/...`
- `inject_references.py`: `_plugin_root` fallback now uses `parents[2]` to account for the deeper script location
- Documentation: `CLAUDE.md` (+ jp), `references/CLAUDE.md` (+ jp), `references/environment.md` (+ jp), `references/hooks.md` (+ jp) updated to point at `hooks/scripts/...`

### Behavior

Identical to v3.35.0. Same hook behavior, same env vars (`CLAUDE_KIT_INJECTION_*`), same prompt files.

### Why

See PR180 / glossary entry `split-hook-inline-python-to-scripts` — inline python is fragile under quote nesting and the layout was inconsistent across plugins (workspace was already `hooks/scripts/`, claude-kit / dev-kit were `hooks/` directly).
