# claude-kit v3.32.0

## 変更

注入フックを ref-inject v1.2.0 の **二層キャッシュ**へ同期（テンプレートから再生成）。

- `hooks/inject_references.py`: トークンを `patterns` / `references` の 2 名前空間化。
  複数パターンで共有される `required` リファレンスはセッション中 1 回だけ本文注入し、
  以降のパターンではパスのみ表示する
- `hooks/templates/injection.md.j2` / `injection.jp.md.j2`: `cached` フラグ対応
- `references/CLAUDE.md` / `references/CLAUDE.jp.md`: 二層キャッシュの記述に更新

## 背景

PR159 で claude-kit を ref-inject 形式へ移行したが、その時点のテンプレートは単層
（パターン単位 TTL のみ）だった。PR160 で ref-inject に二層キャッシュを導入したため、
4 つ目の consumer として claude-kit も同期する。claude-kit の creator ガイド（skills.md /
rules.md / claude-md.md など）は複数の編集パスパターンに紐づくものがあり、二層化により
同一ガイド本文の二重注入を防げる（PR160）。
