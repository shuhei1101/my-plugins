# claude-kit v3.47.0

## feat: references/jinja2/authoring.md — Jinja2 template authoring pitfalls

### Background

PR201 (`CLAUDE_KIT_JP_MIRROR` env var) revealed several Markdown rendering bugs in `.j2`
templates caused by `trim_blocks=True` / `lstrip_blocks=True`. Those bugs were fixed in PR201,
but the knowledge was scattered in the branch document. This release consolidates it into a
dedicated reference that gets auto-injected when editing `.j2` files.

### Pitfalls documented

1. Block tag directly above `---` → setext heading (fix: blank line after `%}`)
2. `{{ expr }}` in ATX heading → rendering corruption (fix: append `<!-- -->`)
3. Content immediately after conditional block tag → missing blank line (fix: explicit blank line)
4. Indented block tags → `lstrip_blocks` removes the indentation (fix: indent content lines instead)
