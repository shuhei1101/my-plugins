# v3.33.0 — 2026-05-29

## 変更内容

- **プラグインの環境変数の使い方を専用 reference `references/environment.md`(+jp) として新設**。
  - 設定（`settings.json` の `env` ブロック、ユーザー/プロジェクト/ローカルのスコープ優先順位）→
    読み取り（フック/スクリプトの `os.environ`、デフォルト・検証）の流れ、実例として `*-kit` 注入フックの
    `{PREFIX}_INJECTION_TTL` / `{PREFIX}_INJECTION_LANG`、命名・文書化の慣習、env とパス変数の区別を記載。
  - **env を使えるのは実行されるコード（フック / スクリプト）だけ**で、Markdown（CLAUDE.md / rule /
    SKILL.md）は `os.environ` を読めず *記載する*だけ、という前提を明示。
  - `injection_rules.yaml` で `environment.md` を **全 claude アーティファクトに共通で**紐付け:
    env を実際に設定する `hooks.json` / `settings.json` は `required`（全文）、その他の全 authoring
    パターン（SKILL.md / rule / CLAUDE.md / prompts / plugin・marketplace / glossary / incidents / `**/*.j2`）は
    `optional`（パス + 説明のポインタ）。`index.yaml`(+jp) に追加。matcher は既存の Edit/Write/MultiEdit/Read 維持。
- `references/hooks.md`(+jp) は env を短いポインタ（→ `environment.md`）に。
- `references/plugin-structure.md`(+jp) に「プラグインが読む env 変数はそのプラグインの CLAUDE.md に記載する」慣習を追記。

## 構造の変更

- **追加**: `plugins/claude-kit/references/environment.md`（+`.jp.md`）。`index.yaml`(+jp) と
  `injection_rules.yaml`（hooks.json / settings.json パターン）に登録。
- 注入フック・既存 reference の本文ロジックは不変（ドキュメント追加と配線のみ）。
