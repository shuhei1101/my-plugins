# v3.33.0 — 2026-05-29

## 変更内容

- **プラグインの環境変数の使い方を references に明文化**。
  - `references/hooks.md`(+jp) に「環境変数（`settings.json` の `env`）」セクションを新設。
    `settings.json` の `env` ブロックで設定 → フック/スクリプトが `os.environ` で読む、という流れ、
    ユーザー / プロジェクト / ローカル各スコープの優先順位、読み取り側のデフォルト・検証、そして
    実例として `*-kit` 注入フックの `{PREFIX}_INJECTION_TTL` / `{PREFIX}_INJECTION_LANG` を記載。
    慣習（キーの名前空間化・必ずデフォルト・プラグイン自身の CLAUDE.md に記載・秘密は settings.local.json）も明記。
  - `references/plugin-structure.md`(+jp) に「プラグインが読む env 変数はそのプラグインの CLAUDE.md に記載する」慣習を一言追記。

## 構造の変更

なし（reference ドキュメントの追記のみ。注入フック・injection_rules・index は不変）。
