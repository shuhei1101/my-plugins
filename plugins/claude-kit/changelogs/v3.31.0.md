# v3.31.0 — 2026-05-29

## 変更内容

- **mark-generated を `references/provenance.md` へ資料化し、スキルは薄ラッパー化**。出自スタンプの
  書式仕様（拡張子別コメント・version は plugin.json から・配置・JP ミラー警告・`.json` スキップ・
  既存行置換）の正本を `provenance.md`(+jp) に移管。Claude が Write/Edit する authoring ファイルは
  注入フックが `provenance.md` を届けるので直接スタンプを書く。mark-generated スキルは、フックが
  発火しないケース（ヘルパースクリプト出力・非マッチ型）のフォールバックとして存置（provenance.md に委譲）。
  - claude-kit 自身の呼び出し元（creator 5本・skills.md・common.md・各 SKILL）から
    `/claude-kit:mark-generated` の明示呼び出しを除去。work-kit / html-kit は無変更（薄ラッパーをそのまま呼ぶ）。
- **claude-refactor を薄化**: Step ごとにインライン重複していた判定基準表（フォルダ構成・抽出先・hook
  イベント・ミラー表）を削除し、Step1 で読む `references/` を基準にする形へ。実行ステップも「creator
  スキルを呼べ」から「対象ファイルを直接編集（ガイドは注入される）」へ更新。407行 → 約160行。
- **j2-stamp-check フック削除**: `j2_stamp_check.py` + prompts。`.j2` の出自は `injection_rules.yaml` の
  `**/*.j2` → `provenance.md` 注入でカバー。
- **jp-mirror-check フック削除**: `jp_mirror_check.py`（PostToolUse）+ prompts。JP ミラー同期は
  プロジェクト側の `*-jp-mirror-sync` ルール群で担保。
- `injection_rules.yaml` に `provenance.md` を全 stampable パターン（SKILL.md / rule / CLAUDE.md /
  prompts / glossary / incidents / `**/*.j2`）の required へ追加。`common.md` の出自スタンプ節は
  provenance.md へ移して撤去。

## 構造の変更

- **追加**: `plugins/claude-kit/references/provenance.md`（+`.jp.md`）
- **削除**: `plugins/claude-kit/hooks/j2_stamp_check.py`, `hooks/jp_mirror_check.py`,
  `hooks/prompts/j2-stamp-check.{md,jp.md}`, `hooks/prompts/jp-mirror-check.{md,jp.md}`
- **変更**: `hooks/hooks.json`（PreToolUse は inject_references のみに。PostToolUse セクションを削除。
  PreCompact は維持）、`references/index.yaml`(+jp)、`references/injection_rules.yaml`、
  `references/common.md`(+jp)、`skills/mark-generated/SKILL.md`(+jp)、`skills/claude-refactor/SKILL.md`(+jp)、
  creator 5本(+jp)、`references/skills.md`(+jp)
- 互換性: `/claude-kit:mark-generated` の呼び出しインターフェース（`--plugin/--skill/--file` → スタンプ文字列）は不変。
  work-kit / html-kit からの既存呼び出しはそのまま動作する。
