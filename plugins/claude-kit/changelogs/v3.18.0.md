# v3.18.0 — 2026-05-24

## 変更内容

- **新規スキル `mark-generated`**: 各生成系スキルから呼び出され、ファイル種別（`*.md` / `*.py` / `*.sh` / `*.yaml`）に応じた出自メタデータコメントを返す。`*.jp.md` には JP ミラー警告コメントも返す。`/claude-kit:mark-generated --plugin {p} --skill {s} --file {f}` で起動。
- **新規スキル `version-sync`**: プラグインのバージョン更新時に、`mark-generated` が付与したメタデータを使って古い生成物を検出し、`changelogs/` の差分を反映して再スタンプするスキル。完全自動モード、master/dirty 拒否、ファイル単位でコミット。
- **既存 creator スキルに mark-generated 呼び出しを必須化**: skill-creator / hook-creator / rule-creator / claude-creator / plugin-creator の末尾に「Required: Stamp generated files」セクションを追加し、生成後の出自メタデータ付与を必須化。
- **既存生成物に出自メタデータを遡及的に付与**: 全プラグイン配下の SKILL.md / SKILL.jp.md / ルール / CLAUDE.md / hook の Python ファイル / changelogs / templates にファイル冒頭の HTML/Python コメントを書き込み。

## 構造の変更

- `plugins/claude-kit/skills/mark-generated/` を新規追加（SKILL.md, SKILL.jp.md）
- `plugins/claude-kit/skills/version-sync/` を新規追加（SKILL.md, SKILL.jp.md）
- `plugins/claude-kit/changelogs/` を新規追加（このファイルが最初のエントリ）
