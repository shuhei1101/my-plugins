# claude-kit v3.43.0 — 2026-05-30

## 変更内容

- **`references/` 配下のメタ系 YAML をアンダースコア接頭辞付きにリネーム (PR179)**: `index.yaml` / `index.jp.yaml` / `injection_rules.yaml` を `_index.yaml` / `_index.jp.yaml` / `_injection_rules.yaml` にリネーム。実コンテンツの reference 群と視覚的に分離され、references 一覧の最上部に固定表示される。
- `hooks/scripts/inject_references.py` のファイル名参照と Jinja2 テンプレート (`injection.{md,jp.md}.j2`) のメッセージ、`references/CLAUDE.md` (+ `.jp.md`)・`references/hooks.md` (+ `.jp.md`) のドキュメント記述も追従。
- **ドキュメントの plugin 名整理 (PR179)**: PR166 で `dev-kit` に統合済みの `py-kit` / `next-kit` / `html-kit` を、現役の `*-kit` 例として並列に列挙していた箇所（`CLAUDE.md`、`references/environment.md`、`references/hooks.md` の各 EN/JP）を `dev-kit` / `claude-kit` に書き換え。
