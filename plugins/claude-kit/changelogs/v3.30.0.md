# v3.30.0 — 2026-05-29

## 変更内容

- creator 系スキル（skill / rule / hook / claude / plugin-creator）を **reference 自動注入方式へ全面移行**。
  各スキルのステップ形式の手順知識を `references/` に資料化し、編集対象ファイルに応じて注入する。
- `ref-inject` のリファレンス自動注入機構を claude-kit に適用（`/ref-inject:apply` 相当）。
  - `hooks/inject_references.py` — PreToolUse(Edit/Write/MultiEdit/Read) で編集パスにマッチした reference を注入
  - `hooks/templates/injection.md.j2`（+ `.jp.md.j2`）— 注入テンプレ
  - `references/index.yaml`（+ `index.jp.yaml`）— reference 一覧 + description
  - `references/injection_rules.yaml` — パス → required/optional マッピング
  - `references/CLAUDE.md`（+ `.jp.md`）— 注入構造の説明
- `references/` の各ガイドを「編集時に読めば直接書ける自己完結ガイド」へ拡充
  （skills.md / rules.md / hooks.md / claude-md.md / plugin-structure.md）。各 JP ミラーも更新。
  `plugin-structure.jp.md` を新規作成。`common.md` に出自スタンプ（mark-generated）手順を追加。
- 旧 `creator_dispatch.py` の **creator 系ルール（skill/rule/claude/hook/plugin）を廃止**。
  非 creator 系の `j2-stamp-check` のみ `hooks/j2_stamp_check.py` に切り出して存置。
  creator 系 dispatch prompt 5 種（10 ファイル）を削除。
- creator スキル 5 種を **薄ラッパー化**（「対応 reference を読んで従え + mark-generated」）。
  description / 名前は維持し、`conversation-to-claude` / `notes-to-claude` からの呼び出し互換を保つ。

## 構造の変更

- **追加**: `plugins/claude-kit/hooks/inject_references.py`, `hooks/j2_stamp_check.py`,
  `hooks/templates/injection.md.j2`, `hooks/templates/injection.jp.md.j2`,
  `references/index.yaml`, `references/index.jp.yaml`, `references/injection_rules.yaml`,
  `references/CLAUDE.md`, `references/CLAUDE.jp.md`, `references/plugin-structure.jp.md`
- **削除**: `plugins/claude-kit/hooks/creator_dispatch.py`,
  `hooks/prompts/{skill,rule,claude,hook,plugin}-creator-dispatch.md`（+ `.jp.md`）
- **変更**: `hooks/hooks.json`（inject_references を Edit/Write/MultiEdit/Read に登録、
  creator_dispatch → j2_stamp_check に差し替え。PreCompact / PostToolUse jp_mirror_check は維持）
- 依存: 注入フックは実行プロジェクト側に PyYAML と Jinja2 が必要。
- 言語切替 env: `CLAUDE_KIT_INJECTION_LANG=jp` / TTL 上書き env: `CLAUDE_KIT_INJECTION_TTL`（デフォルト 3600 秒）。
- claude-kit も `*-kit` グロブに一致するため `kit-hooks-index-sync` ルールの対象に自動で含まれる。
