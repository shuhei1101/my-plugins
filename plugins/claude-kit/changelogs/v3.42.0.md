# claude-kit v3.42.0

## feat: CLAUDE_KIT_INJECTION_DISABLE env var を追加

`inject_references.py` に master kill switch を追加した。
`CLAUDE_KIT_INJECTION_DISABLE=true`（または `1` / `yes` / `on`）で注入機構全体を停止できる。

### Changes

- `hooks/scripts/inject_references.py`: `TRUTHY` 定数を追加、`main()` の先頭に kill switch を追加
- docstring に `CLAUDE_KIT_INJECTION_DISABLE` の説明を追記
- `CLAUDE.md` / `CLAUDE.jp.md` に `## Environment Variables` テーブルを追加（DISABLE / TTL / LANG）

### Behavior

`CLAUDE_KIT_INJECTION_DISABLE` が未設定または空文字の場合は従来どおり注入 ON。
truthy 値（`true`/`1`/`yes`/`on`、大文字小文字不問）のときのみ注入をスキップする。

### Why

PR164 で `ref-inject` テンプレートに `{PREFIX}_INJECTION_DISABLE` チェックを追加したが、
claude-kit の実体スクリプトには手動同期が必要だった（PR174）。
各プラグインはテンプレートの独立コピーを持つ設計のため、テンプレ変更は手動で波及させる。
v3.41.0 (PR184) との衝突により v3.42.0 に再バンプ。
