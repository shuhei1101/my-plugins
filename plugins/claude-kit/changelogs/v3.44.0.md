# claude-kit v3.44.0

## feat: references-edit-guard PostToolUse hook

ref-inject v1.6.0 で導入された `references-edit-guard` フックを claude-kit の `hooks/hooks.json` に組み込み。

### Changes

- 新規: `hooks/scripts/references_edit_guard.py`
- 新規: `hooks/prompts/references-edit-guard.md` (+ `.jp.md`)
- 編集: `hooks/hooks.json` — `PostToolUse(Edit/Write/MultiEdit)` 登録

### Behavior

`plugins/claude-kit/references/` 配下の `.md` ファイルが追加・編集された際、`_index.yaml` / `_injection_rules.yaml` への登録漏れを Claude にリマインドする（セッション内 1 回のみ）。

### Why

PR199 で dev-kit の yaml/yaml.md が `_index.yaml` / `_injection_rules.yaml` に未登録だったヒヤリハット事例があった。同種の登録漏れを自動検知する仕組みを ref-inject 経由で全プラグインに展開する。
