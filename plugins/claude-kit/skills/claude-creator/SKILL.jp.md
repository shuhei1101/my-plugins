# SKILL.jp.md — claude-creator スキル（日本語ミラー）

> このファイルは `SKILL.md` の日本語ミラーです。Claude Code には読み込まれません。
> 変更する場合は JP ミラーを先に更新し、その後 `SKILL.md` にも反映してください。

---

**スキル名**: claude-creator
**トリガー**: ユーザーが「CLAUDE.md を作って」「CLAUDE.md を書いて」「クロードのガイドを作りたい」と言ったとき

---

## 概要

プロジェクトの CLAUDE.md とその日本語ミラー CLAUDE.jp.md を作成するスキル。
CLAUDE.md は Claude Code がセッション開始時に読み込むトップレベルの指示ファイル。

---

## 作業内容

### ステップ0: 公式ドキュメントを読む

#### 条件

- 常に — 他の何より先に実行する

#### 処理内容

1. CLAUDE.md に関する公式ドキュメントを読む:
   **https://code.claude.com/docs/en/memory**
2. CLAUDE.md の配置・スコープ・読み込み挙動を確認してから書き始める

→ ステップ1へ進む

---

### ステップ1: プロジェクト情報を収集する

#### 条件

- ステップ0が完了していること

#### 入力

- ユーザーのプロジェクト説明

#### 処理内容

1. ユーザーに以下を確認する:
   - プロジェクト名と概要（1行）
   - ワークフローのステップ（新規タスク開始 → 実装 → 動作確認 → 完了の流れ）
   - 禁止事項（例: 「ユーザー確認なしでマージしない」）
   - `.claude/rules/` ファイルの一覧（あれば）
2. 各フェーズをステップ番号にマッピングする

→ ステップ2へ進む

#### 出力

- プロジェクト概要・ワークフロー・禁止事項・ルール表エントリの一覧

---

### ステップ2: CLAUDE.jp.md を先に書く

#### 条件

- ステップ1が完了していること

#### 処理内容

1. `CLAUDE.jp.md` を日本語でステップ構造に従って書く（参考資料 §構造 参照）
2. 複数ステップから参照される共通資料は `## 参考資料` にまとめる
3. ~200行以内に収める

→ ステップ3へ進む

#### 出力

- `CLAUDE.jp.md` 作成済み

#### 補足

##### 禁止事項

- 英語で書かない（人間向け日本語参照用）
- 200行超の場合は `.claude/rules/` にドメイン固有内容を切り出す

---

### ステップ3: CLAUDE.md に翻訳する（英語）

#### 条件

- CLAUDE.jp.md が完成していること

#### 処理内容

1. CLAUDE.jp.md を行単位で英語に翻訳する
2. `CLAUDE.md` を書く（Claude Code が指示として読み込むファイル）
3. CLAUDE.jp.md と見出し構造・ステップ番号を揃える

→ ステップ4へ進む

#### 出力

- `CLAUDE.md` 作成済み

#### 補足

##### 禁止事項

- 日本語で書かない（Claude Code が直接読む）
- CLAUDE.jp.md と構造がずれないようにする

---

### ステップ4: 最終確認

#### 条件

- 両ファイルが作成済みであること

#### 処理内容

1. 両ファイルの存在と構造の一致を確認する
2. ~200行以内に収まっているか確認する
3. ユーザーにレビューのために提示する

#### 出力

- ユーザーがコミット前に確認できる状態

#### 補足

##### チェックリスト

- [ ] `CLAUDE.md` — 英語、Claude Code が自動ロード
- [ ] `CLAUDE.jp.md` — 日本語ミラー、人間参照用
- [ ] 両ファイルの見出し構造が一致している
- [ ] ~200行以内に収まっている

---

### CLAUDE.md のステップ構造

各セクションはこのパターンに従う:

```markdown
## 概要
（このプロジェクトが何をするか・AIがどう動くべきか — 1〜3文）

## 作業内容

### ステップN: （アクション名）

#### 条件
（このステップに進む前提条件。満たされない場合は中断または分岐。）

#### 入力
（このステップで使うデータ・ファイル・前ステップの出力・ユーザー入力）

#### 処理内容
（具体的にやること。番号付きリスト。コマンドがあれば記載。）
1. Xをする
2. Yをする
   ```bash
   コマンド
   ```
→ ステップN+1へ進む（または <条件> の場合はステップNへ）

#### 出力
（このステップが完了した状態として存在するもの — ファイル・サーバー起動など）

#### 補足
（必要なサブセクションだけ使う）

##### 禁止事項
（このステップでやってはいけないこと）

##### 条件分岐
（「もし〜なら → ステップNへ」「もし〜なら → 中断してユーザーに確認」）

##### 参照ドキュメント
（このステップで使うファイル・URL・参考資料のリンク）

##### チェックリスト
（このステップを完了とみなす前に確認する項目）

---

## 参考資料
（複数ステップから参照される共通の表・定義・リンク集をここにまとめる）
```
