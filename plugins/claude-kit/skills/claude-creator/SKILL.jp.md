# SKILL.jp.md — claude-creator スキル（日本語ミラー）

> このファイルは `SKILL.md` の日本語ミラーです。Claude Code には読み込まれません。
> 変更する場合は JP ミラーを先に更新し、その後 `SKILL.md` にも反映してください。

---

**スキル名**: claude-creator
**トリガー**: ユーザーが「CLAUDE.md を作って」「CLAUDE.md を書いて」「クロードのガイドを作りたい」「このフォルダの CLAUDE.md を作って」と言ったとき

---

## 概要

CLAUDE.md とその日本語ミラー CLAUDE.jp.md を作成するスキル。

CLAUDE.md は2種類の使い方がある:

| 配置場所 | 読み込みタイミング |
|---|---|
| プロジェクトルート | セッション開始時に必ず読み込まれる |
| サブフォルダ | そのフォルダ内のファイルにアクセスしたとき（遅延ロード） |

---

## 作業内容

### ステップ0: 背景資料を読む

#### 条件

- 常に — 他の何より先に実行する

#### 処理内容

1. CLAUDE.md に関する公式ドキュメントを読む:
   **https://code.claude.com/docs/en/memory**

2. ファイルタイプ使い分けガイドを読む（このプラグインの `references/file-types.md`）。
   要点:
   - `CLAUDE.md`（ルート）: セッション常時ロード — プロジェクト全体のワークフロー・規約
   - `CLAUDE.md`（サブフォルダ）: アクセス時に遅延ロード — フォルダの説明・ローカル規約
   - `.claude/rules/`: 対象ファイル読み込み時にロード — 複数フォルダをまたぐ関連ファイルのリンク
   - `.claude/skills/`: 呼び出し時のみ — 複数ステップのワークフロー

→ ステップ1へ進む

---

### ステップ1: 作成内容の情報を収集する

#### 条件

- ステップ0が完了していること

#### 入力

- ユーザーの説明

#### 処理内容

1. ユーザーに以下を確認する:
   - **配置場所** — プロジェクトルート（`CLAUDE.md`）か、特定のサブフォルダか？
   - **ルートの場合**: ワークフローのステップ・禁止事項・フォルダスコープルール表のエントリ
   - **サブフォルダの場合**: このフォルダにあるファイルの役割・ローカル規約
   - **作成内容の概要** — どんな指示・説明を書くか

→ ステップ2へ進む

#### 出力

- 配置場所（ルートまたはサブフォルダパス）・作成内容の概要

---

### ステップ2: ファイルタイプへの適合を確認する

#### 条件

- ステップ1が完了していること

#### 入力

- ステップ1で収集した配置場所と内容の概要
- ファイルタイプ使い分けガイド（このプラグインの `references/file-types.md`）

#### 処理内容

1. 内容が本当に CLAUDE.md に適しているか確認する:

   | 内容が… | 提案 |
   |---|---|
   | 単一フォルダの説明・規約 | ✅ CLAUDE.md（サブフォルダ）— 正しい選択 |
   | プロジェクト全体のワークフロー・規約 | ✅ CLAUDE.md（ルート）— 正しい選択 |
   | 複数の異なるフォルダをまたぐファイル同期 | ⚠️ `.claude/rules/` の方が適切 |
   | 複数ステップのワークフロー・手順 | ⚠️ `.claude/skills/` の方が適切 |
   | 上記の混在 | ⚠️ ファイルタイプを分割することを検討 |

2. 適合していれば確認してステップ3へ進む
3. 適合していなければ理由を説明し、`rules-creator` または `skill-creator` への切り替えを提案する

→ CLAUDE.md が適切と確認できたらステップ3へ進む

#### 出力

- 確認済み: この内容は CLAUDE.md に適している

#### 補足

##### 条件分岐

- rules の方が適切 → 理由を説明し、`rules-creator` への切り替えを提案
- skill の方が適切 → 理由を説明し、`skill-creator` への切り替えを提案
- 混在 → 分割を提案（CLAUDE.md はフォルダ説明部分のみ、残りはrules/skillsへ）

---

### ステップ3: CLAUDE.jp.md を先に書く

#### 条件

- ステップ2で CLAUDE.md が適切と確認済みであること

#### 入力

- ステップ1の配置場所・内容概要

#### 処理内容

1. `CLAUDE.jp.md`（またはサブフォルダの場合 `<フォルダ>/CLAUDE.jp.md`）を日本語でステップ構造に従って書く（参考資料 §構造 参照）
2. 複数ステップから参照される共通資料は `## 参考資料` にまとめる
3. ~200行以内に収める

→ ステップ4へ進む

#### 出力

- `CLAUDE.jp.md` 作成済み

#### 補足

##### チェックリスト

- [ ] 日本語で書いていること（人間向け日本語参照用、英語不可）
- [ ] ~200行以内に収まっていること（超える場合は `.claude/rules/` にドメイン固有内容を切り出す）

---

### ステップ4: CLAUDE.md に翻訳する（英語）

#### 条件

- CLAUDE.jp.md が完成していること

#### 入力

- ステップ3の CLAUDE.jp.md 内容

#### 処理内容

1. CLAUDE.jp.md を行単位で英語に翻訳する
2. `CLAUDE.md` を書く（Claude Code が指示として読み込むファイル）
3. CLAUDE.jp.md と見出し構造・ステップ番号を揃える

→ ステップ5へ進む

#### 出力

- `CLAUDE.md` 作成済み

#### 補足

##### チェックリスト

- [ ] 英語で書いていること（Claude Code が直接読む、日本語不可）
- [ ] CLAUDE.jp.md と見出し構造が一致していること

---

### ステップ5: 最終確認

#### 条件

- 両ファイルが作成済みであること

#### 処理内容

1. 両ファイルの存在と構造の一致を確認する
2. ~200行以内に収まっているか確認する
3. ユーザーにレビューのために提示する

#### 出力

- ユーザーがコミット前に確認できる状態

#### 補足

##### チェックリスト

- [ ] `CLAUDE.md` — 英語、Claude Code が自動ロード
- [ ] `CLAUDE.jp.md` — 日本語ミラー、人間参照用
- [ ] 両ファイルの見出し構造が一致している
- [ ] ~200行以内に収まっている

### CLAUDE.md のステップ構造

各セクションはこのパターンに従う:

```markdown

## 作業内容

### ステップN: （アクション名）

#### 条件
（このステップに進む前提条件。満たされない場合は中断または分岐。）

#### 入力
（このステップで使うデータ・ファイル・前ステップの出力・ユーザー入力）

#### 処理内容
（具体的にやること。番号付きリスト。コマンドがあれば記載。）
1. Xをする
→ ステップN+1へ進む（または <条件> の場合はステップNへ）

#### 出力
（このステップが完了した状態として存在するもの）

#### 補足
（必要なサブセクションだけ使う）

##### チェックリスト
（このステップを完了とみなす前に確認する項目。
「～していること」で必須確認、「～していないこと」で禁止事項も表現できる）

- [ ] ～していること
- [ ] ～していないこと

##### 条件分岐
（「もし〜なら → ステップNへ」「もし〜なら → 中断してユーザーに確認」）

##### 参照ドキュメント
（このステップで使うファイル・URL・参考資料のリンク）

（複数ステップから参照される共通の表・定義・リンク集をここにまとめる）
```
