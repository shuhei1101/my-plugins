# SKILL.jp.md — claude-creator スキル（日本語ミラー）

> このファイルは `SKILL.md` の日本語ミラーです。Claude Code には読み込まれません。
> 変更する場合は JP ミラーを先に更新し、その後 `SKILL.md` にも反映してください。

---

**スキル名**: claude-creator
**トリガー**: ユーザーが「CLAUDE.md を作って」「CLAUDE.md を書いて」「クロードのガイドを作りたい」と言ったとき

---

## 概要

プロジェクトの CLAUDE.md とその日本語ミラー CLAUDE.jp.md を作成するスキル。

CLAUDE.md は Claude Code がセッション開始時に読み込むトップレベルの指示ファイル。
プロジェクトのワークフロー・コミットルール・サーバー管理・フォルダスコープルールの表などを定義する。

作成する構造:

```
## 概要
## 作業内容
  ### ステップN
    #### 条件
    #### 入力
    #### 処理内容
    #### 出力
    #### 補足
      ##### 禁止事項
      ##### 条件分岐
      ##### 参照ドキュメント
      ##### チェックリスト
## 参考資料
```

---

## 作業内容

### ステップ1: プロジェクト情報を収集する

#### 条件

- ユーザーが CLAUDE.md の作成・全面改修を求めているとき

#### 入力

- ユーザーのプロジェクト説明

#### 処理内容

1. ユーザーに以下を確認する:
   - プロジェクト名と概要
   - ワークフローのステップ（新規タスク開始 → 実装 → 動作確認 → マージの流れ）
   - 禁止事項（例: 「ユーザー確認なしでマージしない」）
   - `.claude/rules/` ファイルの一覧（あれば）

2. ワークフローの各フェーズをステップにマッピングする

→ ステップ2へ進む

#### 出力

- プロジェクト名・ワークフロー・禁止事項・ルール表エントリの一覧

---

### ステップ2: CLAUDE.jp.md を先に書く

#### 条件

- ステップ1が完了していること

#### 処理内容

1. `CLAUDE.jp.md` を日本語で書く
2. `### ステップN:` 見出しと `#### 条件 / 入力 / 処理内容 / 出力 / 補足` で構造化する
3. 共通の表・定義は `## 参考資料` にまとめる
4. ~200行以内に収める

→ ステップ3へ進む

#### 出力

- `CLAUDE.jp.md` 作成済み

#### 補足

##### 禁止事項

- 英語で書かない（CLAUDE.jp.md は人間向け日本語参照用）
- 200行を超える場合は `.claude/rules/` にドメイン固有の内容を移す

---

### ステップ3: CLAUDE.md に翻訳する（英語）

#### 条件

- CLAUDE.jp.md が完成していること

#### 処理内容

1. CLAUDE.jp.md を行単位で英語に翻訳する
2. `CLAUDE.md` を書く（Claude Code が実際に読むファイル）

→ ステップ4へ進む

#### 出力

- `CLAUDE.md` 作成済み

#### 補足

##### 禁止事項

- 日本語で書かない（Claude Code が指示として直接読み込む）
- CLAUDE.jp.md と見出し構造を揃える

---

### ステップ4: 確認してコミットする

#### 処理内容

1. 両ファイルの存在と構造を確認する
2. 両方を同じコミットにまとめる

→ 完了

#### 補足

##### チェックリスト

- [ ] `CLAUDE.md` — 英語、Claude Code が自動ロード
- [ ] `CLAUDE.jp.md` — 日本語ミラー、人間参照用
- [ ] 両方を同じコミットに含めた
- [ ] ~200行以内に収まっている

コミットメッセージ: `docs: CLAUDE.md 作成`
