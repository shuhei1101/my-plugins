# サブエージェント委譲ガイド

スキル内のステップ処理をサブエージェントに委譲する方法と判断基準。
英語原本: `references/common/サブエージェント.md`

---

## 委譲マーカー

サブエージェントに委譲するステップの先頭に、以下のいずれかのマーカーを付ける。
戻り値の形式は括弧内に明記する:

| マーカー | 使うとき |
|---|---|
| `[サブエージェントで実行・完了を待つ]` | 単体のサブエージェント、完了を待ってから次へ |
| `[サブエージェントで並列実行・完了を待つ]` | 複数のサブエージェントを並列実行、全完了を待ってから次へ |
| `[サブエージェントで並列実行・完了を待たない]` | 結果不要な場合のみ（稀） |

**記述例:**

```markdown
#### 処理
1. [サブエージェントで並列実行・完了を待つ] .claude/skills/ を Glob し各 description を収集する
   （戻り値: `[{name, description}]`）
→ ステップ 2 へ
```

---

## 委譲の判断基準

| 状況 | 判断 |
|---|---|
| 必要なコンテキストが少ない（会話履歴・ファイル内容をほぼ参照しない） | ✅ サブエージェント向き |
| 単純な変換・書き写し・翻訳など | ✅ サブエージェント向き |
| 同じ処理を複数ファイル・項目に対して並列実行したい | ✅ サブエージェント向き |
| メインエージェントのコンテキスト圧迫を防ぎたい | ✅ サブエージェント向き |
| メインの会話履歴や大量のコンテキストを参照する必要がある | ❌ メインエージェントで実行 |
| サブエージェントの内部処理もメインで必要 | ❌ メインエージェントで実行 |

---

## 制約と注意事項

- **戻り値のみが返る**: サブエージェントの内部処理詳細はメインに返らない。戻り値だけで十分か確認する。
- **完了を待つのがデフォルト**: 完了を待たない（fire-and-forget）は稀。複数並列実行でも全完了を待つのが基本。
- **コンテキストは空**: サブエージェントは会話履歴のない状態で起動する。必要な情報はプロンプトで明示的に渡す。
