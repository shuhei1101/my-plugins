# 環境変数ガイド

プラグインの**実行可能コード**を環境変数で設定可能にする方法。対象は**フックとスクリプト**（`hooks/*.py`、`scripts/*.py`、インライン `-c` フックコマンド）のみ — プロセスとして実行され `os.environ` を読める唯一の部分。Markdown 指示ファイル（`CLAUDE.md`、ルール、`SKILL.md`）はコンテキストに読み込まれるだけで実行されないため、env var を読めない — どの env var をコードが読むかを**ドキュメント化する**のみ。

---

## 設定 — `settings.json` `env` ブロック

Claude Code は `settings.json` の `env` ブロック内のキー/バリューペアを、すべてのフックとツールサブプロセスの環境に export する。3 つのスコープで有効で、後のスコープが前のスコープを上書きする:

| スコープ | ファイル | コミット対象 |
|---|---|---|
| ユーザー | `~/.claude/settings.json` | なし（個人用） |
| プロジェクト（チーム） | `.claude/settings.json` | ✅ git にコミット |
| プロジェクト（ローカル） | `.claude/settings.local.json` | ❌ gitignore 済み |

```json
{
  "env": {
    "MY_KIT_INJECTION_TTL": "7200",
    "MY_KIT_INJECTION_LANG": "jp"
  }
}
```

---

## 読み取り — フック/スクリプト内の `os.environ`

適切なデフォルト値を持ちつつバリデーションしながら読み取る。var が設定されているとは限らない（`env` ブロックはオプション）:

```python
import os

raw = os.environ.get("MY_KIT_INJECTION_TTL")        # 未設定なら None
ttl = int(raw) if raw and raw.isdigit() else 3600   # デフォルト値にフォールバック

lang = os.environ.get("MY_KIT_INJECTION_LANG", "en").lower()
```

> `env` の値はプレーン文字列 — 読み取り側でパース/バリデーション（`int(...)`、`.lower()`、許可リスト）を行う。

---

## 実例（このリポジトリ）

`*-kit` 参照インジェクションフック（dev-kit / claude-kit の `hooks/scripts/inject_references.py`）はこの方法でチューニングされている:

| 環境変数 | 効果 | デフォルト |
|---|---|---|
| `{PREFIX}_INJECTION_TTL` | 参照が再インジェクトされるまでの秒数 | `3600` |
| `{PREFIX}_INJECTION_LANG` | `jp` → 日本語の説明/テンプレートをインジェクト | `en` |

`{PREFIX}` はプラグイン名を大文字化し、英数字以外を `_` に変換したもの（例: `dev-kit` → `DEV_KIT`）。

---

## 規約

- **キーをプラグイン名でネームスペース化する**（`{PREFIX}_...`）— プラグイン間の衝突を防ぐ。
- **読み取り側に必ずデフォルト値を設ける** — env ブロックはオプション。コードはそれなしでも動作しなければならない。
- **プラグインが読む各 env var をプラグイン自身の `CLAUDE.md` にドキュメント化する**（名前・効果・デフォルト）— ユーザーがソースを読まなくても何が設定可能かわかる。
- コミット済みの `.claude/settings.json` にシークレットを入れない — マシン固有または機密の値は `settings.local.json`（gitignore 済み）を使う。
- Markdown ファイル（`CLAUDE.md` / ルール / `SKILL.md`）は env を読めない — 動作を env によって変える必要があるなら、その変化はフックやスクリプトに属し、markdown はそれをドキュメント化するだけ。

---

## パス変数 vs 環境変数

別の仕組み — 混同しないこと:

| | 設定場所 | 読み取り場所 |
|---|---|---|
| **環境変数**（`MY_KIT_*`） | `settings.json` の `env` ブロック | フック/スクリプトの `os.environ` |
| **パス変数**（`${CLAUDE_PLUGIN_ROOT}`、`${CLAUDE_PROJECT_DIR}`） | `hooks.json` / `settings.json` のコマンド引数で Claude Code が展開 | インジェクトされたプロンプトテキストでは展開されない — `フック.md` 参照 |
