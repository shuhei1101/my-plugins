# Jinja2 テンプレート記法 — trim_blocks / lstrip_blocks の既知の罠

英語版: `references/hook/jinja2/執筆ガイド.md`

注入フックは `.j2` テンプレートを `trim_blocks=True` / `lstrip_blocks=True` の両方を有効にした
Jinja2 エンジンでレンダリングする。これらの設定は出力の余分な空白を除去するが、
Markdown レンダリングに関するいくつかの落とし穴を生む。

---

## エンジン設定（変更不可）

```python
Environment(
    trim_blocks=True,    # ブロックタグ %} 直後の改行を削除
    lstrip_blocks=True,  # ブロックタグのみを含む行の先頭空白を削除
)
```

両方が常に有効。以下の各落とし穴はこの 2 つの設定に起因する。

---

## 落とし穴 1 — ブロックタグの直下に `---` を置くと setext 見出しになる

### 現象

```jinja2
{% if optional %}
---          ← 危険: trim_blocks が改行を削除するため、この --- が直前の行に付いてしまう
```

`trim_blocks` が `%}` 直後の改行を削除するため、レンダリング結果では:

```
[if ブロックが生成した何か]
---
```

のように `---` が直前行のすぐ後に続く。Markdown パーサーはこれを setext 見出しのアンダーライン
として解釈し、見出し階層を壊す。

### 対処法 — ブロックタグの後に空行を入れる

```jinja2
{% if optional %}

---          ← 安全: 空行がブロックタグと水平罫線を分離する
```

---

## 落とし穴 2 — ATX 見出し（`## …`）内の `{{ expr }}`

### 現象

```jinja2
## {{ ref.path }} — {{ ref.description }}
```

一部の Markdown レンダラ（Claude Code のプレビューを含む）が `{{ … }}` をコードスパンとして
解釈しようとして表示が崩れる。

### 対処法 — 末尾に `<!-- -->` を追加

```jinja2
## {{ ref.path }} — {{ ref.description }}<!-- -->
```

空の HTML コメントを付けることで、パーサーが行を純粋な ATX 見出しとして扱わなくなり、
setext / 見出し誤解釈を抑制しつつ表示テキストは維持される。

---

## 落とし穴 3 — 条件ブロック内でタグ直下にコンテンツを置く

### 現象

```jinja2
{% if not jp_mirror %}
> 警告テキスト    ← 空行なしに if タグの直後にブロッククォートが来る
{% endif %}
```

`trim_blocks` によって `{% if not jp_mirror %}` 直後の改行が削除され、ブロッククォートが
前の行と結合する形になる。ブロックレベル要素の前に空行を要求するレンダラでは壊れる。

### 対処法 — 開きタグの直後に空行を入れる

```jinja2
{% if not jp_mirror %}

> 警告テキスト
{% endif %}
```

---

## 落とし穴 4 — インデントしたブロックタグはインデントを失う

### 現象

`lstrip_blocks=True` により、ブロックタグのみを含む行の先頭空白はすべて削除される。
インデントされた `{% for %}` ループはインデントされた出力を生まない。

### 対処法 — インデントはコンテンツ行に記述する

出力にインデントが必要な場合は、ブロックタグをインデントするのではなく、
コンテンツ行にリテラルとして記述する:

```jinja2
{% for item in items %}
    - {{ item }}     ← インデントはブロックタグでなくコンテンツ行に付ける
{% endfor %}
```

---

## クイックリファレンス — Do / Don't

| 状況 | Don't | Do |
|---|---|---|
| if/for ブロックの後の水平罫線 | `{% if x %}\n---` | `{% if x %}\n\n---` |
| ATX 見出し内の `{{ expr }}` | `## {{ path }}` | `## {{ path }}<!-- -->` |
| ブロック要素の前に空行が必要 | `{% if x %}\n> text` | `{% if x %}\n\n> text` |
| インデントされた出力 | `{%` タグをインデント | コンテンツ行をインデント |
