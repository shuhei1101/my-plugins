# 出自スタンプガイド

生成・編集したファイルに出自メタデータを刻み、`claude-kit:version-sync` が後で「古いプラグイン
バージョンが作ったファイル」を検出できるようにする方法。このガイドは自己完結 — スタンプ対象ファイルを
編集したときに注入されるので、それに従ってスタンプを直接書けばよい（スキル呼び出し不要）。
英語版: `references/provenance.md`

> Claude が Write/Edit で書かないファイル（ヘルパースクリプトの出力、注入フックの対象外の型など）には、
> `/claude-kit:mark-generated` 薄ラッパースキルが同じ仕様を適用してスタンプ文字列を返す。
> どちらの経路でも下記の仕様が単一の正本。

---

## 何を書くか

ファイル本文の**先頭**に、拡張子に応じた記法で1行コメント:

| 拡張子 / パターン | コメント書式 |
|---|---|
| `*.md` | `<!-- Generated by {plugin}/{skill} v{version} -->` |
| `*.html` | `<!-- Generated by {plugin}/{skill} v{version} -->` |
| `*.py` | `# Generated by {plugin}/{skill} v{version}` |
| `*.sh` | `# Generated by {plugin}/{skill} v{version}` |
| `*.yaml` / `*.yml` | `# Generated by {plugin}/{skill} v{version}` |
| `*.js` | `// Generated by {plugin}/{skill} v{version}` |
| `*.css` | `/* Generated by {plugin}/{skill} v{version} */` |
| `*.j2` | `{# Generated by {plugin}/{skill} v{version} #}`（ref-inject テンプレは既存の `<!-- Generated by ref-inject/apply -->` HTML マーカーでも可） |
| `*.json` | **なし** — JSON はコメント不可。スタンプしない |

- `{plugin}` / `{skill}` = そのファイルを生成したプラグインとスキル（または生成元）。
- `{version}` = `plugins/{plugin}/.claude-plugin/plugin.json` の `version` フィールド。必ず読む（推測しない）。

---

## どこに置くか

- YAML frontmatter（`---` … `---`）がある場合: 閉じ `---` の**直後**に挿入。
- frontmatter が無い場合: **ファイル最上部**に挿入。
- frontmatter の**前に置かない** — `---` の前に HTML コメントがあると Markdown の frontmatter 検出が
  壊れる（`---` が水平線として描画される）。
- その位置に同じ記法の `Generated by …` 行が既にある場合は、重複追加せず**その1行を置換**する。

---

## JP ミラーファイル（`*.jp.md`）

メタデータ行に加え、その直下に次の警告行を入れる（Markdown のみ）:

```
<!-- This file is a Japanese mirror. When updating the English original, update this file too. -->
```

---

## 例

- `SKILL.jp.md`（claude-kit / skill-creator）: HTML コメント2行 — `Generated by claude-kit/skill-creator v{version}` 行、続けて JP ミラー警告行 — を閉じ `---` の直後に。
- `TODO.md`（work-kit / work-start）: 先頭に HTML コメント1行 `Generated by work-kit/work-start v{version}`。
- `stop.py`（claude-kit / hook-creator）: `#` コメント1行 `Generated by claude-kit/hook-creator v{version}`。

---

## なぜ

`version-sync` はこのスタンプを読んで、古いプラグインバージョンが生成した成果物を見つけ最新へ追従させる。
スタンプが無い/誤っていると、古いファイルがその同期から見えなくなる。
