# プラグインバージョン同期不変条件

下記の 3 ファイルは**常に同じバージョン番号**を持ち、同期していなければならない。
絶対にズレを許してはいけない。

---

## 3 ファイルの内訳

| # | ファイル | 更新内容 |
|---|---|---|
| 1 | `plugins/<name>/.claude-plugin/plugin.json` | `version` をバンプ |
| 2 | `.claude-plugin/marketplace.json` | 対応プラグインの `version` をバンプ |
| 3 | `plugins/<name>/CLAUDE.md` | 追加・変更したスキル / フック / env / 動作を反映し `## Changelog` 行を追加 |

---

## コミット前チェックリスト

プラグインへのいかなる変更をコミットする前にも確認する：

- [ ] `plugin.json` バージョンバンプ済み
- [ ] `marketplace.json` バージョンを一致させてバンプ済み
- [ ] `CLAUDE.md` に新バージョンの changelog 行が追加済み

---

## バージョンバンプ規則

| 変更種別 | バンプ |
|---|---|
| バグ修正 / 軽微な修正 | PATCH（`1.x.y` → `1.x.y+1`） |
| 新スキル追加 / 動作変更 | MINOR（`1.x.0` → `1.x+1.0`） |
| 完全な設計見直し | MAJOR（`1.0.0` → `2.0.0`） |

---

## 並行 PR のバージョン衝突

2 つの並行ブランチが同じプラグインをバンプし、片方が先にマージされた場合は、
もう片方のブランチで**次のバージョンへ再バンプ**してからマージする（インシデント `parallel-pr-version-bump-collision` を参照）。
