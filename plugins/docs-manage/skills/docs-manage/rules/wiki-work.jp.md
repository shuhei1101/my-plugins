# Wiki / ドキュメント作業ルール

> **このファイルは日本語ミラーです。Claude には読み込まれません。本体は `wiki-work.md`。**

## マスタードキュメント原則

1事実1ドキュメント。wiki ファイルを編集する前に、同じ内容が他に既に書かれていないか確認する。あればリンクで済ませて重複を避ける。

## フォルダ構成

- wiki ファイルは全て `wiki/` 直下に同一階層で置く。**サブフォルダ禁止。**
- `wiki/home.md` がナビゲーションハブ。すべてのドキュメントは home.md からリンクされていること。

## 追加 / 削除

- 新規 wiki ドキュメントを作成する → `wiki/home.md` に該当セクションのリンクを追加。
- wiki ドキュメントを削除する → `wiki/home.md` のリンクと他ドキュメントのクロスリファレンスを削除。

## wiki ドキュメントの編集

書き込む前にキーワードを `wiki/` 全体で grep して重複がないか確認する。重複がある場合はマスタードキュメント原則を適用：非マスタードキュメントからマスタードキュメントへのリンクに置き換え、内容のコピーは行わない。

```markdown
詳細は [マスタードキュメント — セクション](wiki/master.md#section) を参照。
```

## 最終更新日の記録

ドキュメントを更新するたびに（初回作成時を除く）、末尾に追記または更新する:

```markdown
**Last updated**: YYYY-MM-DD — {変更内容の一行説明}
```

## やってはいけないこと

- `wiki/` 内にサブフォルダを作らない
- 同じ事実を複数のドキュメントに書かない
- 新規ドキュメントを追加したら必ず `home.md` も更新する
