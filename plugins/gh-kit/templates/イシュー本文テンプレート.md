# GitHub Issue 本文テンプレート

スキャナーが起票する Issue の本文に使うテンプレート。各セクションを実内容で埋めて投稿する。
不要なセクションは見出しごと削除してよい。

````markdown
## 概要

何についての問題か（1〜3 行）。

## 背景

なぜこの問題が起きているか / 関連仕様・要件・技術的背景。

## 現状

現状の実装。コードスニペットは ``` で囲んで添付。

```python
# 例: 該当箇所
def foo():
    ...
```

## 期待される状態

完了条件。「これが満たされたらこの Issue はクローズしてよい」が読み取れること。

## 対応案

対応案をチェックボックスで列挙する。**推奨案を最上位に置き、本文末尾に「推奨: A — 理由」を明記する。** 議論で結論が出たら該当案にチェックを入れ、それ以外の案を消す。

- [ ] A: {案 A の内容}
- [ ] B: {案 B の内容}
- [ ] C: {案 C の内容}
- [ ] その他（自由入力）

**推奨: A** — 理由を 1〜2 行

## 横展開

同じ問題がありそうな他箇所を列挙。

| No | 対象 | 内容 |
|---|---|---|
| 1 | `{path}` | {横展開内容} |

## 関連リンク

| No | ファイル / リンク | 備考 |
|---|---|---|
| 1 | `{path/to/file}` | {何の資料か} |
````
