# `needs-user-review` 判定基準

下記いずれかに **該当するもの以外** はすべて `needs-user-review` を付ける。

## 付けないもの（ブラックリスト）

- リファクタリング（表面の動作は変わらない変更、type: refactor）
- 命名規則変更
- 例外ハンドル変更（裸 `except:` 改善・ログ追加など）
- ロガー使用箇所の追加・整理
- ラベル / テキスト / コメントなど見た目変更
- dead code 除去
- 分散ロジックの単純な共通化
- タイムアウト追加
- タイムゾーン挙動の明示化
- typo / lint warning 修正
