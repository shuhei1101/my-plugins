# 観点 → 実ファイル一覧 への変換ルール

観点を実ファイル一覧に落とし込むときの統一ルール。

## 変換方法

| 観点の種類 | 方法 |
|---|---|
| フォルダ | Glob で配下のソースを収集 |
| grep パターン | Grep で検索しヒットしたファイルを対象に |
| レイヤー / ファイル種別 | ファイル名パターンで Glob |
| 単一ファイル | そのファイルのみ |

## 除外パターン（常時適用）

- `.git/` `.claude/`
- `node_modules/` `.venv/` `venv/` `__pycache__/`
- `dist/` `build/` `.next/` `.turbo/` `coverage/`
- `*.lock` `*.lock.json`
- ベンダリングされたサードパーティコード（明らかに自分のコードでないもの）

## 関連ファイルの追加読み込み

主対象ファイルだけでなく以下も文脈として読む:

- 兄弟ファイル（同フォルダの関連実装）
- import 元 / import 先（依存関係）
- 関連レイヤー（例: route → service → repository の縦のつながり）
- 対応するテストファイル（存在すれば）

## 対象 0 件のとき

そのまま「対象なし」として完了する（空 findings を返す）。
