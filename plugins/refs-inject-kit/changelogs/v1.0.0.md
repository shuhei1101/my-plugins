# refs-inject-kit v1.0.0

## 初回リリース

py-kit v2.0.0 で実装した `inject_references.py` を独立したプラグインに切り出した (PR140)。

### 設計のポイント

- **複数プラグインを自動検出**: `~/.claude/plugins/cache/*/*/*/references/injection_rules.yaml` と `${CLAUDE_PROJECT_DIR}/plugins/*/references/injection_rules.yaml` を走査し、reference を持つプラグインを動的に発見
- **`${REFS_INJECT_KIT_EXTRA_PATHS}` 環境変数で追加パスを設定可能**（テスト / 開発用）
- **言語切替**: `REFS_INJECT_KIT_LANG=jp` で日本語版テンプレと `index.jp.yaml` を使用
- **ループ防止**: セッション + ファイルハッシュトークンで 1 ファイル 1 セッション 1 回のみブロック

### プラグイン作者の統合手順

各プラグインに以下 3 ファイルを置くだけ（フックコード不要）:

- `references/injection_rules.yaml`: `rules: [{pattern, required, optional}]`
- `references/index.yaml`: `references: [{path, description}]` (英語)
- `references/index.jp.yaml`: 同・日本語ミラー (任意)
