# refs-inject-kit v1.1.0

## 破壊的変更: 中央集約 + プレースホルダ記法へ移行

v1.0.0 では各プラグイン（py-kit / next-kit 等）が `references/injection_rules.yaml` を持ち、
refs-inject-kit がそれらを自動検出する設計だった。

v1.1.0 では **全プラグインの注入ルールを refs-inject-kit に集約** する設計に変更:

### 新フォーマット

`plugins/refs-inject-kit/injection_rules.yaml`:

```yaml
enabled_plugins:
  - py-kit
  - next-kit

rules:
  - pattern: "**/*.py"
    required:
      - "${py-kit}/core/naming.md"
      - "${py-kit}/core/style.md"
    optional:
      - "${py-kit}/core/comments.md"
  - pattern: "**/page.tsx"
    required:
      - "${next-kit}/frontend/conventions/naming.md"
```

### プレースホルダ展開

`${plugin-name}/path/to/ref.md` を以下の順で解決:

1. `${CLAUDE_PROJECT_DIR}/plugins/{plugin}/references/{path}` — marketplace 開発時
2. `${HOME}/.claude/plugins/cache/*/{plugin}/*/references/{path}` — インストール済み
3. `${REFS_INJECT_KIT_EXTRA_PATHS}` — 追加パス

### 加わったもの

- `injection_rules.yaml` の集約（`${CLAUDE_PLUGIN_ROOT}/injection_rules.yaml` を読む）
- `${plugin-name}/path` プレースホルダ記法と展開ロジック
- `refs-inject-kit:add-plugin` スキル: プラグインを `enabled_plugins:` に登録し、`rules:` セクションにコメント付きスタブを挿入（rules 本体はユーザー手書き）

### 廃止

- 各プラグインに `references/injection_rules.yaml` を置く設計
- v1.0.0 で実装した「複数プラグインを自動検出して各々の rules を集める」ロジック
