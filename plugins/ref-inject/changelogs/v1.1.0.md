# ref-inject v1.1.0

## 変更

生成されるフックのトークンフィールドを `injected_at` → **`expires_at`** に変更した。

- `templates/hooks/inject_references.py`:
  - トークンの各エントリを `{injected_at: epoch}` → `{expires_at: epoch}`（`expires_at = 注入時刻 + TTL`）に変更
  - スキップ判定: `now - injected_at < TTL` → `now < expires_at`
  - 再注入後の書き込み: `injected_at = now` → `expires_at = now + TTL`
  - クリーンアップ: 期限切れ判定を `now - injected_at > TTL` → `now >= expires_at` に。`_cleanup_expired` の引数から `ttl` を削除
- `CLAUDE.md` / `CLAUDE.jp.md`: 注入設計の記述を `expires_at` に更新

## 背景

`expires_at` を保存すると判定が `now >= expires_at` で自明になり読みやすい。トレードオフとして、期限が注入時に確定するため **TTL の env var を変えても既存エントリには遡及しない**（`injected_at` 方式なら読み取り時計算で即座に効いた）。可読性を優先してユーザー判断で `expires_at` を採用（PR157）。
