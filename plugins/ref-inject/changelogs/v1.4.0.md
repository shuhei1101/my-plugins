# ref-inject v1.4.0 — 2026-05-30

## 変更内容

- **`references/` 配下のメタ系 YAML をアンダースコア接頭辞付きにリネーム**: `index.yaml` / `index.jp.yaml` / `injection_rules.yaml` を `_index.yaml` / `_index.jp.yaml` / `_injection_rules.yaml` にリネームし、ファイル一覧の最上部に固定表示されるようにした。
  - 注入フックテンプレート (`templates/hooks/inject_references.py`)、`apply` スキル、CLAUDE.md、テンプレート内のヘッダコメント、Jinja2 テンプレート (`injection.{md,jp.md}.j2`) も追従。
  - **既存プラグインで `/ref-inject:apply` を再実行する場合**: 旧名のファイル (`index.yaml` 等) が残っていればユーザー側で削除する必要がある（`apply` は上書きしない）。
- **`CLAUDE.md` の plugin 名整理**: PR166 で `dev-kit` に統合済みの `py-kit` / `next-kit` への参照（冒頭の説明と「関連プラグイン」表）を、現役の `dev-kit` / `claude-kit` に書き換え。「ref-inject テンプレートへ移行予定」も既に採用済みの表現に修正。
