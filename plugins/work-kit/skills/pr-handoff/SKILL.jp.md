# work-kit:pr-handoff — 引き継ぎ指示書の生成

現在のセッションの作業内容を分析し、次のセッション（真っさらなコンテキスト）に  
渡すための引き継ぎ指示書をコードブロックで会話内に出力する。

---

## 概要

1つのPRが終わった後に残作業がある場合、次のセッションのClaudeはこれまでの経緯を  
何も知らない。このスキルは「これまで何をしたか」と「次に何をしてほしいか」を  
まとめた指示書を生成し、ユーザーが次のセッションに貼り付けられるようにする。

---

## 作業内容

### ステップ 1: 引き継ぎ先のPRを確認

#### 条件

- 常に最初に実行する

#### 処理内容

1. ユーザーが次のPR番号・タイトルをすでに指定していればそれを使用する
2. 指定がない場合は以下を確認する:
   - `index.yaml` を読んで `completed: false` のPRを一覧表示する
   - ユーザーに「引き継ぎ先のPRを教えてください」と聞く

3. 引き継ぎ先のPRのTODO.mdが存在すれば読み込んで作業内容を把握する:
   ```
   .work/tasks/{task_folder}/PR{N}/TODO.md
   ```

→ ステップ 2 へ進む

#### 出力

- 引き継ぎ先のPR番号・タイトル・TODO内容（あれば）が確認された

---

### ステップ 2: 現在のセッション作業を要約

#### 条件

- ステップ 1 完了

#### 処理内容

1. 現在の会話履歴を振り返り、このセッションで行った主な作業を要約する:
   - 作業したPRの番号とタイトル
   - 完了した主な変更（何をどう変えたか）
   - 重要な設計判断・決定事項

2. 現在の作業PRのTODO.mdが存在すれば読み込んで完了済み行を確認する:
   ```
   .work/tasks/{task_folder}/PR{N}/TODO.md
   ```

→ ステップ 3 へ進む

#### 出力

- 現在セッションの作業サマリーが整理された

---

### ステップ 3: 引き継ぎ指示書をコードブロックで出力

#### 条件

- ステップ 2 完了

#### 処理内容

1. 以下の構成でmarkdown形式の引き継ぎ指示書を作成する
2. コードブロック（` ```markdown `）で会話内に出力する（ファイル保存は不要）

**引き継ぎ指示書の構成:**

```
# 引き継ぎ指示書 — PR{N}: {タイトル}

## 前回の経緯

このセッションでは {リポジトリ名} で以下の作業を行いました:

### 完了した作業
- {PR番号}: {タイトル} — {主な変更内容の要約}

### 重要な判断・決定
- {設計判断や背景情報があれば}

---

## 次のPRでやってほしいこと

**PR{N}: {タイトル}**

### 依頼内容

{TODO.md の作業内容または指示内容}

### 作業手順の提案

1. `/work-kit:work-start` でPR{N}の作業を開始する
2. {具体的な実装手順があれば}

### 参考ファイル

- `.work/tasks/{task_folder}/PR{N}/TODO.md`: タスクリスト
- {その他関連ファイル}

---

## 注意点

- {リポジトリ固有の制約・ルールがあれば}
- `CLAUDE.md` にプロジェクトルールが記載されているので最初に確認すること
```

→ 完了

#### 出力

- 引き継ぎ指示書がコードブロックで会話内に出力された

#### 補足

##### 出力形式について

- ファイルへの書き出しは不要
- コードブロックで出力することで、ユーザーがClaudeCodeのコピー機能でそのままコピーできる
- 次のセッションを新しく開いた後、コピーした内容を最初のメッセージとして貼り付ける

##### 出力の品質について

- 「次にやること」が明確になるよう具体的に書く
- 「なぜそうするか」の背景情報も添えると引き継ぎ品質が上がる
- TODO.mdの内容だけでなく、会話で判明した重要な制約や経緯も含める
