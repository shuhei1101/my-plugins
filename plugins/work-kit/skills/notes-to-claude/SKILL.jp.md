# work-kit:notes-to-claude — ノートを恒久知識に昇格させる

`.work/notes/` に蓄積した一時的なメモを分析し、
ルール・CLAUDE.md・references などの恒久アーティファクトに変換する。

---

## 概要

`.work/notes/` は「書き捨て可能な議事録・検討メモ」置き場であり、Claude Code に自動読み込みされない。
作業が蓄積してきたタイミングでこのスキルを実行し、有用な知識を永続的なファイルへ昇格させる。
不要なメモはその場で削除、昇格済みのメモも削除してよい。

---

## 作業内容

### ステップ1: ノート一覧を取得する

#### 条件

- 常に最初に実行する

#### 処理内容

1. `.work/notes/` 配下のファイルを列挙する:
   ```bash
   ls .work/notes/
   ```
2. ファイルが存在しない場合は「昇格対象のノートがありません」と報告して終了する

→ ステップ2へ進む

#### 出力

- ノートファイルの一覧

---

### ステップ2: 各ノートを分析して昇格種別を分類する

#### 条件

- ステップ1完了

#### 処理内容

各ノートを読み、以下の判定基準で昇格種別を決定する:

| 種別 | 昇格先 | 判定基準 |
|---|---|---|
| **A — ルール** | `.claude/rules/` | ファイル依存関係、「X を編集したら Y も更新」、パス構造の発見 |
| **B — CLAUDE.md** | `CLAUDE.md` | 全セッション共通の規約・禁止事項・命名規則 |
| **C — references** | `.claude/references/` | 詳細な参考資料・設計図・長い表（ルールからリンク） |
| **D — 廃棄** | 削除 | 一時的な比較・ボツ案・実装済みで不要になったメモ |

→ ステップ3へ進む

#### 出力

- 各ノートの昇格種別（A/B/C/D）と理由

---

### ステップ3: 既存アーティファクトと照合する

#### 条件

- ステップ2完了

#### 処理内容

種別 A / B / C のノートについて、内容を吸収できる既存ファイルがないか確認する:

| 種別 | 確認対象 |
|---|---|
| A | `.claude/rules/` 配下のルールファイル（ファイル名・見出しを確認） |
| B | プロジェクトの `CLAUDE.md` / `plugins/*/CLAUDE.md` |
| C | `.claude/references/` 配下のファイル |

- **既存ファイルに追記できる** → 既存ファイルへのマージを計画する（新規ファイル不要）
- **既存ファイルがない** → 新規ファイル作成を計画する

→ ステップ4へ進む

#### 出力

- 昇格計画: 各ノートの `昇格先ファイルパス`（既存 or 新規）と `アクション`（追記 or 新規作成）

---

### ステップ4: 昇格計画をユーザーに提示して確認する

#### 条件

- ステップ3完了

#### 処理内容

1. 以下のフォーマットで昇格計画を表示する:

   ```
   ## ノート昇格計画

   | ノート | 種別 | 昇格先 | アクション |
   |---|---|---|---|
   | foo.md | A — ルール | .claude/rules/feature/foo.md | 新規作成 |
   | bar.md | B — CLAUDE.md | plugins/work-kit/CLAUDE.md | 追記 |
   | baz.md | D — 廃棄 | — | 削除 |
   ```

2. 「この計画で進めますか？変更があれば指示してください」と確認する

→ ユーザーが承認したらステップ5へ進む

#### 出力

- ユーザーから承認を得た昇格計画

#### 補足

##### 禁止事項

- ユーザーの承認なしにファイルを編集・削除しない

---

### ステップ5: 昇格を実施する

#### 条件

- ステップ4完了（ユーザー承認済み）

#### 処理内容

承認された計画に従い、順番に実施する:

1. **種別 A — ルール**: `/claude-kit:rule-creator` を呼び出してルールを作成・更新する
2. **種別 B — CLAUDE.md**: `/claude-kit:claude-creator` を呼び出して CLAUDE.md を更新する
3. **種別 C — references**: `.claude/references/` に新規ファイルを作成するか、既存ファイルに追記する
4. **種別 D — 廃棄**: 該当ノートを削除する

→ ステップ6へ進む

#### 出力

- 昇格先ファイルが作成・更新済み

#### 補足

##### ルールや CLAUDE.md を作成する場合

種別 A / B の実施には対応するクリエイタースキルを使うこと。
直接ファイルを編集しない（スキルが構造・バージョン管理を強制するため）。

---

### ステップ6: 昇格済みノートの削除を提案する

#### 条件

- ステップ5完了

#### 処理内容

1. 昇格が完了したノートファイルの削除を提案する:
   ```
   以下のノートは昇格が完了しました。削除してよいですか？
   - .work/notes/foo.md（→ .claude/rules/feature/foo.md に昇格）
   - .work/notes/bar.md（→ CLAUDE.md に追記済み）
   ```
2. ユーザーが承認した場合のみ削除する

→ 完了

#### 補足

- 削除しない選択も有効（「参照用に残す」など）。強制しない。
- 廃棄（種別 D）は既にステップ5で削除済みのため再確認不要

## 参考資料

### 昇格種別の判定早見表

| 内容の性質 | 昇格先 |
|---|---|
| 「X を編集したら Y も更新」などのファイル依存 | ルール (`.claude/rules/`) |
| 命名規則・フォルダ構造・禁止事項（全セッション適用） | `CLAUDE.md` |
| 長い表・設計図・詳細仕様（ルールからリンクされる） | `.claude/references/` |
| 一時的な比較・調査メモ・ボツ案・完了済みメモ | 廃棄 |

### クリエイタースキル対応表

| 昇格種別 | 使用するスキル |
|---|---|
| ルール | `/claude-kit:rule-creator` |
| CLAUDE.md | `/claude-kit:claude-creator` |
| references | 直接作成でよい（スキル不要） |
