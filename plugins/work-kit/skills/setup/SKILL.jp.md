## 概要

work-kit が前提とするドキュメント構造をプロジェクトに初期化するスキル。
テンプレート展開は Claude が直接ファイルを作らず Python スクリプトに委譲する。

展開される構造:
```
{docs_dir}/
├── tasks/      # タスク・PR フォルダ（動的生成）
├── specs/      # 仕様書（空フォルダ）
└── QA.md       # 未解決事項
```

---

## 作業内容

### ステップ1: ドキュメントディレクトリのパスを確認する

#### 条件

- 常に — 最初に実行する

#### 処理内容

1. ユーザーに以下を確認する:
   - ドキュメントフォルダのパス（デフォルト: `docs`）

→ ステップ2へ進む

#### 出力

- ドキュメントディレクトリのパスが確定している

---

### ステップ2: セットアップスクリプトを実行する

#### 条件

- ステップ1が完了していること

#### 処理内容

1. 以下のコマンドを実行する:

```bash
python "${CLAUDE_SKILL_DIR}/../../scripts/setup.py" {docs_dir}
```

→ ステップ3へ進む

#### 出力

- テンプレートが `{docs_dir}` に展開済み

---

### ステップ3: 完了確認

#### 処理内容

1. スクリプトの出力を確認する
2. ユーザーに完了を報告する
