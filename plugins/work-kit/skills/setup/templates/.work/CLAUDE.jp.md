# .work/ — work-kit タスク管理ディレクトリ

このディレクトリは work-kit プラグインが管理するタスク・PR ライフサイクルの作業場所。
Claude はここのファイルを読み書きしながら作業状態を追跡する。

---

## ディレクトリ構成

```
.work/
├── tasks/
│   └── {YYYYMMDD}_{title}/       # タスクフォルダ（新規作業ごとに作成）
│       └── PR{N}/                # PR フォルダ（1タスクに複数 PR が紐づく場合あり）
│           └── TODO.md           # このPRの作業チェックリスト・仕様参照
├── specs/                        # 機能仕様書（タスクをまたいで参照）
│   └── {機能名}.md
└── QA.md                         # 未解決事項・設計上の疑問点
```

---

## 作業内容

### ステップ1: 新規作業を開始するとき

#### 処理内容

1. `/work-kit:work-start` を実行する
2. スキルの指示に従って TODO.md・仕様書・QA を整備する
3. ユーザーの承認後に実装を開始する

---

### ステップ2: 作業中

#### 処理内容

1. 実装前に該当 PR の `TODO.md` を読んで作業範囲を確認する
2. 完了したタスクを `- [x]` にチェックする
3. 仕様変更があれば `specs/` の該当ドキュメントも更新する
4. 疑問点や未確定事項は `QA.md` に追記する

---

### ステップ3: PR をマージするとき

#### 処理内容

1. `TODO.md` の `## TODO` セクションが全て `- [x]` であることを確認する
2. `/work-kit:merge` を実行する
3. マージ後、`QA.md` の解決済み事項を `## 解決済み` セクションへ移す

---

## 参考資料

### work-kit スキル一覧

| スキル | 用途 |
|---|---|
| `/work-kit:setup` | `.work/` を初期化する（初回のみ） |
| `/work-kit:work-start` | 新規タスク・PR・TODO.md を作成する |
| `/work-kit:merge` | TODO 確認・マージ・クリーンアップを実行する |

### 対応表

| ファイルパス | 概要 |
|---|---|
| `.work/tasks/{date}_{title}/PR{N}/TODO.md` | PR の作業チェックリスト |
| `.work/specs/{機能名}.md` | 機能仕様書 |
| `.work/QA.md` | 未解決事項 |
