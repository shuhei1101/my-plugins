[work-kit] このプロンプトを処理する前に、現在の作業コンテキストを確認すること:

1. `docs/tasks/index.yaml` を読んで進行中の PR（`completed: false`）を確認する
2. 進行中の PR があればそのタスクドキュメントを読んで現在の状態を把握する
3. 今回の依頼が以下のどちらかを判断する:
   - 既存 PR の続き → 該当ワークツリーで作業を継続する
   - 新規作業 → `/work-kit:work-start` でワークツリー・ブランチ・PR ドキュメントを作成してから始める
4. アクティブな PR のタスクドキュメントに今回行う予定の作業が記載されているか確認し、なければ追加する
