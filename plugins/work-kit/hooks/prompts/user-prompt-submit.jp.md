[work-kit] **このプロンプトを処理する前に、以下のステップを必ず実行すること。スキップ・省略は禁止。**

---

### ステップ1: PR が進行中かどうかを判断する

#### 条件

- 常に最初に実行する

#### 処理内容

**現在の Claude Code との会話セッション**で進行中の PR があるかどうかを確認する。

→ PR がある場合 → ステップ2へ
→ PR がない場合 → ステップ3へ

#### 補足

- 「進行中の PR」とは、この会話の中で作成・言及された PR のことを指す
- `index.yaml` やその他のファイルを読んで進行中 PR を探してはならない
- 判断に迷う場合は「PR なし」として扱い、ステップ3へ進む

---

### ステップ2: QA を確認してから TODO を読む

#### 条件

- 進行中の PR がある

#### 処理内容

1. `git worktree list` で進行中 PR のワークツリーパスを特定し、そのディレクトリに移動する
2. `.work/tasks/{YYYYMMDD}_{title}/PR{N}/QA.md` を読む
3. 未解決の QA エントリがあれば **ここで停止する** — ユーザーに QA の解決を求め、それ以上の作業は行わない
4. QA が全て解決済み（またはファイルが空）なら `.work/tasks/{YYYYMMDD}_{title}/PR{N}/TODO.md` を読む
5. 今回の依頼内容が TODO に含まれていない場合、作業を始める前に TODO に追記してコミットする
6. TODO の内容に従って作業を継続する

#### 補足

##### 禁止事項

- QA が未解決のまま実装を進めること
- master ブランチ上で `git commit` を実行すること

---

### ステップ3: work-start を実行してから始める

#### 条件

- 進行中の PR がない

#### 処理内容

1. `/work-kit:work-start` を実行して PR を作成する
2. PR が作成されたらステップ2へ進む

#### 補足

##### 禁止事項

- work-start をスキップしてファイルを編集・コミットすること
- master ブランチに直接コミットすること
- 「今回だけ」という理由でこのチェックを省略すること
