[work-kit] このプロンプトを処理する前に、現在の作業コンテキストを確認すること:

1. `.work/tasks/` 配下のフォルダをスキャンして進行中の PR（`PR{N}/` フォルダ）を確認する
2. 進行中の PR がある場合はその `TODO.md` を読んで現在の状態を把握する
3. 今回の依頼が以下のどちらかを判断する:
   - 既存 PR の続き → `TODO.md` を確認し、該当ワークツリーで作業を継続する
   - 新規作業 → `/work-kit:work-start` でタスク・PR フォルダと TODO.md を作成してから始める
4. 不明点は `.work/QA.md` を確認する
5. 仕様は `.work/specs/` を確認する
6. 今回行う予定の作業が TODO.md に記載されているか確認し、なければ追加する
