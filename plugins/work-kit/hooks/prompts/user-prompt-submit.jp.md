[work-kit] **必須チェック — 実装・コミット・ファイル編集を行う前に必ずこのチェックを完了すること。スキップ禁止。**

## ルール（絶対厳守）

- **master ブランチへの直接コミットは禁止。** 実装作業は必ず worktree + PR ブランチ上で行うこと。
- **PR ブランチなしで実装を始めてはならない。** ユーザーから実装を求められた場合、まず以下のチェックを完了してから着手すること。
- このチェックを「知っているが省略する」ことは許可されていない。毎回実行すること。

## チェック手順

1. **現在のセッションで進行中の PR がある場合:**
   a. `.work/tasks/{YYYYMMDD}_{title}/PR{N}/QA.md` を読む
   b. 未解決の QA エントリがあれば **作業を完全に停止し**、ユーザーに QA の解決を求める（QA 未解決のまま実装を続けることは禁止）
   c. QA が全て解決済み（またはファイルが空）なら `.work/tasks/{YYYYMMDD}_{title}/PR{N}/TODO.md` を読んで作業を継続する

2. **進行中の PR がない場合:**
   - `/work-kit:work-start` を実行して PR を作成してから始める
   - work-start をスキップして直接実装・コミットすることは禁止

## 違反パターン（これをやってはいけない）

- work-start せずにファイルを編集してコミットする
- master ブランチ上で `git commit` を実行する
- QA が未解決のまま TODO の実装を進める
- このチェックを「今回は省略する」と判断する
