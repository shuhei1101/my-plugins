[work-kit] 作業開始前チェック

ユーザーの依頼を処理する前に以下を確認すること。

1. `docs/tasks/index.yaml` を読んで進行中の PR（`in_progress: true`）を把握する
2. 進行中の PR がある場合はそのタスクドキュメントを読んで現在の状態を確認する
3. 今回の依頼が以下のどちらかを判断する:
   - 既存 PR の続き → 該当ワークツリーで作業を継続する
   - 新規作業 → `/wt:wt` でワークツリーとブランチを作成してから始める
4. 作業対象の PR タスクドキュメントに今回やる内容が記載されていなければ追加する
