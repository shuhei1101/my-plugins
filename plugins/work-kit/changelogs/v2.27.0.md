# v2.27.0 — 2026-05-24

## 変更内容

- **merge Step 10 を分割して「次の PR」提示を 3 カテゴリ化**: 旧 Step 10（完了報告 + pr-handoff 呼び出し + 進行中 PR 一覧）を 3 ステップに分割。新 Step 12 では予約済み PR を `🟢 着手可能 / 🟡 進行中 / 🔴 条件あり` の 3 カテゴリに分類して表示する。
  - 🟢 着手可能: `git log master..{branch} --oneline | wc -l ≤ 1`（予約直後・未着手）
  - 🟡 進行中: コミット数 ≥ 2（他セッション作業中）
  - 🔴 条件あり: 今マージした PR の `## 次PR候補` で実施条件が他候補依存になっているもの（[[glossary#依存後続候補]]）

## 構造の変更

- merge SKILL の Step 10 → Step 10/11/12 に分割（番号繰り下げではなく末尾追加のみ）
