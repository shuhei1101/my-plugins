# work-kit v2.39.0 — 2026-05-30

## 変更内容

- **guard-kit を統合**: 別プラグインだった `guard-kit`（`git push` / `git merge` を検出して PreToolUse(Bash) でユーザー確認を挟む）を work-kit に取り込んだ。インストール対象が 1 プラグイン減る。
- **env トグル `WORK_KIT_GUARD` を追加**: ガード機能はデフォルト有効。`false`/`0`/`no`/`off` で無効化。プロジェクト個別に `.claude/settings.json` の `env` で切り替え可能（プロジェクト配下の設定がユーザー配下の設定より優先される）。

## 変更ファイル

- `hooks/scripts/git-guard.py` — guard-kit から移植 + `WORK_KIT_GUARD` env チェックを追加
- `hooks/prompts/git-guard.md` / `git-guard.jp.md` — guard-kit から移植
- `hooks/hooks.json` — PreToolUse(Bash) 配列に git-guard エントリを追加
- `.claude-plugin/plugin.json` — 2.38.0 → 2.39.0
- リポジトリ側: `plugins/guard-kit/` 削除、`.claude-plugin/marketplace.json` から guard-kit エントリ除外、work-kit の description に `WORK_KIT_GUARD` を追記
