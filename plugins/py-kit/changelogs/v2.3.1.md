# py-kit v2.3.1

## 変更

任意 companion だった `session-kit` プラグインが削除された（PR155）ことに伴うドキュメント/コメントの整理。**コード挙動の変更はない。**

- `hooks/inject_references.py` のトークン挙動コメントから session-kit への言及を除去。注入トークンは常にセッション全体で生きる（once-per-pattern）。「このターンで注入済み」→「このセッションで注入済み」に修正
- `CLAUDE.md` / `CLAUDE.jp.md` の「任意 companion session-kit」記述を削除し、トークンはセッション中1回注入・空マーカーは自動削除されない旨に修正

## 背景

session-kit は注入トークンを毎ターン削除して reference をターンごとに再注入させる任意 companion だったが、現在の注入は path+description のポインタのみ（PR147）でターンごと再注入の限界価値が小さく、専用のプラグイン横断プラグインに見合わないと判断して削除した。
