# py-kit v2.4.0

## 変更

references 自動注入フックを **PR156 で作った `ref-inject` の注入形式へ移行**した。フックの実体は `ref-inject` のテンプレートを `/ref-inject:apply` で再生成したもので、プラグインごとの手書きをやめた。references の実コンテンツ（`index.yaml` / `index.jp.yaml` / `injection_rules.yaml` / 各 reference 本文）はそのまま保持し、差し替えたのは注入の仕組み（hooks + テンプレ）のみ。

- `hooks/inject_references.py`: `ref-inject` 版へ置換（`PLUGIN_NAME=py-kit` / `ENV_PREFIX=PY_KIT` / `LOG_TAG=py-kit-references-injection` / `DEFAULT_TTL=3600`）
- 本文注入の復活: `required` は **本文全量**、`optional` は **path + description のみ**（PR147 でポインタのみにしていたのを、TTL トークンで再注入を抑制できるため本文に戻した）
- トークン方式の変更: パターンハッシュごとの空マーカーファイル（`{session_id}-{patternhash}`）→ pattern をキーにした **拡張可能 YAML マップ** `~/.claude/tokens/py-kit/{session_id}.yaml`（各エントリ `expires_at` = 注入時刻 + TTL）
- **TTL** 判定: `now < expires_at` の間はスキップ、`now >= expires_at` で再注入。デフォルト 3600 秒、`settings.json` の `env` `PY_KIT_INJECTION_TTL`（秒）で上書き可。発火のたびに期限切れエントリを掃除し、空ファイルを削除（expires_at を保存するため、TTL を変えても既存エントリには遡及しない）
- **`PreCompact` フックは作らない**: `/compact` 後は TTL 経過で本文が再注入されるため不要（PR156 で決定）
- `hooks/templates/injection.md.j2` / `injection.jp.md.j2`: `required` を本文全量で展開するテンプレートへ置換
- `CLAUDE.md` / `CLAUDE.jp.md` / `references/CLAUDE.md` / `references/CLAUDE.jp.md`: 注入設計の説明を新方式に更新
- `hooks/hooks.json`: 変更なし（新旧で同一）

## 背景

`ref-inject`（PR156）はこの注入の仕組みを「プラグインへ後付けできる機構」として切り出したもの。py-kit はその最初の移行先。本文全量に戻したのは、TTL トークンが再注入を絞るためコンテキスト肥大（PR147 で問題化）が再発しないと判断したため。
