# py-kit v2.3.0

## 加わったもの

`references/core/comments.md`（および JP ミラー `comments.jp.md`）に、関数の中身（各ステップ・条件分岐）へのコメント方針を追記（PR154）。

aituber のリファクタリング中に「マーカーは見やすいが中身にもコメントが欲しい」という指摘が出たのが発端。コメントの量はレイヤーではなくコードの非自明さに従う、という整理。

### 追記内容

- **マーカーだけでなく中身にもコメント** — ブロックマーカーのラベルだけでなく、各ステップが何をしてなぜそうするのかを一言添える。**レイヤーに関係なく**（サービス / 内部ヘルパー / 末端ユーティリティすべて同じ）適用する
- **条件分岐パターン** — `if` / `elif` / `else` の各分岐に「条件の意味 + 何をするか」をインラインコメント。コメントだけで判断ツリーを追えるようにする
- **ログ出力のみの行はコメント不要** — `logger.*` は自明なので説明コメントを付けない（「書いてはいけないもの」に例を追加）
- 必須 / 推奨マトリクスと制約まとめに上記の行を追加
- `handle_personal_chat` を例にしたサンプルを追加（たまたまサービス関数だが、どのレイヤーでも同じ書き方をする旨を明記）
