# タスク索引スキーマ（`index.yaml` / `index.archive.yaml`）

`.work/tasks/` 配下のブランチ索引ファイルのスキーマ。`.work/tasks/index*.yaml` を編集するときに
自動注入される。これらは通常 `index-tool.py`（Bash 経由）と `merge` スキルが管理する —
索引を直接修正するときだけ手編集する。
英語原文: `タスクインデックス.md`

---

## `index.yaml` — 進行中ブランチ索引

git 管理外（`.work/tasks/.gitignore` に記載）。ブランチ状態の単一の正本。

```yaml
# .work/tasks/index.yaml — ブランチ索引
last_id: 0
branches: []
```

| フィールド | 意味 |
|---|---|
| `last_id` | これまでに付与した内部数値 ID の最大値。`index-tool.py next-id` が読み取り・採番する。アーカイブ相互参照専用 — ブランチ名・ワークツリーパス・ファイル名には**埋め込まない** |
| `branches` | ブランチエントリの一覧（下記）。`completed: false` = 進行中 |

### ブランチエントリ

```yaml
- id: 258                       # 内部数値 ID（アーカイブ相互参照）
  branch: refactor/my-feature   # git ブランチ名
  title: 機能名                  # ブランチドキュメントの H1 タイトル（日本語）
  type: refactor                # feat / fix / docs / refactor / chore / test
  tags: []                      # 自由形式タグ（省略可）
  summary: 一行説明              # ファイルを開かずに内容がわかる一行説明
  task: 260531_my-feature       # タスクフォルダ名（YYMMDD_{title}）
  completed: false              # false = 進行中、true = マージ済み / 廃止済み
```

---

## `index.archive.yaml` — アーカイブ済みブランチ

git 管理対象。`index-tool.py archive` がマージ時に `completed: true` のエントリをここへ移動し、
`index.yaml` を小さく保つ。

```yaml
# Managed by workspace merge skill. Archived (completed / abandoned) branches.
branches: []
```

### アーカイブエントリ

進行中エントリと同じフィールドに加えて:

| フィールド | 意味 |
|---|---|
| `archived` | アーカイブ日（`YYYY-MM-DD`） |
| `resolution` | `merged` または `abandoned` |

---

## 規約

- `task` フォルダのプレフィックスは 6 桁 `YYMMDD`（例: `260531`）。8 桁形式は使わない。
- `index.yaml` は git 管理外 — コミットしない。変更時に master へのコミットは不要。
- 手編集より `index-tool.py`（`next-id` / `add` / `archive`）を優先する。
