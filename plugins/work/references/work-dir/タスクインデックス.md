# Task Index Schema (`index.yaml` / `index.archive.yaml`)

Schema for the branch index files under `.work/tasks/`. Auto-injected when you edit
`.work/tasks/index*.yaml`. These files are normally maintained by `index-tool.py` (via Bash) and
the `merge` skill — hand-edit only when fixing the index directly.
Japanese mirror: `タスクインデックス.jp.md`

---

## `index.yaml` — active branch index

Git-ignored (listed in `.work/tasks/.gitignore`). The single source of truth for branch status.

```yaml
# .work/tasks/index.yaml — ブランチ索引
last_id: 0
branches: []
```

| Field | Meaning |
|---|---|
| `last_id` | Highest internal numeric ID assigned so far. `index-tool.py next-id` reads/increments it. Used only for archive cross-reference — **not** embedded in branch names, worktree paths, or file names |
| `branches` | List of branch entries (see below). `completed: false` = in progress |

### Branch entry

```yaml
- id: 258                       # internal numeric ID (archive cross-reference)
  branch: refactor/my-feature   # git branch name
  title: 機能名                  # the branch document H1 title (Japanese)
  type: refactor                # feat / fix / docs / refactor / chore / test
  tags: []                      # free-form tags (optional)
  summary: 一行説明              # one-line summary readable without opening the doc
  task: 260531_my-feature       # task folder name (YYMMDD_{title})
  completed: false              # false = in progress, true = merged / abandoned
```

## `index.archive.yaml` — archived branches

Committed to git. `index-tool.py archive` moves `completed: true` entries here on merge, keeping
`index.yaml` small.

```yaml
# Managed by workspace merge skill. Archived (completed / abandoned) branches.
branches: []
```

### Archived entry

Same fields as an active entry, plus:

| Field | Meaning |
|---|---|
| `archived` | Archive date (`YYYY-MM-DD`) |
| `resolution` | `merged` or `abandoned` |

---

## Conventions

- Use a 6-digit `YYMMDD` (e.g. `260531`) for the `task` folder prefix, not the 8-digit form.
- `index.yaml` is git-ignored — never commit it; no master commit needed when it changes.
- Prefer `index-tool.py` (`next-id` / `add` / `archive`) over hand-editing.
