# イシュー記述ルール

`.work/issues/` 配下のイシューファイルの書き方。`.work/issues/ISSUE-*.md` を読み・書き・編集する際に
自動注入されるので、直接これに従う — 専用の保存スキルは存在しない。
Japanese mirror: `references/issues/イシュー記述ルール.jp.md`

---

## イシューとは

1 イシュー = コードベースで発見された、またはユーザーが報告した、独立して対処可能な 1 つの問題。
各イシューは 1 つの Markdown ファイル。オープンなイシューは `.work/issues/ISSUE-{N}.md`、
クローズ済みは `.work/issues/closed/ISSUE-{N}.md` に置かれる（`merge` スキルが移動する）。

---

## ファイル命名と採番

- ファイル名: `ISSUE-{N}.md`（`{N}` は 3 桁ゼロ埋め。例 `ISSUE-007.md`）。
- 正本のカウンタは `.work/issues/_index.yaml` の `last_id`。
- 新規 ID の採番: `last_id` を読み、+1 した値を `{N}` とする。
- **並列採番（issue-scan）**: 一度に多数のイシューを作る場合、オーケストレーターが各書き手に
  予約済み ID ブロックを渡すため、イシュー番号は連続しないことがある。これは想定内 — ID は
  一意で単調増加であればよく、欠番があってもよい。

---

## ファイルフォーマット

**イシュー本文は日本語で書く** — イシューは日本語話者が読むため、タイトル・セクション見出し・本文は
すべて日本語。本文には作成日と問題のみを書き、分類メタデータ（type / priority / tags / scope）は
ファイルではなく `_index.yaml` で管理する。

以下の構造で正確に書く。該当しない任意セクションは省略する:

```markdown
# ISSUE-{N}: {タイトル（日本語）}

**作成日**: {YYYY-MM-DD}

## 問題

{何が問題で、なぜか。可能なら file:line を引用する。}

## 水平展開

{同じパターンがコードベースの他のどこに存在しそうか。}   ← 無ければセクションごと省略

## 修正案

{修正の方向性。}   ← 不明ならセクションごと省略
```

- 必須は `## 問題` のみ。`## 水平展開`・`## 修正案` は任意。
- `**Type**` / `**Priority**` / `**Tags**` / `**Scan scope**` 行や `## User's words` セクションは
  **書かない**（廃止した）。分類は `_index.yaml` に置く。
- `**作成日**` は Bash 経由で `date +%Y-%m-%d` を使う。

---

## インデックスの更新

イシューファイルを書いたら、`_index.yaml` の `issues` リストにエントリを追記し `last_id` を更新する。
type / priority / tags / scope はここに記録する:

```yaml
- id: ISSUE-{N}
  title: "{タイトル}"
  created: {YYYY-MM-DD}
  type: {refactor | rule-violation | ui | backend}
  scan_scope:
    - "{scope}"        # scope が無ければ scan_scope: [] とする
  priority: {high | medium | low}
  tags: [{tags}]
```

- `type`: `refactor`（整理・再構成）、`rule-violation`（規約・リファレンス違反）、
  `ui`（フロントエンド・見た目）、`backend`（サーバー・データ・ロジック）。
- `priority`: 推定値 — ユーザーが後で `_index.yaml` を編集して変更できる。
- `_index.yaml`（オープンイシュー・git 管理外）がライブな一覧。`last_id` は使用した全イシュー番号以上に保つ。
- `_index.archive.yaml`（クローズ済み + スキャン記録・git 管理）はここでは編集しない —
  `merge` スキル（クローズ時）と `issue-scan`（スキャン記録）が管理する。

---

## クローズ

クローズは手編集しない。`merge` スキルがブランチドキュメントの `## 関連イシュー` テーブルに
列挙されたイシューをクローズする: ファイルを `closed/` へ移動し、`_index.yaml` のエントリを削除し、
`_index.archive.yaml` に追記する。修正せず捨てる場合は `resolution: wontfix` でクローズする。
