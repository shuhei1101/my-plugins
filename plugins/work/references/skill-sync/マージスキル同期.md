# Merge Skill ↔ Merge-Flow Note Sync

The merge flow's current spec lives in the note `.work/notes/work-kitスキル群.md`. When you add,
remove, or reorder steps in the merge `SKILL.md`, update that note's merge-flow description in the
same change so the note keeps reflecting the actual behavior.
Japanese mirror: `references/skill-sync/マージスキル同期.jp.md`
