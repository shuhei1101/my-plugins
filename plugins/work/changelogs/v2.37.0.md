# workspace v2.37.0 — 2026-05-29

## 変更内容

- **worktree-kit プラグインを統合**: 廃止した `worktree-kit` の 2 スキルを workspace に取り込んだ。
  - `work-add` — git worktree とブランチを作成（旧 `worktree-kit:work-add` → `workspace:work-add`）
  - `vscode-workspace-sync` — VS Code `.code-workspace` の `folders` を worktree と同期する PostToolUse フックを設定（旧 `worktree-kit:vscode-workspace-sync` → `workspace:vscode-workspace-sync`）
- **ワークツリー利用を env var でゲート**: `work-start` Step 4 が環境変数 `WORK_KIT_USE_WORKTREE` を見て分岐するようになった。
  - デフォルト有効。`false` / `0` / `no` / `off` を設定するとワークツリー作成をスキップし `.work/` 管理のみで動作する。
  - 従来の「worktree-kit インストール有無」判定を置き換えた。
- `work-start` は `/workspace:work-add` を呼び出すように変更（旧 `/worktree-kit:work-add`）。

## 構造の変更

- `plugins/worktree-kit/` を削除。`.claude-plugin/marketplace.json` から `worktree-kit` エントリを削除。
- `plugins/workspace/skills/work-add/` と `plugins/workspace/skills/vscode-workspace-sync/` を追加。
- ワークツリーを使わないプロジェクトは、`settings.json` の `env` に `WORK_KIT_USE_WORKTREE=false` を設定する（worktree-kit を入れない運用の代替）。
