[master-commit-guard] master/main/develop ブランチへの直接コミットをブロックしました。再実行しても通りません。

対応方法:
- まず以下の git status と現在のディレクトリを確認し、なぜ保護ブランチ上でコミットしようとしたのかを把握してください。
  - 多くの場合、cwd がワークツリーではなくメインリポジトリに戻っているのが原因です。`git -C {ワークツリーパス} commit` で実行し直してください。
- 作業ブランチが必要な場合は `/work:start` でワークツリーを作成してください。
- 本当に保護ブランチへ直接コミットする必要がある場合のみ、ユーザーに確認を取ったうえで
  `WORK_ALLOW_MASTER_COMMIT=1 git commit ...` の形で実行してください。
