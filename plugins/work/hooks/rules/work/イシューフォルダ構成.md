# イシューフォルダ構成
```
.work/
├── issues/
│   ├── closed # 終了したイシュー
│   ├── logs # サブエージェントが実行したログ
│   ├── progress # 進行中のイシュー（現在エージェントが対応中のイシュー）
│   ├── targets # ユーザが確認したイシュー（AIがいつでも実施できるイシュー）
│   ├── _index.archive.yaml # アーカイブされたイシューの索引
│   ├── _index.yaml # イシューの索引
│   ├── .gitignore # _index.archive.yaml以外はすべてgitignoreする
│   ├── ISSUE-{N}.md # ユーザ確認待ちのイシュー
│   ...
```
