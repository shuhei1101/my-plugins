### `_index.yaml`の構成

```yaml
- id: ISSUE-007
  title: "{日本語タイトル}"
  created: {YYYY-MM-DD}
  type: {type}          # refactor / rule-violation / ui / backend
  scan_scope:           # イシューを発見したスコープを記載する。例えば、`src/llm/**`の用に記載。
    - "{scope}"         # 無ければ scan_scope: []
  priority: {priority}  # high / medium / low
  tags: [{tags}]        # 任意のタグを列挙する。例: [config, performance]
  status: not_started   # not_started / in_progress（issue-tool.py set-status で設定）
  branches: []          # このイシューに対応するブランチ名の配列（work:start が追記）
  # direct_merge: true  # 省略可 — true のとき issue-resolver は最終コミット後に直接マージする
```
