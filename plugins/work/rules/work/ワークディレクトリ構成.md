# .work/ ディレクトリガイド

## ディレクトリ構成

```txt
.work/
├── tasks/
│   ├── index.yaml # 進行中のタスク索引
│   ├── index.archive.yaml # アーカイブされたタスクの索引
│   └── {YYMMDD}_{title}/
│       ├── {YYMMDD}-{title}.task.md  # タスクドキュメント
│       └── (任意の作業ファイル)
├── notes/
│   ├── _index.md # ノート索引
│   └── {カテゴリ}/
│       └── {topic}.md # スナップショット仕様書
└── issues/
│   ├── closed/  # クローズしたイシュー
│   ├── logs/ 
│   │   ├── {YYMMDD-HHMM}-{title}.scan.md  # `/issue-scan`スキルを実施した結果
│   │   ├── {YYMMDD-HHMM}-{title}.resolve.md  # `/issue-resolve`スキルを実施した結果
│   │   └── ...
    └── ISSUE-{N}.md # イシューファイル

```
