# タスクドキュメント

## 配置とファイル名
```
.work/tasks/{YYMMDD}_{タスクタイトル}/{YYMMDD}-{日本語タイトル}.task.md
```

- タスク**フォルダ**は 1 タスクにつき 1 つ（`{YYMMDD}_{タスクタイトル}`）。1 フォルダに複数のタスク
  ドキュメント（同一タスク領域を複数ブランチで進める場合）や**ユーザーが任意に作成したファイル**を
  格納してよい — タスクフォルダは汎用の作業領域も兼ねる。
- タスクドキュメント本体は必ず **`.task.md`** 拡張子を持ち、ユーザーファイルと明確に区別する。
- ファイル名のステムは `{YYMMDD}-{日本語タイトル}`（6 桁日付 + 日本語 H1 タイトル）。
- git ブランチ名はファイル名に**含めない** — `> ブランチ:` ヘッダー行に記録する。


## テンプレート

```markdown
# {日本語タイトル}

> ブランチ: `{branch-name}`

## 概要

<!-- このブランチの目的・背景を書く -->

### 実施条件

<!-- {例: 即時実施可 / 「{他ブランチ名}」が完了してから} -->

## 作業内容

| No | 完了 | 作業内容 |
|---|---|---|
| 1 | - | 未解決事項を `## QA` に記録する |
| 2 | - | {実装タスク（ブランチ固有の作業に書き換える）} |
| 3 | - | 実装箇所に対応するテストを追加、編集する |
| 4 | - | プロジェクトのテストを実行する |
| 5 | - | `.work/notes/` の関連ノートを更新する |

## 変更内容

<!-- 実装したファイル（テスト以外）。コミットに積まれる全ファイルを列挙する。 -->

| No | ファイル名 | 新規/編集 | 内容 | 補足 |
|---|---|---|---|---|
| 1 | `{file/path}` | 新規 | {このファイルで何を実装したか} | {補足あれば} |

## テスト

<!-- 手動テスト・動作確認の実施記録。 -->

| No | 確認内容 | 実測結果 | 判定 |
|---|---|---|---|

## QA
```
