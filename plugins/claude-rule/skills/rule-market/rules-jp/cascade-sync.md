# カスケード同期（Cascade Sync）

> このファイルは人間向けの日本語ミラーです。Claude には読み込まれません。本体は `rules/cascade-sync.md`。

## 概要

ファイルを編集したとき、関連するすべてのリソース（wiki、ルール、JP ミラー）を同じコミットで更新する。関連ドキュメントを変更後に古いまま放置しない。

## Step 1 — 適用されるルールを探す

`.claude/rules/**/*.md` をスキャンし、編集したファイルにマッチする `paths:` パターンを持つルールを見つける。そのルールの「参照ドキュメント」セクションが確認すべき場所を示す。

## Step 2 — wiki / ドキュメントを更新する

編集によってドキュメント化された挙動（スキーマ、フィールド名、プロセス、有効な値）が変わる場合はドキュメントを更新する。挙動が変わらなければ更新不要。

## Step 3 — 変更した識別子を grep する

ドメイン定数（設定キー、識別子、モデル名など）を追加・削除・リネームするとき:

```
grep -r "<old_or_new_identifier>" src/ docs/ wiki/
```

見つかったすべての参照を更新する。

## Step 4 — ルール自体を更新する

ルールの説明や参照リストが今の内容と合わなくなったら:
1. `.claude/rules/<rule>.md`（英語本体）を更新
2. `.claude/rules-jp/<rule>.md`（JP ミラー）を更新
3. 両方を同じコミットに含める

## 三方向ループ

```
ファイル変更 → 適用ルールが読み込まれる → 参照ドキュメントを更新
ドキュメント更新 → ルールの参照リストが完全か確認
ルール更新 → JP ミラーを同期 → 参照ドキュメントを確認
```
