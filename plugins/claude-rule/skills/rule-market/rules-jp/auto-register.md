# ルール自動登録（Auto Rule Registration）

> このファイルは人間向けの日本語ミラーです。Claude には読み込まれません。本体は `rules/auto-register.md`。

## 概要

ファイルを編集するとき、そのファイルが既存の path-scoped ルールでカバーされているか確認する。カバーされていなければ新しいルールを作成する。

## カバー状況の確認方法

`.claude/rules/**/*.md` をスキャンし、`paths:` パターンをグロブセマンティクスで照合する。
広いパターンが適用されていれば（例: `src/**/*.py` が Python ソース全体をカバー）、別途ルールは不要。

## ルールを作るとき

以下の場合に作成する:
- 既存のカバレッジがないドメインのファイル
- 特定の制約、参照ドキュメント、カスケード同期が必要なドメイン

作成不要:
- 手動編集不要な自動生成ファイル
- 広いパターンで既にカバー済み
- ドキュメントも設計も持たない一回限りのスクリプト

## ルールの作り方

1. `.claude/rules/<domain>.md` を `paths:` frontmatter 付きで作成し、最低限:
   - ドメインの説明と適用条件
   - 参照ドキュメントの一覧
   - カスケード同期のメモ
2. `.claude/rules-jp/<domain>.md` を作成（JP ミラー）
3. `CLAUDE.md` のフォルダスコープルールテーブルに行を追加
4. EN ルール + JP ミラー + CLAUDE.md 更新を同じコミットに含める

`/rules-creator` スキルでファイルを自動スキャフォールドできる。
