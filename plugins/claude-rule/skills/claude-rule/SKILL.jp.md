# Claude 指示ファイルの記述ルール

このルールは、Claude が指示として読み込むファイル（`CLAUDE.md`、`SKILL.md`、スタンドアロンのプロンプトファイルなど）を作成・編集するすべての場面に適用されます。

## 基本ルール：AIへの指示は英語で書く

Claude Code は、正確なファイル名（`CLAUDE.md`、`SKILL.md`）で指示ファイルを自動読み込みします。これらのファイルの内容は**必ず英語**で記述してください。これにより、Claude は翻訳のオーバーヘッドなしに明確・的確な指示を受け取ることができます。

## バイリンガルファイル規約

すべての指示ファイルには、人間の著者が参照するための日本語翻訳ファイルが対になって存在します。

| Claude が自動読み込み（英語） | 人間の参照用のみ（日本語） |
|------------------------------|--------------------------|
| `CLAUDE.md` | `CLAUDE.jp.md` |
| `SKILL.md` | `SKILL.jp.md` |

**`.jp.md` ファイルは Claude Code に自動読み込みされません。** これは人間が内容を読み、英語本体の編集前後に意図を確認するための参照専用ファイルです。

この分離が必要な理由：人間の著者は日本語で考え・コミュニケーションしますが、Claude には英語で指示を与える必要があります。`.jp.md` ファイルは著者の作業コピーとして機能し、意図を母国語で記録し、英語ファイルが意図通りの内容になっているかを検証しやすくします。

## 更新ワークフロー

指示ファイルに変更が必要な場合：

1. **まず `.jp.md` を更新する** — 日本語で変更内容を記述し、意図が正しく表現されているか確認する
2. **次に英語本体を更新する** — 同じ変更を権威ある英語ファイルに反映する
3. **両ファイルは常に同期を保つ。** 片方だけ更新してはいけない。

ユーザーは日本語で指示を出します。あなたがすべきことは：
- 日本語（`.jp.md` またはユーザーのメッセージ）で意図を受け取る
- 対応する英語の権威ファイルを記述・更新する
- `.jp.md` も同期させる

## ファイル名まとめ

| ファイル | 言語 | Claude が読む？ | 目的 |
|---------|------|-----------------|------|
| `CLAUDE.md` | 英語 | はい（自動） | プロジェクトレベルの指示 |
| `CLAUDE.jp.md` | 日本語 | いいえ | CLAUDE.md の人間向け参照 |
| `SKILL.md` | 英語 | はい（自動） | スキル定義 |
| `SKILL.jp.md` | 日本語 | いいえ | SKILL.md の人間向け参照 |

## 新しい指示ファイルを作成するとき

ゼロから Claude 指示ファイルを作成する場合：

1. まず日本語版（`*.jp.md`）を下書きして意図を確定させる
2. 英語版（サフィックスなしの正式名）を翻訳・記述する
3. 両ファイルを一緒にコミットする

## やってはいけないこと

- `CLAUDE.md` や `SKILL.md` の中に日本語のコンテンツを書かない — Claude がそのまま読む
- 英語本体と異なる内容の `.jp.md` ファイルを作成しない
- `.jp.md` の作成を省略しない — 著者が将来編集するときに必要
