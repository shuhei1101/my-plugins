# md-template-create

ドキュメントの書式を定義するテンプレートファイル（例: `テンプレート/モジュール構成.md`）を、以下の構成で作成する。

## 入力

- タイトル: テンプレート名
- セクション構成: 対象ドキュメントが持つセクションと、それぞれの必須 or 条件

指示から読み取れない場合は作成前にユーザーに確認する。

## 出力構成

| 順序 | 内容 |
| --- | --- |
| 1 | `# {タイトル}` |
| 2 | `## セクション一覧` — セクション / 必須or条件 の 2 列表だけを置く（説明文は書かない） |
| 3 | セクションごとに `## {セクション名}` の H2 + `### 記述例` + `### 補足` を繰り返す |

## 雛形

````markdown
# {タイトル}

## セクション一覧

| セクション | 必須or条件 |
| --- | --- |
| `## {セクション名A}` | 必須 |
| `## {セクション名B}` | {条件}の場合のみ |

## `## {セクション名A}`

### 記述例

```markdown
## {セクション名A}

{記述例本文}
```

### 補足

- {書き方の要点}

## `## {セクション名B}`

（`### 記述例` + `### 補足` の同構成を繰り返す）
````

## 補足の書き方

記述例が表を含むセクションでは、カラムごとの説明を **`**{カラム名}列:**` の太字ラベル** で列挙する。

````markdown
### 補足

**種別列:**
- `クラス` / `関数` / `データモデル` のいずれかを書く

**補足列:**
- 特記事項がなければ `-`
````
